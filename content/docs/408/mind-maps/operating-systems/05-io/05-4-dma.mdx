# 5.4 DMA控制方式与寄存器

## DMA的核心目的
- CPU事先配置传输参数：内存地址、传输长度、方向、设备/通道
- DMA控制器在获总线/互联访问权后，**设备与主存直接交换数据**
- 完成或出错时，通常以中断/状态寄存器等方式通知CPU
- <img src="/images/408-mind-maps/os-0131.svg" alt="DMA命令、传送和完成通知流程" width="560" height="306">

## 经典教材的寄存器
- **MAR**（Memory Address Register）：主存起始或当前地址
- **DC**（Data Count）：剩余传输字节/字数，具体按题意
- **CR**（Command Register）：控制、读写方向、启动等
- **DR**（Data Register）：在部分DMA结构中用于暂存数据；不是每种DMA芯片都具有相同寄存器清单
- <img src="/images/408-mind-maps/os-0153.svg" alt="DMA控制器结构图与地址、数据计数、命令寄存器" width="760" height="300">

## DMA与CPU的关系
- **配置阶段** CPU参与；传输过程中CPU通常不逐字搬运
- DMA仍占用总线/内存带宽，与CPU访问主存可能竞争
- 经典传输策略：周期窃取、停止CPU访存、交替访存；按题设分析
- 缓存一致性须由硬件或驱动同步保证；有DMA不等于自动缓存一致

## 考试中的传输粒度
- 教材常以“整块数据传送一次、结束后中断”对比PIO
- 实际传输长度可配置，**并非DMA一次只能搬一个物理磁盘块**
- 高级控制器支持**分散-聚集（scatter-gather）**，可传离散物理缓冲区
- 408题若明确“不支持分散-聚集”，按题给模型计算
