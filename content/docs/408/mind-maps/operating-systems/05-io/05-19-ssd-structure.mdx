# 5.19 SSD结构：闪存页、擦除块与FTL

## SSD的基本组织
- SSD以**NAND闪存芯片**为主要存储介质，控制器执行地址转换和闪存管理
- NAND通常**以页读取/编程**，以更大的**擦除块**为单位擦除
- 一块由多个页构成；不同代际/型号页大小、块大小不同
- <img src="/images/408-mind-maps/co-0082.svg" alt="SSD控制器、FTL、芯片与页块结构" width="800" height="392">

## FTL：闪存翻译层
- 主机请求LBA → FTL映射到物理闪存页/块
- 更新逻辑地址往往**写入新物理页**并改写映射，旧页标记失效
- 不能对已写NAND页随意原位反复覆盖，通常需以块为单位先擦除
- <img src="/images/408-mind-maps/os-05-ssd-ftl-clean.svg" alt="SSD逻辑页更新、新物理页写入及垃圾回收示意" width="920" height="375">

## 读写与擦除流程
- 读：按照映射定位数据页，交由控制器返回主机
- 写：将数据编程到可用物理页，再更新映射关系
- 垃圾回收：复制仍有效页 → 擦除可回收块 → 重新投入空闲块池
- **写放大**：物理NAND写入量通常大于主机写入量，垃圾回收会增加额外写入

## HDD/SSD关键区别
- HDD：寻道+旋转延迟是随机访问开销核心
- SSD：没有机械寻道；延迟与闪存读写、映射、垃圾回收和控制器队列有关
- SATA/NVMe是主机接口/协议栈特征，不是NAND页/擦除块内部单位
