# 5.12 设备分配策略、独占/共享与LUT

## 设备使用方式
- 独占设备：同一时刻只服务一个使用者；经典例子为物理打印机
- 共享设备：请求可按队列交替服务多个进程；经典例子为磁盘
- 虚拟设备：由SPOOLing等方式使多个进程看来“各有一个设备”
- **共享磁盘**不代表单磁头能真正同时服务两个扇区；是并发请求与分时完成

## 静态与动态分配
- **静态分配**：作业运行前一次取得所需独占资源，按教材模型避免运行中申请造成的某些死锁
- **动态分配**：执行中按需申请，更灵活但可能发生循环等待
- 静态分配是否绝对无死锁依资源模型；考试通常讨论设备一次性整体分配
- 设备请求可使用先来先服务、优先级等策略；需兼顾公平性

## 逻辑设备名与LUT
- **LUT**（Logical Unit Table / 逻辑设备表）：维护逻辑名 → 具体物理设备、驱动等的绑定
- 优点：I/O重定位、分配灵活、提高设备无关性
- 同一逻辑名在不同进程/用户命名空间中可以有不同映射
- 不能一概断言“每个进程PCB中都有独立LUT”；属于特定教材实现方案

## 常考分析
- 用户请求逻辑“打印机” → 系统选定可用物理打印设备 → 查驱动 → 占用资源
- 用户若固定指定物理设备号，则系统可选择范围缩小
- 一个进程使用磁盘时，其它进程可排队；硬件调度与进程互斥锁不可混淆
