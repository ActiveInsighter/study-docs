# 5.17 SCAN、LOOK与循环扫描

## SCAN（电梯算法）
- 沿**既定方向**逐个处理请求，继续移动到该方向的**磁盘物理端点**后反向
- 从磁道53向增大方向出发：先 `65→67→98→122→124→183`，后逆向处理 `37→14`
- 若物理柱面编号0至199，SCAN会先抵达`199`再回扫
- 题目若把“到最远请求即折返”称SCAN，应按其显式定义处理；严格区分LOOK

## LOOK
- 方向相同，但**到本方向最后一个待服务请求**就反向，不必到物理端点
- 上例：`53→65→67→98→122→124→183→37→14`
- 因而与SCAN在服务顺序上可相同，**磁头移动总量不同**

## C-SCAN（循环扫描）
- 仅在一个方向服务：扫到物理端点 → 快速回到另一物理端点 → 同方向继续
- 回程**不服务**，但机械磁头移动距离通常仍应计入总移动量
- 极端处等待更均匀，但回程增加额外移动

## C-LOOK
- 只到本方向最远请求，再跳回**另一侧最远请求**，仍同方向处理
- 上例上行服务至183 → 跳回14 → 继续服务37
- 不要求经过磁盘物理两端；跨越路径的距离如何计，由题干对回程的计时定义决定

## 务必单独记住
- **SCAN≠LOOK，C-SCAN≠C-LOOK**；“若无说明默认LOOK”不是可靠通则
- 考试若没给初始移动方向，某些算法不能唯一决定完整路径
- 扫描可能造成“磁臂黏着”——磁头附近不断插入请求导致偏向局部，具体依调度模型
