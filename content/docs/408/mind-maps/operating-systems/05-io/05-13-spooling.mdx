# 5.13 SPOOLing假脱机与虚拟打印机

## SPOOLing是什么
- **Simultaneous Peripheral Operations On-Line**：在联机环境模拟脱机输入/输出
- 将独占慢速设备请求先保存在**磁盘输入井/输出井**，再由后台进程逐项服务
- 用户快速提交打印作业，不必等待纸张全部打印完才返回
- 表现操作系统的**虚拟性与共享性**，不是硬件设备突然变多

- <img src="/images/408-mind-maps/os-0115.svg" alt="脱机输入 / 输出技术：在外围控制机控制下用磁带缓解速度矛盾" width="760" height="280">

## 经典组成
- 磁盘：输入井、输出井（存放待处理数据/作业）
- 内存：输入/输出缓冲，维护作业控制块及请求队列
- 输入进程与输出进程：模拟旧式外围控制机的相关功能
- <img src="/images/408-mind-maps/os-05-spooling-clean.svg" alt="SPOOLing输入输出井、请求队列和打印机工作流程" width="900" height="366">

## 以打印机为例
- 用户进程提交打印请求、生成作业数据与请求信息
- 输出进程将作业放入**输出井**并登记等待队列
- 打印机空闲后，后台守护进程按调度策略取下一个作业并实际打印
- 真正打印完成后再更新作业状态/通知用户

## 与普通缓冲区的本质区别
- buffer：主存或硬件内的临时区，主要匹配速度与数据粒度
- SPOOLing：**磁盘驻留作业队列+后台服务机制**，把独占设备逻辑共享
- SPOOLing不要求一台**专门的物理外围控制机**；软件进程即可模拟
- 也不是普通“消息队列+异步回调”就能完整覆盖设备虚拟化含义
