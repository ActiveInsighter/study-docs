# 5.16 磁盘调度：FCFS与SSTF

## 调度目标
- 对HDD，减少磁头总移动距离通常能改善寻道开销
- **平均寻道长度**：总移动磁道数 / 服务请求个数
- 仅用磁道数近似时间时，题目默认相邻磁道移动成本相等；真实设备非严格线性
- 初始磁头位置、队列到达情况与初始方向必须先读题

## FCFS先来先服务
- 请求先到先服务，保持入队顺序
- 简单、可理解、公平，但磁头可能来回大幅跳跃
- 所有请求预先到达时，直接按给定序列累加邻项差值

## SSTF最短寻道时间优先
- 每次选**当前磁头位置距离最近**的待处理磁道
- 贪心地降低当前移动量，整体距离通常较短，但不保证全局最优
- 持续新请求到来时，远端请求可能长期饥饿
- 等距出现时要明确题设的优先顺序，否则可有多个合法服务路径

## 统一算例（全部请求已到达）
- 初始磁道 `53`，队列 `[98,183,37,122,14,124,65,67]`
- FCFS：`53→98→183→37→122→14→124→65→67`
- SSTF：`53→65→67→37→14→98→122→124→183`
