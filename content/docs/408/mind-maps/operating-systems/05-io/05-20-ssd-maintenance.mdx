# 5.20 SSD磨损均衡、TRIM与性能因素

## 为什么需要磨损均衡
- 闪存擦除块可承受的编程/擦除次数有限，频繁擦写同一块易提前失效
- 控制器使写入和擦除分布更均匀，以改善整体耐久性
- **动态均衡**：优先使用写入更新活跃区域中擦除次数较少的空闲块
- **静态均衡**：必要时迁移很久不更新的冷数据，使冷块也参与均衡
- 静态通常覆盖更全面，但会增加数据迁移；不能一概说“静态效果总是更好”

## TRIM / Discard
- 文件删除后，操作系统可告知SSD哪些LBA不再需要旧数据
- FTL可据此减少未来垃圾回收时搬移无效数据
- TRIM不是“删除后马上擦净所有闪存物理单元”的保证
- 是否支持及其执行策略取决于主机系统、文件系统、控制器等

## 垃圾回收的权衡
- 触发垃圾回收会占用内部闪存带宽，可能出现写入延迟波动
- 预留空间、后台清理、多通道并行可降低其性能影响
- SSD并不是每写一页都立即“把整个块复制一遍再擦除”；常采用异地更新+延后回收

## 与操作系统章节的联系
- 文件删除 → 逻辑块释放，可能触发discards，但不必同步物理擦除
- 磁盘调度中的寻道/旋转公式主要用于HDD
- DMA可用于SSD或HDD的主存数据搬运，与闪存内部FTL是不同层次
