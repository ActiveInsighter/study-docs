# 4.8 混合索引：408高频计算题

## 教材模型与参数
- 设数据块大小 B、块号指针长度 a、**每索引块地址项数** `K=B/a`
- 文件inode地址表：D个直接项、1个一级间接、1个二级间接、1个三级间接
- 这个“D+1+1+1”只是常见**题设模型**，并非所有真实inode固定结构
- <img src="/images/408-mind-maps/os-04-mixed-index-clean.svg" alt="混合索引直接块、一级、二级和三级间接索引的容量层级" width="870" height="545">
- <img src="/images/408-mind-maps/os-0003.svg" alt="原始Unix风格inode混合索引结构示意" width="820" height="507">

## 数据容量公式
- 直接项最多定位 `D` 块
- 一级间接项最多定位 `K` 块
- 二级间接项最多定位 `K²` 块
- 三级间接项最多定位 `K³` 块
- **最大数据块数**：`D+K+K²+K³`
- **最大数据容量**：`(D+K+K²+K³)×B`
- **不要**把索引块容量当文件的有效数据容量，但计算实际磁盘占用需计入索引块

## 例：B=4KiB，指针4B，D=10
- `K=4096/4=1024`
- 直接项容量：`10×4KiB=40KiB`
- 一级间接数据：`1024×4KiB=4MiB`
- 二级间接数据：`1024²×4KiB=4GiB`
- 三级间接数据：`1024³×4KiB=4TiB`
- 因真实文件系统还有其它长度限制，上述是**纯指针模型理论最大容量**

## 从0开始的逻辑块号范围
- 直接范围：`0` 至 `D−1`
- 一级范围：`D` 至 `D+K−1`
- 二级范围：`D+K` 至 `D+K+K²−1`
- 三级范围：`D+K+K²` 至 `D+K+K²+K³−1`
- `D=10,K=1024` 时，第 `1034` 号逻辑块**首次落入二级间接**
- 第 `9` 号块直接寻址，`10` 号块一级，`1033` 号块一级，`1034` 号块二级

## I/O次数与索引块数
- 若inode/目录已在内存、索引与数据都不在缓存：直接块1次、一级2次、二级3次、三级4次
- 读文件内容≠访问文件夹；必须先确认题目“是否计inode读取、目录遍历、TLB/cache”
- 分配新增一块数据可能同时需要分配新的间接索引块
