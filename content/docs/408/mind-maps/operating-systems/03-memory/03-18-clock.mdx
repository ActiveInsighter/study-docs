# 3.18 CLOCK：用访问位近似 LRU

## 简单 CLOCK / Second-Chance
- 物理页框排成环，维护一个循环扫描指针
- 每个驻留页带**访问位 $R$**（引用后通常置1）
- 缺页需要淘汰时扫描：
  - 遇到 $R=0$：选为牺牲页
  - 遇到 $R=1$：清零 $R$，移向下一页，给一次“第二次机会”
- 访问位周期性被清零，因而可近似近期使用情况

## 改进 CLOCK（访问位 R + 修改位 M）
- 优先级按 $(R,M)$ 分类
  - $(0,0)$：最近未访问、未修改，**最优先淘汰**
  - $(0,1)$：最近未访问、已修改，可能需写回
  - $(1,0)$：最近访问、未修改
  - $(1,1)$：最近访问、已修改
- 教材常见实现：第一轮寻找 $(0,0)$，第二轮寻找 $(0,1)$ 并视规则清访问位，必要时重复
- **具体轮次/是否第一轮清R，依题设算法版本**，模拟前必须读准规则

## 访问位与存在位不能混
- **存在/驻留位 $P$**：页面在物理内存中否
- **访问位 $R$ 或 A**：近期是否访问
- **修改位 $M$**：与后备内容相比是否被写脏
- 原资料将“P”同时用于两种含义，考试须明确各字段语义

## 时钟题四步
- 列出所有页框当前页号及 $(R,M)$ 值、指针位置
- 按题给扫描规则访问，命中则更新对应访问位
- 缺页时选择牺牲页，写脏页所需的额外代价应单独考虑
- 更新新装页的状态和下一次扫描指针；不要凭“看起来最旧”跳跃扫描
