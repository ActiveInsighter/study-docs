# 3.1 内存管理：管理的究竟是什么

## 四项核心职责
- **分配与回收**：为进程及内核建立可用存储区、释放不再需要的资源
- **地址转换**：把程序生成的逻辑/虚拟地址映射到物理地址
- **保护**：按进程和访问权限限制非法读写、执行
- **逻辑扩充**：按需调入、页面置换，使进程地址空间不必全部常驻物理内存
- 分清：管理**虚拟地址**、物理页框和后备存储的不同层次

## 地址空间的三个视角
- 逻辑地址：编译、链接产生的程序相对地址，具体模型依装入方式
- 虚拟地址：CPU执行时看到的地址，现代系统通常经 MMU 翻译
- 物理地址：主存总线和存储控制器最终定位的地址
- 两个进程即便出现相同虚拟地址数值，也**可能映射不同物理页**
- `MMU`是**硬件地址变换部件**；OS通过页表等配置其映射，并非“一段软件程序”

## 进程典型虚拟内存映像
- 代码/只读常量：`.text`、`.rodata`，可按权限共享物理页
- 已初始化数据 `.data`、未初始化数据 `.bss`
- 堆：动态分配对象；线程栈：保存调用帧、局部变量与返回地址
- 共享库、内存映射区域及栈与堆之间的未映射空洞
- PCB 属于**内核管理对象**，并非每个程序用户地址空间中的一个普通数据段
