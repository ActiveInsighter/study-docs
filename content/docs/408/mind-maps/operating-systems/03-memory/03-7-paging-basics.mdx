# 3.7 基本分页：地址被拆成两段

## 页与页框的角色
- 进程逻辑地址空间按固定大小划为**页（Page）**
- 物理内存按同样大小划为**页框/页帧（Frame）**
- 每页可装入任意空闲页框；逻辑相邻页的物理页框**不必相邻**
- 页内偏移保持不变，改变的是页号→物理页框号的映射
- <img src="/images/408-mind-maps/os-0017.svg" alt="进程逻辑页到不连续物理页框映射" width="700" height="550">

## 地址位数与页号公式
- 按字节编址，页大小 $S=2^k$ B，则**页内偏移**占 $k$ 位
- $n$ 位逻辑地址：页号占 $n-k$ 位，理论页数为 $2^{n-k}$
- 对逻辑地址 $A$：页号 $p=\lfloor A/S\rfloor$，偏移 $w=A\bmod S$
- 物理页框号 $b$ 已知后：物理地址 $E=bS+w$
- 例：32位虚拟地址、4KiB页 → 页号20位、偏移12位

## 页表项与存储空间
- 单级页表通常按页号索引页表项，页号**不必每项显式保存**
- 常见 PTE 字段：物理页框号、有效位、访问位、修改位、权限位等
- **先确认题设**是仅存页框号，还是含状态位、对齐和控制信息
- 例：32位虚拟地址、4KiB页、PTE 4B → $2^{20}$ 项，单进程满页表约4MiB
- 物理内存4GiB、页框4KiB → 页框数 $2^{20}$，页框号至少20 bit

## 408提醒
- 页表是进程地址空间的一种映射结构，通常本身也占主存空间
- PTE 的实际字节数并不总等于“页框号bit数向上取整到字节”
- **物理页框号**与**页内偏移**不能颠倒或做算术相加得错位结果
