# 1.10 从源代码到内存中的进程

## 构建流水线
- 源代码 → **预处理**（宏、头文件文本包含）→ **编译**（中间代码/汇编）→ **汇编**（目标文件）→ **链接**（可执行文件或共享对象）
- 预处理头文件发生在**构建阶段**，程序运行`printf`并不会每次重新读取`stdio.h`
- 目标文件可包含符号表与重定位信息；链接器解析外部符号并安排代码、数据节布局

## 静态与动态链接
- **静态链接**：所需目标代码在生成可执行文件时被链接进结果，通常体积大、部署依赖少
- **动态链接**：共享库可在装入时或运行时装载与解析，代码段可在多个进程之间共享
- “动态链接=程序执行到某函数时才第一次加载库”不成立：存在**装入时动态链接**与**运行时动态链接**
- 动态链接可能涉及PLT/GOT等间接访问，具体取决于系统和平台

## 程序装入与重定位
- **绝对装入**：已知固定物理起址；地址约定简单、灵活性差
- **静态重定位**：装入时一次性修改地址引用，执行期间通常不能直接自由移动
- **动态重定位**：运行时地址转换（例如MMU），允许使用逻辑/虚拟地址，不要求每次执行前重写全部地址
- **链接重定位**与**装入重定位**不是同一步骤：前者解决符号布局，后者处理装入位置和执行地址映射

## OS实际参与何处
- 创建进程 → 建立地址空间和页表 → 映射可执行映像、共享库、栈等 → 安排入口状态 → 调度执行
- 具体装载常由内核与用户态动态链接器协同完成
- **重点**：程序文件是静态磁盘内容；进程是运行期的资源与执行状态集合
