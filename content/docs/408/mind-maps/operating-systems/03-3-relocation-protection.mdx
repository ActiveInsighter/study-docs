# 3.3 内存保护：合法地址也不一定有权限

## 连续空间下的基址—界限机制
- 假设逻辑偏移为 $A$，界限为 $L$，物理基址为 $B$
  - 合法条件：$0\le A<L$
  - 合法时物理地址：$E=B+A$
- **基址寄存器**决定映射起点；**界限寄存器**决定允许的逻辑偏移范围
- 每次访存检查边界；越界触发保护异常，不是普通“缺页后换入”
- 上下限寄存器也可以直接检查物理绝对地址的区间，判题先看定义

## 页式系统里的保护
- PTE 可以包含：存在/有效、只读/可写、用户/内核、不可执行等权限位
- 地址已映射**不意味着**当前操作可写或可执行
- 页表修改、切换地址空间以及与TLB一致性维护应由受控内核机制执行
- 同一物理页可映射到不同进程虚拟地址，但权限可不同

## 程序段共享与可重入
- 可重入/不可变的代码可被多个执行流安全复用；可写的进程私有状态应与代码分离
- 动态库的共享只读代码页通常可减少物理内存消耗
- 重入性不等于“整个程序没有任何共享可写变量”，也不等于线程同步已被解决

## 判断题
- 两个程序访问相同虚拟地址，就一定访问同一物理单元？**错**
- TLB记录了某映射，用户程序就能随意修改PTE？**错**
- 越界、权限异常、缺页不驻留是不同故障原因，处理方式不同
