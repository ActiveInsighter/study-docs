# 2.8 调度量化：周转、等待、响应时间

## 五种时间与基本公式
- 进程到达时刻 $A_i$，首次执行时刻 $S_i$，完成时刻 $C_i$
- 实际CPU服务时间 $B_i$：本题给定的CPU总运行时长
- **周转时间**：$T_i=C_i-A_i$
- **等待时间**（无I/O，且所有未运行时间均在就绪队列）：$W_i=T_i-B_i$
  - 有I/O阻塞时，$T-B$还包含阻塞等待，不全是“等待CPU”的时间
- **响应时间**：$R_i=S_i-A_i$，只看**首次被调度**
- **带权周转时间**：$T_i/B_i$，最小为1；平均应先逐个算后求均值

## 常见效率指标
- CPU利用率：CPU有效忙于任务时间 / 总观察时间（明确是否把OS开销计入）
- 吞吐量：单位时间完成的作业数
- 公平性/饥饿：某些作业等待是否无上界
- 响应与吞吐、平均等待与实时截止期经常存在取舍

## 例题：SRTF 最短剩余时间优先
- 进程 A：到达0，CPU需5；B：到达1，需3；C：到达2，需1
- SRTF甘特：A[0,1) → B[1,2) → C[2,3) → B[3,5) → A[5,9)
- <img src="/images/408-mind-maps/os-02-srtf-gantt-clean.svg" alt="A、B、C在SRTF下的甘特图与完成时刻" width="760" height="300">
- 完成：$C_A=9, C_B=5, C_C=3$
  - 周转：A=9、B=4、C=1，平均 $14/3$
  - 等待：A=4、B=1、C=0，平均 $5/3$
  - 响应：A=0、B=0、C=0

## 审题顺序与边界
- 先标明抢占/非抢占、同一时刻到达和时间片结束的裁决规则
- 将所有到达、抢占、恢复、完成画在**同一时间轴**
- 平均带权周转时间 $\neq$ 平均周转时间 / 平均服务时间
