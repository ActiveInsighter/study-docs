# 5.7 高速缓存、缓冲与预读延迟写

## 缓冲区（buffer）强调传输过程
- 用于平衡CPU与I/O速度、调整传输粒度、减少中断频度、支持并行
- 数据可先存缓冲区等待消费或写出，**不要求别处必有完整副本**
- 常由主存分配；硬件控制器内也可设置FIFO/缓冲存储
- 常见：键盘输入队列、网卡收发环、打印作业、磁盘I/O

## 高速缓存（cache）强调复用命中
- 将近期/热点数据保留在较快层，减少再次访问慢速设备
- 磁盘页缓存可容纳**干净页**（与后端一致）及**脏页**（写回前不同步）
- 缓存并不满足“高速缓存中所有数据已经在磁盘上有同样副本”的绝对命题
- 内存页缓存、CPU缓存和设备控制器缓存处于不同层次，不能混为同一硬件

## 预读、延迟写与持久化
- **预读**：观察到连续访问后预先取后续块；可能命中也可能浪费带宽
- **延迟写**：先修改缓存/缓冲，合并写回；提高效率但存在断电丢失风险
- 写调用返回不必等于磁盘介质永久完成写入；需根据持久化模型判断
- 高速缓存使随机读在命中时更快，但冷数据仍受设备时延制约

## 缓冲的三个能力
- 速度匹配：高速处理与慢速设备解耦
- 粒度匹配：字节流与磁盘块/网络帧等交换单元协调
- 并发重叠：设备输入与CPU分析流水化
- **不要**把cache与buffer一律解释为“设备必须先经过buffer，不能直接访问慢速设备”
