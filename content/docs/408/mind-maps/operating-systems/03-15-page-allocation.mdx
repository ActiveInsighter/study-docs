# 3.15 页面分配策略：给谁多少页框

## 驻留集与两种分配
- **驻留集**：某时刻进程在物理内存中已驻留页面的集合
- 固定分配：为进程设定固定页框数，在其生命周期某阶段保持不变
- 可变分配：可按缺页率、内存负载等调整驻留页框数
- 注意“驻留集大小”是页框/页数量，不是“连续空闲地址区大小”

## 局部与全局页面置换
- **局部置换**：从当前进程的已驻留页面中选择牺牲页
- **全局置换**：可从系统允许的其他进程页或更广的页框集合中回收
- 经典教材三组合
  - 固定分配 + 局部置换
  - 可变分配 + 全局置换
  - 可变分配 + 局部置换
- 固定分配 + 全局置换通常不作为经典稳定组合，原因在于全局替换可能改变其他进程驻留集
- 不能说“局部置换OS不干预”：页面分配与置换本身就是OS策略

## 页面调入时机
- **请求调页**：访问缺页后再从后备存储调入
- **预调页**：在访问前根据空间局部性/预测提前调入若干页
- 预调页并非成功率必然不高，适用于顺序访问等可预测模式
- 预调过多会浪费带宽和页框，导致真正热页被挤出

## 页面从哪里来
- 文件后备页：可执行程序/内存映射文件通常可从文件重新读取
- 匿名脏页：可能需存放于交换区；匿名零页可按需产生
- 经典教材把外存分为**文件区和对换区**，便于分析不同页面的调入调出
- 现代系统具体实现有文件页缓存、写回、交换设备等，不能机械认定“UNIX首次一律文件区、以后必交换区”
