# 1.1 操作系统是什么：三重角色

## 定义与层次
- **操作系统 OS**：控制和管理计算机软硬件资源，合理组织工作，为用户与程序提供服务接口的**系统软件**
- 分层视角：硬件 → 操作系统内核/系统服务 → 应用程序 → 用户
- **裸机**：没有操作系统等系统软件支持的硬件；**扩充机器**：借助系统软件提供更易用的抽象
- OS管理的核心是**共享资源的分配、复用、隔离与保护**，不是替应用直接完成全部业务逻辑

## 作为资源管理者
- **处理机管理**：进程/线程、调度、同步互斥、死锁处理
- **存储器管理**：地址转换、分配回收、保护、虚拟内存
- **文件管理**：命名、目录、逻辑/物理组织、存取与权限
- **设备管理**：驱动、I/O控制、缓冲、设备分配
- 资源有互斥性与共享性：调度负责**谁用、何时用、用多久**，保护负责**允许用什么**

## 面向用户与程序的接口
- **命令接口**：联机交互（命令解释器/Shell）、脱机作业控制（批处理）
- **程序接口**：**系统调用**，在用户程序与内核功能之间建立受控入口
- **GUI**：图形用户界面；它是人机交互方式，**不等同于系统调用 API**
- C库函数 ≠ 系统调用：`printf` 通常在用户态运行，必要时才通过 `write` 等陷入内核
- Shell、桌面环境多数作为普通用户态程序运行；“由OS提供”**不推出**“必须在内核态”

## 以打开文件为例
- 应用调用 `open/read` 等接口 → 经过库封装与系统调用入口 → 内核验证参数、权限 → 文件系统/驱动处理 → 返回结果
- 核心：应用**提出请求**，内核**决定与执行受保护的资源操作**
- **考点判断**：OS是系统软件；GUI是用户接口；程序接口是系统调用；设备驱动通常由操作系统管理
