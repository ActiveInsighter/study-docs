# 1.16 本章综合题与答题清单

## 例题A：事件分类
- A正在用户态计算，定时器到期 → **外部中断** → 进入中断处理入口
- A读一块未驻留RAM但合法映射的虚拟页 → **缺页异常** → 调页后可重试原指令
- A执行`syscall`请求打开文件 → **同步自陷** → 内核服务 → 返回或阻塞
- A访问根本无权限的页 → **保护异常**；不保证可恢复
- 查找TLB未命中而页表有效 → **TLB miss**，不应直接等同磁盘缺页

## 例题B：`read` + I/O + 调度完整流程
- ① A在用户态准备参数并发起`read`，**模式切换**进入内核
- ② 内核校验参数并判断数据未就绪，提交I/O，把A从运行态转为阻塞态
- ③ 调度B运行，此时发生**进程上下文切换**
- ④ 设备完成后触发外部中断；ISR使A转为**就绪态**
- ⑤ 由调度策略决定何时重新选择A；A恢复时**系统调用返回值**才呈现给用户程序
- **关键**：系统调用、外中断、模式切换、进程切换、阻塞、唤醒是不同概念

## 例题C：三类判断题
- “I/O指令若是特权指令，用户进程就不能进行I/O”→ **错**；可通过系统调用委托内核
- “微内核把文件服务器移到用户态，因而所有文件访问都不用进入内核”→ **错**；服务通信和保护机制仍需受控路径
- “启动引导程序一定来自MBR”→ **错**；UEFI可直接从ESP加载EFI程序
- “Windows上的所有调用都要转内核”→ **错**；普通库函数、用户态计算不需要

## 例题D：性能与安全权衡
- 提高多道程序度，可能提高CPU利用率，也可能由于内存抖动反降性能
- 微内核的IPC可增加路径成本，但隔离用户态服务可改善故障恢复性
- 裸机型/宿主型虚拟化差别在**层次与控制路径**，不能仅凭“是否有图形桌面”判断

## 必背三句话
- **并发不是并行；共享不代表独占设备可以物理同时使用**
- **模式切换 ≠ 上下文切换；系统调用不必然阻塞或发生I/O**
- **BIOS/MBR与UEFI/GPT是不同的典型启动路径**
