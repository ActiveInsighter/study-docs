# 4.11 文件共享：两种链接不能混淆

## 硬链接 Hard link
- 新建目录项指向**已有文件inode**，文件内容不是复制一份
- 两个路径名地位平等：删除任一目录项不必影响剩余路径的正常使用
- 硬链接计数记录指向相应inode的目录项数（按典型UNIX语义）
- 常限制在同一文件系统内；对目录创建硬链接通常受限制
- <img src="/images/408-mind-maps/os-0067.svg" alt="多个硬链接目录项指向同一inode与数据块" width="830" height="403">

## 符号链接/软链接 Symlink
- 符号链接**本身是一个独立文件对象**，保存目标路径文本或等价目标描述
- 目标可跨文件系统，能指向目录；跟随时按路径解析
- 删除或改名目标后可能形成**悬空链接**；再次解析是否成功取决于目标路径当前状态
- 不应认为创建符号链接自动增加目标 inode 的硬链接计数
- <img src="/images/408-mind-maps/os-0133.svg" alt="符号链接有独立inode、保存到目标路径" width="820" height="420">

## 删除与占用
- 目标的硬链接数从2变1：仍有一个目录项可访问相同inode
- 硬链接数从1变0：如果**还有进程打开文件**，数据仍可由已有fd访问直到最后引用释放
- 删除指向目标的**软链接本身**：不应删除目标数据
- 删除目标：软链接仍可能存在，但访问时悬空

## 408思考题
- A、B是同一inode硬链接，修改A内容，读B能否看到？**能，观察到同一文件内容**
- C是指向A的软链接，删除C是否减少A的硬链接计数？**否**
- 创建硬链接能否任意跨不同文件系统？**通常不能**
