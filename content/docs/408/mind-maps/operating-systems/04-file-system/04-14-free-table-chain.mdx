# 4.14 空闲空间管理：表与链

## 为什么还要管理空闲块
- 文件分配方式告诉我们**一个文件的块怎样连接**
- 空闲空间管理告诉我们**哪些块尚未分配，如何快速分配和回收**
- 两者相互配合，不能把“FAT链接文件”与“空闲盘块链”混同

## 空闲表法
- 每条记录通常是 `(空闲区起始块号, 连续空闲块数)`
- 适合按**连续空闲区**寻找空间，首适应/最佳适应等可按题设操作
- 回收区域若与左右空闲区相邻，应合并区间，避免空闲表长期碎片化
- 存在空闲区A `[10,14]`、B `[20,23]`，回收块 `[15,19]` → 合并成 `[10,23]`
- <img src="/images/408-mind-maps/os-0066.svg" alt="空闲表组织多个可用的连续区" width="810" height="382">

## 空闲盘块链
- 每个空闲块（或其元数据）链接下一个空闲块；从头取块，回收时接回
- 适合离散块分配；分配多块可能沿链访问多个条目
- 指针维护/数据结构本身带来开销，链损坏会影响管理

## 空闲盘区链
- 按“空闲**连续区**”组成链，节点维护起点、大小与链接指针
- 可对各段采用首次/最佳适应等策略；回收时尝试与邻接空闲区合并
- 和空闲盘块链的区别在于链节点的**管理粒度**
- <img src="/images/408-mind-maps/os-0074.svg" alt="按空闲盘块或盘区建立链表的两种组织" width="820" height="424">

## 408考法
- 连续分配想找10块连续区：空闲块总量20块≠一定能满足
