# 4.12 文件保护：身份、权限与数据保密

## 访问控制模型
- 访问是否允许 = **进程当前有效身份/凭据 + 文件/目录访问规则 + 操作类型**
- owner、group、other 是类UNIX常见简化权限模型
- ACL（访问控制列表）可以列出更细粒度的用户/组及允许的权限
- 目录权限与普通文件权限语义不同，不能只看最终目标文件本身

## rwx权限含义
- 普通文件：`r`读取内容、`w`修改内容、`x`执行（还受格式与系统策略影响）
- 目录：`r`列出目录项名称、`w`修改目录项、`x`遍历或搜索目录路径
- 删除一个普通文件通常需要**父目录的相应写入和搜索权限**，不只是该文件的写权限
- 访问路径中的父目录若不可遍历，拥有目标文件读权限也未必能打开

## ACL、口令与加密
- ACL重点是对**访问主体**授予/拒绝操作权限
- 文件加密保护**静态数据机密性**，安全性取决于算法、密钥管理及使用方式
- 口令口令策略也需要加盐哈希/安全密钥派生，不能简化为“口令一定明文放内存”
- ACL与加密并非简单的“谁更安全”：控制目标不同，可联合使用

## 共享条件与特殊情况
- 文件所有者不是“创建者永远不变”，所有权可按系统策略改变
- 进程优先级影响调度，不直接授予文件权限
- 超级用户或特权进程可有特权操作，但也受具体安全策略/挂载参数限制
