# 3.13 虚拟内存：逻辑容量不是物理RAM容量

## 两个基础前提
- **局部性**：程序在一段时间内集中访问少量页面
  - 时间局部性：最近访问过的数据或指令容易再次访问
  - 空间局部性：附近地址容易陆续被访问
- **离散映射与缺页机制**：不是所有页面都要同时常驻主存
- 传统连续装入往往要求程序运行前驻留要求高；虚拟存储可按需调页

## 三个基本特征
- **多次性**：只装入必要页面便可启动执行，后续分批调入
- **对换性**：暂时不活跃的页面可离开内存，之后再调入
- **虚拟性**：每个进程可看到比当前驻留物理页更大的逻辑地址空间
- 实现常见为**请求分页**，也有请求分段与请求段页式的教材模型

## 容量的严谨说法
- $n$位按字节编址虚拟地址，理论可表示 $2^n$ B 的地址编号空间
- 单进程**实际可用**地址范围还受保留地址、指令集、OS策略与映射限制
- 可承诺的存储量还受物理内存、交换空间、文件后备页及资源策略约束
- 不能把“虚拟内存大小严格等于RAM+硬盘容量”当普适公式

## 优缺点与题型
- 好处：运行大于可驻留RAM的程序、提高并发度、强化隔离及映射管理
- 代价：页表和TLB管理开销、缺页时I/O延迟、极端情况下抖动
- “虚存让每次访问变慢”并不绝对：绝大部分访问可能不缺页
- “必须同时把进程所有页装入内存才能运行”与虚存设计目标相反
