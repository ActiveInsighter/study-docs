# 3.21 内存管理：408综合速查与自测

## 必会公式与限制条件
- 分页位数：页大小 $2^k$ B → 页内偏移 $k$ bit
- 逻辑地址：$A=p\times S+w$；物理地址：$E=b\times S+w$
- 单级页表大小（全量）：$页表项数\times每项字节数$
- 连续段保护：合法偏移 $0\le d<L_s$，物理地址 $B_s+d$
- 无TLB简化访存：1级表 → 2次；2级表 → 3次；n级表 → $n+1$次
- 串行TLB平均访问：$EAT=h(t+m)+(1-h)(t+2m)$（单级表、无缺页）

## 经典六问
- **问1**：地址 36 bit，页大小8KiB → 页内位数？**13**；页号位数？**23**
- **问2**：页大小4KiB，虚拟地址32 bit，PTE 4B → 全量一级页表大小？**4MiB**
- **问3**：段基址5000，段长256，偏移256 → 是否合法？**越界**
- **问4**：TLB未命中但PTE显示页面已驻留 → 是否缺页？**不是**
- **问5**：物理页框增加，FIFO缺页次数是否必降？**否，可能出现Belady异常**
- **问6**：COW中写进程获得私有页后，其他进程会直接看到写入？**通常不会**

## 高频易错清单
- 不能用“内存总容量－已用容量”直接定义**外部碎片**
- MMU为硬件部件，页表由OS维护，二者配合完成地址翻译
- 页表项中的页框号不等于页号；页表项不一定显式保存自己的页号
- 缺页异常、越界错误、权限错误须逐一判断
- CLOCK的 $R$ 是访问位，$M$ 是修改位，别与存在位混淆
- 工作集与驻留集没有无条件的固定不等式
- 经典固定分配局部置换、可变分配全局/局部置换，按题设定义判断

## 原始资料中已纠正的不准确表述
- “MMU是把虚拟地址转物理地址的程序” → **硬件地址变换部件**
- “换出死锁进程非常好，能解决问题” → **死锁等待不会因换页自动消失**
- “动态分区首次适应永远最好” → **性能依工作负载与碎片分布而变**
- “内部碎片 = 所有申请总量－使用量；外部碎片 = 内存总量－申请总量” → **按已分配单位内闲置和空闲洞分散性区分**
- “驻留集大小必大于工作集” → **不是理论上恒成立的关系**
- “CLOCK的P是访问位” → **标记需与页驻留位分开定义**
