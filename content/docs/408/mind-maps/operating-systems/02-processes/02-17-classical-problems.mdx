# 2.17 经典同步：哲学家、吸烟者、前驱图

## 五位哲学家
- 每位哲学家吃饭必须同时持有左、右两根筷子
- 每根筷子是二值信号量，初始值1
- **错误**：所有人先拿左筷子再拿右筷子 → 每人持一根互相等待可死锁
- **方案A**：另设`room=4`，最多4个人同时尝试拿两根筷子
  - `P(room); P(left); P(right); eat; V(right); V(left); V(room)`
- **方案B**：由互斥保护“一次取两根”的动作；不允许持一根继续等另一根
- **方案C**：指定全局筷子编号，全部按统一顺序申请 → 破坏环路

## 关键边界
- `room=4`防止**五人全部各持一根**的环形死锁；并不能自动保证绝不饥饿
- 方案B若持全局锁并阻塞等待单根筷子，虽然避免两人取筷交叉，可能降低并发度
- 不是“最多4人同时进餐”：最多只有相邻筷子不冲突的若干人能真正吃饭

## 吸烟者问题
- 三人分别自带烟草/纸/胶水；供应者每次放**另外两种材料**
- 信号量 `offer_tp`、`offer_tg`、`offer_pg` 都为0；`finish=0`
- 放烟草+纸 → `V(offer_tp)` → 自带胶水者消费 → `V(finish)`
- 放烟草+胶水 → `V(offer_tg)` → 自带纸者消费 → `V(finish)`
- 放纸+胶水 → `V(offer_pg)` → 自带烟草者消费 → `V(finish)`
- 供应者在每轮尾`P(finish)`，**必须等当前轮消费完成后再放下一轮**

## 201x式大题抽象方法
- 列出**共享资源**与初值；找互斥（同时不能）和同步（先后必须）
- 一次操作要持有多个资源：审查拿取顺序和环路
- 多步操作要求原子性：考虑复合许可/批处理而不只是无锁`count++`
