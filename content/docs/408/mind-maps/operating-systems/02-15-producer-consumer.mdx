# 2.15 生产者—消费者：同步许可与互斥锁的次序

## 标准有界缓冲区
- 缓冲区容量`N`，初始为空
- 三个信号量：`empty=N`（空位）、`full=0`（产品）、`mutex=1`（互斥）
- **生产者**：生产产品 → `P(empty)` → `P(mutex)` → 放入 → `V(mutex)` → `V(full)`
- **消费者**：`P(full)` → `P(mutex)` → 取走 → `V(mutex)` → `V(empty)` → 消费
- <img src="/images/408-mind-maps/os-02-buffer-pv-clean.svg" alt="生产者消费者两个计数信号量和互斥信号量的关系" width="760" height="380">

## 初值与不变式
- `empty + full = N`（**稳定状态下**指可用的空格/满格许可，实际并发进行中还存在已保留未入队的许可）
- 一个缓冲区只允许一个线程更新队列头尾和槽位映射
- 不能把`P(mutex)`放在`P(empty)`之前：缓冲区满时会持锁等待空位，消费者进不来
- 不能把`P(mutex)`放在`P(full)`之前：缓冲区空时可能持锁阻止生产者
- 即使单个槽位由互斥保证，empty/full仍分别表达两个**不同的同步条件**

## 苹果橘子单盘子
- 桌面只有1个槽位；爸爸放苹果，妈妈放橘子，儿子吃橘子，女儿吃苹果
- 设 `plate=1`、`apple=0`、`orange=0`
- 爸爸：`P(plate) → 放苹果 → V(apple)`；妈妈类似对`orange`发信号
- 儿子：`P(orange) → 拿橘子 → V(plate)`；女儿类似对`apple`等待
- 为什么可省略额外mutex？容量1下由`plate`与特定水果许可保证放/取互斥

## 题型迁移
- 容量`N>1`：计数和队列头尾需额外的互斥保护
- “必须连续拿10件”的消费者：先确保单次拿取事件定义正确，再考虑如何保持批量原子性；不能只靠无锁计数器
- `V(full)`应发生在产品已真实进入缓冲区之后
