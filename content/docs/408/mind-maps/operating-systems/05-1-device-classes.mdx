# 5.1 I/O设备类别与应用接口

## 按交换方式分类
- **块设备**：以可寻址的数据块交换；典型为磁盘、SSD
  - 支持块号定位、随机读写；是否采用DMA由硬件与驱动决定
- **字符设备**：面向字节或字符流；典型为串口、键盘、打印机
  - 通常不可按固定块号随机访问；不等于“每次恰好1字节”
- 网络设备：通过网络接口队列、报文与协议栈交换数据；不宜简单归入传统块/字符二选一
- **分类依据不同**：字符/块是接口和访问特征，不是精确的速率等级

## 按用途与传输特征
- 人机交互设备：键盘、显示器、触摸屏、打印机
- 存储设备：HDD、SSD、光盘、磁带
- 网络通信设备：以太网卡、无线网卡等
- 低/中/高速按时代、接口与设备类型变化；原图固定为“几B/s～几MB/s”不具通用性
- 固态存储与机械硬盘随机访问特征差异显著，统一磁盘调度结论不能机械套用

## 应用程序看到的接口
- 字符流接口：读写字节、字符、终端控制等
- 块接口：按块访问底层设备；普通文件read/write提供更高层字节流抽象
- 网络接口：`socket`、`send`、`recv` 等
- 系统调用负责从用户态进入内核；库函数可能在用户态先做缓冲或格式化

## I/O调用的等待语义
- **阻塞I/O**：当前进程/线程在所需结果未就绪时等待，CPU可调度其他线程
- **非阻塞I/O**：若操作暂不可完成，可尽快返回，如 `EAGAIN`；不意味着设备不工作
- **异步I/O**：请求提交与完成通知/结果获取解耦；与阻塞/非阻塞维度相关但不完全等价
- **易错**：不应把“中断驱动”直接等同于“用户态异步I/O”
