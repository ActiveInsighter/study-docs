# 2.7 三级调度与调度时机

## 三级调度的对象
- **高级调度（作业调度）**：从后备作业集合选作业，为其创建/接纳进程并分配资源
  - 主要决定进入系统的作业；现代OS实现形态不一定与传统批处理完全相同
- **中级调度（内存调度）**：决定进程挂起/换入，调整驻留内存的进程集合
  - 不是简单把PCB整体换出；内核可能保留必要控制信息
- **低级调度（进程/线程调度）**：从就绪队列选择CPU运行主体
  - 发生最频繁；操作系统基本必备

## 何时可能调度
- 当前执行流主动阻塞、终止、调用`yield`
- 时间片到期、较高优先级线程就绪，可触发**抢占式**调度
- 中断/异常处理完成的合适位置，内核检查是否应切换任务
- 非抢占式调度：运行主体主动让出CPU或阻塞时才选新任务

## 不可简单切换的临界窗口
- 处理中断与持有**不可抢占内核锁**的关键路径通常不执行普通进程切换
- “进入内核态后绝对不能被抢占”错误：现代可抢占内核可以在安全点抢占
- 关中断的原子区内不应进行依赖可抢占时钟的调度；需尽快恢复中断
- **用户程序临界区**不自动禁止系统调度；调度与数据互斥由不同机制处理
