## 课本要求的基本操作函数

- StrAssign(&amp;T, chars): 赋值操作。把串T赋值为chars。
- StrCopy(&amp;T, S): 复制操作。由串S复制得到串T。
- StrEmpty(S): 判空操作。若S为空串，则返回TRUE，否则返回FALSE。
- StrLength(S): 求串长。返回串S的元素个数。
- ClearString(&amp;S): 清空操作。将S清为空串。
- DestroyString(&amp;S): 销毁串。将串S销毁 (回收存储空间) 。
- Concat(&amp;T, S1, S2): 串联接。用T返回由S1和S2联接而成的新串。
- SubString(&amp;Sub, S, pos, len): 求子串。用Sub返回串S的第pos个字符起长度为len的子串。
- Index(S, T): 定位操作。若主串S中存在与串T值相同的子串，则返回它在主串S中第一次出现的位置:否则函数值为0。
- StrCompare(S, T): 比较操作。若S&gt;T，则返回值&gt;0: 若S=T，则返回值=0: 若S&lt;T，则返回值&lt;0。

## KMP 可能的考法

- KMP求next数组
  - next\[1\]无脑写0
  - next\[2\]无脑写1
  - 考点：手写next数组<br>(不需要优化，左边只要<br>对得上就可以）

    - 练习：1. google
      - 011121
    - 练习：2. ababaa
      - 011234
    - 练习：3. aaaab
      - 01234
    - 做法：建议使用21年的做法，去看最长相同前后缀子串长度+1
  - 没考过：next数组的代码<br>/nextval数组

    - 代码实现next\[\]

      ```cpp
      // 求模式串 T 的 next 数组，串下标从 1 开始
      void get_next(SString T, int next[]) {
          int i = 1, j = 0;
          next[1] = 0;
          while (i < T.length) {
              if (j == 0 || T.ch[i] == T.ch[j]) {
                  ++i;
                  ++j;
                  // 匹配时将相等前后缀的长度增加 1
                  next[i] = j;
              } else {
                  // 否则令 j = next[j]，继续比较
                  j = next[j];
              }
          }
      }
      ```

      > 整理说明：原截图循环条件写为 L.length，但参数及串名为 T；整理为 T.length。原截图将“p_i=p_j”作为递推文字说明，保留其说明用途。

    - 如何求nextval数组：
      - 算出next数组，从左到右扫描next数组，去消除冗余项
      - 配图

        |序号 j|1|2|3|4|5|
        |---|---|---|---|---|---|
        |模式串|a|a|a|a|b|
        |next[j]|0|1|2|3|4|

      - 代码

        ```cpp
        // nextval 数组：先算出 next 数组，再令 nextval[1] = 0
        nextval[1] = 0;
        for (int j = 2; j <= T.length; j++) {
            if (T.ch[next[j]] == T.ch[j])
                nextval[j] = nextval[next[j]];
            else
                nextval[j] = next[j];
        }
        ```

        > 整理说明：原截图使用 j<T.length；结合上下文的 1 起始串下标，改为 j<=T.length，避免漏算最后一个 nextval 值。
