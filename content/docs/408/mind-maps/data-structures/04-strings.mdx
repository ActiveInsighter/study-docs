# 第四章 串 · 八节分层导览

## 4.1 串的基本概念
- [串、空串、子串与子序列](/docs/408/mind-maps/data-structures/04-1-concepts)
  - 串是**有限字符序列**，是特殊线性表
  - 子串连续；子序列不要求连续
  - 子串位置、字符位序常采用 **1 基**
- 考试：先统一 `S[1..n]` 或 `S[0..n-1]` 的约定

## 4.2 基本操作与串 ADT
- [赋值、复制、比较、连接、求子串、定位](/docs/408/mind-maps/data-structures/04-2-adt)
  - `StrAssign / StrCopy / StrEmpty / StrLength`
  - `Concat / SubString / Index / StrCompare`
  - 清空与销毁的**资源管理含义不同**
- 重点：`Index` 无匹配按教材可返回 0

## 4.3 串的存储结构
- [顺序串、动态分配与块链串](/docs/408/mind-maps/data-structures/04-3-storage)
  - 定长数组、堆分配、`'\0'` 结束符
  - 单字符链表与多字符结点块链
  - 长度单独记录 vs 查找结尾
- <img src="/images/408-mind-maps/ds-0202.svg" alt="四种串的顺序存储方式" width="500" height="263">

## 4.4 朴素模式匹配（BF）
- [主串与模式串的逐位匹配](/docs/408/mind-maps/data-structures/04-4-naive)
  - 失配后：主串起点右移一位、模式串回到首位
  - 最坏时间 **O(nm)**；成功时返回第一次匹配位置
  - 空模式串及未找到的处理需声明约定

## 4.5 next 数组从何而来
- [真前后缀、border 与 next 构造](/docs/408/mind-maps/data-structures/04-5-prefix-next)
  - 相等且**非完整串自身**的前缀与后缀
  - `next[1]=0`，`next[j]` 取决于 `P[1..j−1]`
  - 辨析 `next`、0 基 `lps`：并非同一个数组

## 4.6 KMP 完整匹配
- [匹配指针与失配状态转移](/docs/408/mind-maps/data-structures/04-6-kmp)
  - 失配时主串指针 i **不回退**
  - 模式串指针 j ← `next[j]`
  - 匹配总时间 **O(n+m)**，含预处理
- <img src="/images/408-mind-maps/ds-04-kmp-fallback.svg" alt="具体主串中 KMP 失配后保持主串指针不变并移动模式串" width="620" height="269">

## 4.7 nextval 优化
- [连续重复比较消除与下标版本](/docs/408/mind-maps/data-structures/04-7-nextval)
  - 若 `P[j]==P[next[j]]`，继续沿失配链跳转
  - 1 基 `nextval[1]=0`；`nextval` 不改变最终答案
  - 混用 `next`、`nextval`、`lps` 是高频错误
