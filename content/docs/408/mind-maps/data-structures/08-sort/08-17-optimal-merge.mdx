# 8.17 最佳归并树 · WPL 与虚段

## 为什么选最短归并段优先合并
- 不同初始段长度不同时，每段被读写的次数与其在归并树中的**叶深度**有关
- 设第 i 个初始归并段长度为 $w_i$、深度为 $\ell_i$，则
  - **带权路径长度** $WPL=\sum_i w_i\ell_i$
- 若每次归并完整读取并写出其全部记录，归并 I/O 量近似为 $2WPL$（按记录计）
- 每次取**k 个最小权值**的段合并，构建 k 叉哈夫曼型最佳归并树

## 二路归并示例
- 四段长度 `2, 3, 6, 9`
- 先合并 2+3→5；再 5+6→11；最后 9+11→20
- 归并内部结点总权值：$WPL=5+11+20=36$
- 每次完整读写约 2 倍：**72 次记录读写量**（不计生成初始段）
- 若错误地先合并 2+9 和 3+6，会得较大 WPL=40

## 严格 k 叉树的虚段补齐
- 严格 k 叉归并树：每个内部结点**恰有 k 个孩子**
- 叶子数为 r，内部结点数为 t 时：$r=(k-1)t+1$
- 不能整除时补充长度为0的**虚段**，使 $r+u-1$ 能被 $k-1$ 整除
- 最小需补：$u=((k-1)-((r-1)\bmod(k-1)))\bmod(k-1)$
- 例：112个初始段作11路归并
  - $(112-1)\bmod10=1$，故补$10-1=9$个零长度虚段
  - r=111 时无需补；r=122 时仍需补9个
- **整除时 u=0**，不能机械地按 `k−1−余数` 补满 k−1 个

## 三路归并示例与注意
- 初始权重为 `2,3,6,9`，k=3，补1个0权虚段
- 第一次合并 0+2+3=5；第二次合并 5+6+9=20
- $WPL=5+20=25$，归并读写量约50次记录读写
- 相同 k 下，要让**权重小的段通常处于更深的叶子**，而不是先合并最大段
