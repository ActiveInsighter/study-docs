# 8.6 快速排序 · 一次划分

## 划分不变式
- 从 $A[low]$ 选取枢轴 `pivot`（本页按教材挖坑法）
- 将当前区间调整成：枢轴左边元素 $\le pivot$，右边元素 $\ge pivot$
- 枢轴最后落在一个正确的**最终下标**，但两边内部**尚未有序**
- 继续分别处理 `[left,p-1]` 与 `[p+1,right]`
- <img src="/images/408-mind-maps/ds-0148.svg" alt="快速排序枢轴49，左右指针交替挖坑填数并递归" width="700" height="520">

## 挖坑法步骤
- 缓存左端 `pivot=A[left]`，设 `i=left, j=right`
- `i<j` 且 `A[j]>=pivot`：右指针左移，直到发现小于 pivot 的元素
- 将找到的元素放入左侧空位 `A[i]=A[j]`
- `i<j` 且 `A[i]<=pivot`：左指针右移，直到发现大于 pivot 的元素
- 将找到的元素放入右侧空位 `A[j]=A[i]`
- 重复直到 `i==j`，写回 `A[i]=pivot`，返回 i
- **两条内层 while 都必须先检查 `i<j`**，防止指针越界/越界搬移

## 一次划分模拟
- 原始 `[5, 2, 8, 4, 7, 1, 6]`，首元 pivot=5
- 右侧先找到 1，填左坑 → `[1, 2, 8, 4, 7, 1, 6]`（此时右侧成为坑）
- 左侧找到 8，填右坑 → `[1, 2, 8, 4, 7, 8, 6]`（此时左侧成为坑）
- 右侧继续找到 4，填左坑 → `[1, 2, 4, 4, 7, 8, 6]`
- 左侧指针从位置2继续右移，在位置3与右指针相遇（无需再搬移）
- 指针相遇并写回枢轴 → `[1, 2, 4, 5, 7, 8, 6]`
- 枢轴前面均不大于5，后面均不小于5；**尚未整体排好**

## 递归与重复关键字
- 递归终止：区间为空或仅有1个元素，即 `left>=right`
- 划分位置 p **不再加入递归子区间**，避免不终止
- 若分区内存在多个相等关键字，划分后的相等值可分布在两侧
- 该标准交换/挖坑算法**不稳定**：相等记录最终相对顺序可能变化
