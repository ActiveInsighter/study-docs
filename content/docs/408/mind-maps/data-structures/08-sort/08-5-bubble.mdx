# 8.5 冒泡排序 · 相邻交换

## 基本思想与两个方向
- 只比较**相邻元素**；升序时若前者 > 后者，则交换
- 从左向右扫描：一趟把**最大值推到最右端**
- 从右向左扫描：一趟把**最小值推到最左端**
- 两种方向都正确，但每趟确定位置不同；过程题必须看清代码
- <img src="/images/408-mind-maps/ds-0063.svg" alt="从右向左冒泡，每一趟在左端固定一个最小记录" width="600" height="392">

## 从右到左的伪代码
- 第 i 趟（i 从 0 开始），下标 0..i−1 已固定为较小记录
- 从 `j=n-1` 逐步减到 `i+1`
  - 若 `A[j-1]>A[j]` 则交换相邻二者，记 `changed=true`
- 若整趟一次都没交换，表已全局有序，可以立即退出
- 该版本**最小值**在本趟冒到 `A[i]`；把它解释成最大值确定在尾部是方向错误

## 复杂度与稳定性
- 有“无交换提前退出”检测：最好情况比较 $n-1$ 次，$\Theta(n)$
- 最坏（逆序）：比较 $n(n-1)/2$ 次，$\Theta(n^2)$
- 一般随机输入平均 $\Theta(n^2)$；辅助空间 $O(1)$
- **稳定**：相等关键字不交换，其相对顺序不变
- 没有提前退出机制的版本，即使已排序也执行 $\Theta(n^2)$ 次比较

## 典型辨析
- 与简单选择：两者最坏 $O(n^2)$，但冒泡交换可能多、标准选择的交换少
- 与直接插入：两者稳定、对基本有序表较友好；操作方式不同
- 链式实现可交换记录内容，也可调整相邻链接；需要维护前驱和头指针
