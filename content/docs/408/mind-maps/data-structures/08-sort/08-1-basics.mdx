# 8.1 排序概念 · 稳定性 · 比较下界

## 排序的对象和目标
- 输入 n 个记录，按给定**关键字**的非降序或非升序排列输出
- **记录**可能含关键字之外的数据，排序时应保持关键字与其他字段的关联
- **稳定排序**：若两条记录关键字相同，则它们在最终输出中的**相对次序**与输入相同
  - 如 `[(3,a),(1,x),(3,b)]` 升序后为 `[(1,x),(3,a),(3,b)]` 才体现稳定
  - **稳定性是排序算法/具体实现的性质**，并非“有相等值才可以排序”
- 升序稳定比较：相等时保留先出现的记录；降序同理
- 原地排序：除少量变量和调用栈之外无需与 n 同阶的辅助存储；“原地”不直接保证稳定

## 内部排序与外部排序
- 内部排序：排序数据能够驻留主存，主要关注比较、移动、时间和辅助空间
- 外部排序：数据无法全部放入内存，分批读入外存记录，**I/O 往往是主要代价**
- 外部常用归并范式：形成有序归并段 → 多路合并 → 得到全局有序文件
- 访问介质和缓存条件影响代价：理论比较次数不等于磁盘读写次数

## 基于比较的下界
- n 个**互不相同**的关键字有 n! 种输入排列
- 两两比较可建成二叉判定树；若最坏比较次数为 t，其叶子至多有 $2^t$ 个
- 因而 $2^t\ge n!$，最坏比较次数 $t\ge\lceil\log_2(n!)\rceil$
- 由 Stirling 估计，$\log_2(n!)=\Theta(n\log n)$
- 因此任何**只依赖关键字比较**的通用排序，在最坏情形都不能优于 $\Omega(n\log n)$
- 计数、桶、基数等利用关键字结构的排序**不受此比较模型的下界约束**

## 性能指标及易混点
- 时间比较：最好、平均、最坏需分别说明；“平均”一般还需输入分布假设
- 空间代价：区分辅助数组、临时变量、递归栈，外存算法另计缓冲区
- 交换次数不等于移动次数：一次交换常涉及数次赋值
- 不稳定不代表结果错：它只说明**相同关键字原次序可能改变**
