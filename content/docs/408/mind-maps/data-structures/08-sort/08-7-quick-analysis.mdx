# 8.7 快速排序 · 性能与退化

## 为什么平均快
- 每轮划分扫描当前区间：$\Theta(m)$，m 为区间长度
- 平衡划分时递推：$T(n)=2T(n/2)+\Theta(n)=\Theta(n\log n)$
- 最坏每次分出 0 和 n−1：$T(n)=T(n-1)+\Theta(n)=\Theta(n^2)$
- 典型随机排列 / 随机枢轴前提下：**期望** $\Theta(n\log n)$
- 不能断言“快速排序在所有输入上总是最快”

## 枢轴和输入分布
- 总选最左端作为枢轴：已升序/已降序输入容易划分极不平衡
- 大量相等关键字时，某些两路划分会持续产生极端不平衡分区
- 随机选枢轴或三数取中：减少常见退化风险，**不改变理论最坏 $O(n^2)$**
- 三路划分把区间拆成 `<pivot`、`=pivot`、`>pivot`
  - 尤其适合大量相等键；中间相等组不再递归

## 递归空间与工程改进
- 平均/平衡递归深度为 $\Theta(\log n)$，额外栈空间通常 $O(\log n)$
- 每次只缩小 1，朴素递归深度可到 $\Theta(n)$
- 优化：**总先递归较小区间、循环处理较大区间**，可把递归栈上界控制到 $O(\log n)$
- 很小的子区间改用插入排序，有机会降低常数开销
- 内省式排序在递归深度过大时切换为堆排序，可取得最坏 $O(n\log n)$ 上界

## 一趟 vs 整体性质
- 一趟划分后仅能确认枢轴的位置，左右内部顺序未必确定
- 使用“枢轴交换前后都可能跨越相等键”的实现，**不稳定**
- 快速排序常属于**内部、比较型、原地划分**排序；递归栈不等于 O(1)
- 与堆排序：快排平均常数往往较小，堆排最坏上界更稳
- 与归并排序：归并可稳定但典型数组版本要 $O(n)$ 辅助空间
