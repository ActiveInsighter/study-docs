# 8.11 归并排序 · 分治 + 合并

## 二路归并基本操作
- 前提：左右两段 $A[l\ldots m]$、$A[m+1\ldots r]$ 各自有序
- 双指针 i=l、j=m+1，依次取较小记录写入输出段
- 相等时**优先取左段的记录**，保证稳定
- 一段耗尽后直接顺序复制另一段剩余记录
- 合并时间 $\Theta(r-l+1)$，只扫描一次本次归并范围
- <img src="/images/408-mind-maps/ds-0215.svg" alt="归并排序的分解、局部有序段与回合归并" width="700" height="481">

## 自顶向下归并过程
- 如果区间长度≤1，直接返回
- 令 `mid=(left+right)//2`，递归排序左侧与右侧
- 最后用**辅助数组**合并两个已排好序的子区间
- 递推：$T(n)=2T(n/2)+\Theta(n)=\Theta(n\log n)$
- 标准实现每一层合并数据总量为 n，共 $\lceil\log_2 n\rceil$ 层

## 性质与资源
- 传统数组二路归并：最好/平均/最坏均为 $\Theta(n\log n)$
- 额外数组空间 $\Theta(n)$；递归栈 O(log n)，总辅助空间仍 $\Theta(n)$
- **稳定**的条件是相等时不先取右段；若反过来比较，稳定性会被破坏
- 对链表可通过修改链接归并，无需按记录个数分配辅助数组（递归栈另计）
- 外部排序可采用归并方案，但**不能仅凭内存二路归并就推断外部 I/O 量**

## 过程与边界示例
- 左段 `[(2,a),(4,b),(4,c)]`；右段 `[(1,d),(4,e)]`
- 合并后 `[(1,d),(2,a),(4,b),(4,c),(4,e)]`
- 原左段的两个 4 先于右段 4，符合稳定归并
- 标准二路归并中每次合并段长可按 1→2→4→8… 倍增
