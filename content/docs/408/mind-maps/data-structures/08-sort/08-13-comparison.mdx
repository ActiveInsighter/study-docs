# 8.13 内部排序 · 统一对照

## 插入与交换
- 直接插入：最好 $\Theta(n)$，平均/最坏 $\Theta(n^2)$；空间 O(1)；**稳定**
- 折半插入：比较 $\Theta(n\log n)$，移动最坏 $\Theta(n^2)$；最好总时间 $\Theta(n\log n)$；空间 O(1)；**稳定**（相等右插）
- 希尔排序：依增量而异、简单对半增量最坏可到 $\Theta(n^2)$；空间 O(1)；**不稳定**
- 冒泡（提前退出）：最好 $\Theta(n)$，平均/最坏 $\Theta(n^2)$；空间 O(1)；**稳定**
- 快速排序：最好/典型平均 $\Theta(n\log n)$、最坏 $\Theta(n^2)$；栈均衡 O(log n) / 朴素最坏 O(n)；**不稳定**

## 选择与归并
- 简单选择：最好/平均/最坏均 $\Theta(n^2)$；空间 O(1)；**不稳定**
- 堆排序：最好/平均/最坏均 $\Theta(n\log n)$；空间 O(1)；**不稳定**
- 二路归并：标准数组版各情形 $\Theta(n\log n)$；空间 $\Theta(n)$；**稳定**
- 基数：$\Theta(d(n+r))$；空间随桶实现 O(r) 或 O(n+r)；LSD 稳定分配时**稳定**
- **注意**：上述都是典型实现的复杂度，存在优化变体和不同计数模型

## 可用于算法选型的需求
- 数据**基本有序**且 n 不大 → 直接插入或带提前退出的冒泡
- 需要稳定且规模较大 → 归并；链表时可考虑指针归并
- 希望最坏 $O(n\log n)$ 且不占 n 级辅助空间 → 堆排序
- 平均性能良好、额外存储有限且可接受不稳定 → 快速排序（需警惕退化）
- 交换/移动十分昂贵 → 简单选择因交换次数少而可能合适
- 整数/固定长度键、位数和基数适中 → 基数排序可避免比较排序下界

## 408 题目最爱考的条件
- 稳定性需结合**标准实现的相等元素处理方式**判断
- “快速排序空间 O(log n)”只是通常的平衡/平均递归深度，**最坏仍可能 O(n)**
- “折半插入 O(n log n)”仅说明**定位比较次数**，不能推出整体时间
- “希尔 O(n^1.3)”不是对任意增量序列普适的时间上界
- “基数 O(r) 空间”是特定**链接桶**实现，不是所有基数排序
