# 8.8 简单选择排序 · 少交换

## 每一趟做什么
- 第 i 趟，从尚未排好的 $A[i\ldots n-1]$ 中找最小关键字下标 min
- 若 min≠i，则交换 $A[i]$ 和 $A[min]$
- 前 i+1 个位置成为升序中的固定前缀
- 不变式：每趟完成后，已排前缀是全表中最小的相应个数记录

## 伪代码与边界
- 对 i=0..n−2：令 `min=i`
- 对 j=i+1..n−1：若 `A[j]<A[min]`，更新 `min=j`
- 如 `min!=i`，交换 `A[i]` 与 `A[min]`
- 注意：只选出**最小关键字位置**，不能直接在候选区间每次遇到更小值就交换

## 复杂度
- 无论输入已有序还是逆序，都要比较 $(n-1)+(n-2)+\cdots+1=n(n-1)/2$ 次
- 最好/平均/最坏时间均为 $\Theta(n^2)$
- 最多 $n-1$ 次记录交换（若相同位置可跳过）；额外空间 $O(1)$
- 在记录很大、交换代价显著时，“交换次数少”可能有实用价值

## 不稳定性反例
- 输入：`[(2,a),(2,b),(1,c)]`
- 第一趟选到 `(1,c)`，和首元素 `(2,a)` 交换
- 结果：`[(1,c),(2,b),(2,a)]`
- 两个关键字为2的记录相对次序**由 a在b前变为b在a前**
- 因此**标准交换版不稳定**；特殊的稳定选择变体不是同一算法操作方式

## 相关题型
- 识别一趟排序结果：第 i 趟后**前 i 个位置固定**，并不是任意相邻元素有序
- 与冒泡排序：两者均 $\Theta(n^2)$，但“交换少/稳定”性质不同
- 与堆排序：堆将“每次选最值”从线性扫描降为对数时间维护
