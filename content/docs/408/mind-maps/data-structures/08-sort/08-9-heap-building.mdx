# 8.9 完全二叉树与建大根堆

## 堆的定义和顺序存储
- **大根堆**：每个非叶结点关键字 ≥ 所有直接孩子关键字，**根最大**
- **小根堆**：每个非叶结点关键字 ≤ 所有直接孩子关键字，根最小
- 堆是一棵**完全二叉树**，不是二叉搜索树；兄弟与两个子树之间无需有序
- 1基下标：父结点 $\lfloor i/2\rfloor$，孩子 $2i,2i+1$
- 0基下标：父结点 $\lfloor(i-1)/2\rfloor$，孩子 $2i+1,2i+2$
- 最后一个非叶结点：1基 $\lfloor n/2\rfloor$，0基 $\lfloor n/2\rfloor-1$

## 从下向上建堆
- 对 1基的 i=$\lfloor n/2\rfloor,\ldots,1$，依次做一次**向下调整**
- 假设两个孩子为根的子树已有序为堆（自底向上保证这一前提）
- 从当前结点保存临时值，在两个孩子中选择较大者
- 若临时值 ≥ 较大孩子则停止；否则让较大孩子**上移**，继续下滤到相应孩子位置
- 把临时值放入最终空位，形成以当前结点为根的大根堆

## 一次下滤与整体建堆
- 单次从树高 h 的结点下滤：最多 O(h)=$O(\log n)$ 层
- **整表自底向上建堆为 $\Theta(n)$，不是 $O(n\log n)$**
- 因为多数结点距离叶层很近：$\sum_{h\ge0}(n/2^{h+1})h=O(n)$
- 上述 O(n) 是总调整的量级，不表示所有元素只比较一次
- 建堆额外空间可为 $O(1)$（迭代下滤、原数组）

## 过程题与错误定位
- 自底向上建堆与逐个插入堆不同：中间状态和比较次数可能不同
- 选“大孩子”须确认 `right<=heapSize` 才允许比较右孩子
- 下滤时 `p` 必须更新为**被选中的较大孩子位置**，不是无条件乘2
- 根最大**不意味数组递减排列**；堆仅规定父子大小关系
