# 8.4 希尔排序 · 缩小增量

## 为什么能加速插入
- 直接插入遇到“距目标位置很远”的记录，可能需要大量相邻移动
- 希尔排序按增量 d 划分**相隔 d 个位置的子序列**，各自做插入排序
- 逐渐减小 d，最后必须取 d=1，才能确保全局有序
- 常见教材增量：$d=\lfloor n/2\rfloor,\lfloor d/2\rfloor,\dots,1$
- <img src="/images/408-mind-maps/ds-0175.svg" alt="希尔排序按 d=5、3、1 分组排序的演示" width="700" height="394">

## 一趟 d-排序
- 下标相差 d 的记录属于同一组，如 d=3 时：0,3,6…；1,4,7…；2,5,8…
- 在各组内部使用**直接插入**，使每组有序
- 后续更小的 d-排序在前面近似有序的基础上继续移动记录
- 仅当 d=1 的整数组插入排序结束，才确定最终顺序

## 常见代码关键点
- 外层遍历一组递减增量 `d`，直到 `d==1` 结束
- 当前 `i` 对应的先前同组记录在 `i-d`
- 若 `A[i]<A[i-d]`，缓存 `key=A[i]` 并令 `j=i-d`
- 当 `j>=0 && A[j]>key` 时，将 `A[j]` 写到 `A[j+d]`，再 `j-=d`
- 将 `key` 放到 `A[j+d]`

## 复杂度和性质
- **不稳定**：相等关键字可能在不同分组跨组越过彼此
- 辅助空间 $O(1)$（普通数组就地实现）
- **时间复杂度依增量序列和输入而变**，不可把 $O(n^{1.3})$ 当成无条件定理
- 简单“增量对半”序列的最坏时间可到 $\Theta(n^2)$；改进序列可获得更好界
- 典型实现需要随机访问，因此适合顺序表而非一般链表

## 408 过程题抓手
- 先把每个 d 组的下标完整列出来；不可把连续区间误当一组
- 每个组内执行**稳定插入**，但整个希尔过程仍可能不稳定
- 每趟 d 的结果是“各 d 间隔组有序”，**不代表全数组有序**
