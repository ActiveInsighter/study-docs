# 8.14 外部排序 · 初始段与多路归并

## 外存排序基本流程
- 内存容量不足以同时容纳全部待排记录，按块读取外存文件
- 先分批得到**初始有序归并段**，再把若干段按关键字合并为更长的段
- 每一趟合并 k 路通常读入旧段并写出新段
- 原始文件记录总数 N，若每趟完整读写且忽略边界效应：每趟约 **N 次读 + N 次写**

## 缓冲区与归并路数
- 二路归并最基本需要两个输入缓冲区和一个输出缓冲区
- k 路归并典型需要**k 个输入缓冲区与 1 个输出缓冲区**
- <img src="/images/408-mind-maps/ds-0220.svg" alt="二路归并使用两个输入缓冲区和一个输出缓冲区" width="600" height="265">
- <img src="/images/408-mind-maps/ds-0097.svg" alt="四路归并缓冲区及两层归并示意" width="700" height="321">
- 缓冲区大小、可打开的文件数和内存容量共同限制 k

## 归并趟数和 I/O
- 假设起初有 r 段、各轮均可做 k 路平衡归并，则归并趟数 $s=\lceil\log_k r\rceil$
- 当 r=1 时已是一段，无需归并趟；r>1 时 k 应≥2
- 多路数 k 越大，理论归并趟数通常**不增加**，但每次选最小记录所需比较及缓冲代价可能上升
- **提升 k 不必然减少总运行时间**：内存、文件句柄与 CPU 选择代价都是制约
- 置换选择产生更长初始段，可减小 r；败者树能加速 k 路的内部选择

## 块 I/O 与记录 I/O
- 上述 2N 是按**记录搬运量**估算；若每块容 B 个记录，约对应 $2\lceil N/B\rceil$ 个块传输（忽略零碎块）
- 若中间结果复用存储、最终输出无需落盘，实际物理 I/O 可不同
- 同一个算法的“比较次数”和“读写次数”是两类指标，不可混算
