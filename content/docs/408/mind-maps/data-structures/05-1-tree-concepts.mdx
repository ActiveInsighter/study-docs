# 5.1 树的定义 · 度、深度、高度

## 什么是树（Tree）
- 非空树是 n 个结点组成的有限集合，恰有**一个根结点**
- n>1 时，其余结点分为若干**互不相交的非空子树**
- 从图论看，底层无向图**连通且无环**；任意两结点间有唯一路径
- 层次关系中，除根以外，每个结点**恰好一个双亲**
- 空树是否允许，按具体 ADT 定义；很多教材允许 n=0 的空树

## 结点之间的亲属关系
- 直接上级 = 双亲（父结点）；直接下级 = 孩子（子结点）
- 具有同一双亲的结点互为**兄弟**
- 祖先/子孙是父子关系的传递闭包
  - 根是非根结点的祖先；叶子可以是某结点的子孙
  - “祖先”是否包含结点自身，需看题目约定；通常**不包含**
- 分支结点（内部结点）度 > 0；终端结点（叶子）度 = 0
- 森林：若干棵**互不相交**的树，允许零棵（空森林）

## 度与层次
- **结点的度** = 直接孩子数；**树的度** = 全树结点度的最大值
- 根所在层为第 1 层；其孩子在第 2 层，以此类推
- 根深度为 0（按**边数**计算），也有教材令根深度为 1
- 若根深度 0，则某结点“层号 = 深度 + 1”
- 本系列除另行声明外：**层号从 1 起，深度按边数从 0 起**

## 高度与路径
- 结点的**高度（按边数）**：到其最远叶子的路径长度；叶子为 0
- 树高度若按**层数**：为最大层号；与根的“边数高度”差 1
- 路径长度：沿边走的**边数**，不是经过的结点数
- 两结点间有唯一的无向路径；仅当目标是源结点的子孙时，才有向下的祖先到子孙路径
- 树的内部路径长度 IPL：各结点到根的距离之和
  - 同样结点数的二叉树，**完全二叉树**达到最小 IPL（但不一定唯一）

## 有序与无序
- **有序树**：每个结点孩子的左右次序有意义，不可任意交换
- **无序树**：交换同一结点的孩子次序不区分为不同树
- 二叉树左右孩子有区别：只有右孩子与只有左孩子是两种二叉树
- 不能从具体编程容器 (`vector`/链表) 直接判定逻辑上的有序性

## 高频判断
- “二叉树的度是 2”：错；是**至多 2**，实际可以是 0、1、2
- “树结点深度 = 树结点高度”：一般不成立；前者向根，后者向叶
- “树高度 h”先核对 **层数/边数** 及空树、叶子约定
- “树的路径从任意结点都能向下到另一个结点”：错，须满足祖先关系
