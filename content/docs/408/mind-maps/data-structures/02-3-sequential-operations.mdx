# 2.3 顺序表 · 基本操作与复杂度

## 第 i 位插入（原表长 n）
- 前提：$1\le i\le n+1$，且 `length < capacity`
- 从**后向前**移动：`for (j = length; j >= i; --j) data[j] = data[j-1]`
  - 再执行 `data[i-1] = e; ++length`
  - 从前向后移动会覆盖仍需搬动的元素
- 实际移动次数：$n-i+1$
- 最好：尾插 i=n+1 → 0 次移动，$\Theta(1)$（不计扩容）
- 最坏：表头插入 i=1 → n 次，$\Theta(n)$
- 等概率插入 n+1 个位置 → 平均 $n/2$ 次，$\Theta(n)$

## 第 i 位删除（原表长 n）
- 前提：$1\le i\le n$
- 先保存 `e = data[i-1]`
- 从**前向后**覆盖：`for (j = i; j < length; ++j) data[j-1] = data[j]`
  - 然后 `--length`
- 实际移动次数：$n-i$
- 最好：删除尾元素 → 0 次，$\Theta(1)$
- 最坏：删除首元素 → n−1 次，$\Theta(n)$
- 等概率删除 n 个位置 → 平均 $(n-1)/2$ 次，$\Theta(n)$
- 删除后剩余旧数据在无效槽位中，不再属于线性表

## 按位取值与按值查找
- `GetElem(L, i)`：先检验范围，直接取 `data[i-1]` → $\Theta(1)$
- `LocateElem(L, e)`：从前往后逐个比较
  - 最好首位命中：$\Theta(1)$
  - 最坏未找到或末位命中：$\Theta(n)$
  - 在**保证命中且每个位置等概率**时，平均比较 $(n+1)/2$ 次
- 有序顺序表能二分查找：比较次数 $\Theta(\log n)$
- 有序并不使“任意位置插入”自动成为 O(log n)：元素移动仍 O(n)

## 典型例题：删除值为 x 的所有元素
- 不保持顺序：可将末元素覆盖被删元素，但可能改变相对次序
- 保持相对顺序：设置读指针 `read`、写指针 `write`
  - `read` 遍历旧数组；保留元素写入 `data[write++]`
  - 最后 `length = write`
- $\Theta(n)$ 时间，$\Theta(1)$ 额外空间，稳定保序
- 不能“正序删除后无条件下标加 1”——会跳过连续目标值

## 典型例题：有序表去重
- 维护 `write` 指向已去重结果的下一个位置
- 仅当当前元素不等于最后一个保留元素时复制
- 已排序是关键前提；未排序表不能只比较相邻元素
- 复杂度：时间 $\Theta(n)$，额外空间 $\Theta(1)$

## 典型例题：合并两个有序表
- 双指针 `i`、`j` 从两个表头开始
- 依次取较小元素写入结果，最后接上剩余部分
- 若长度分别 m、n：时间 $\Theta(m+n)$
- 新数组存储结果：额外空间 $\Theta(m+n)$
- 注意：链表归并可以通过重接链结点，额外辅助空间可为 O(1)

## 复杂度速查
- 按位访问：$\Theta(1)$
- 按值查找：无序最坏 $\Theta(n)$；有序二分 $\Theta(\log n)$
- 表头插入／删除：$\Theta(n)$
- 表尾删除：$\Theta(1)$
- 表尾插入：未扩容 $\Theta(1)$；倍增扩容的均摊 $O(1)$
