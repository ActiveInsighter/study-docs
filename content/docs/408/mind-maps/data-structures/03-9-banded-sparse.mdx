# 3.9 特殊矩阵 · 三对角与稀疏矩阵

## 三对角矩阵的结构
- n 阶三对角矩阵：只有主对角线及其上下各一条对角线可能非零
- 即 $|i-j|>1\Rightarrow a_{ij}=0$
- 第一行、最后一行各最多 2 个非零位置
- 中间 n−2 行各最多 3 个非零位置
- **压缩项总数**：$2+3(n-2)+2=3n-2$（$n\ge2$）
- 小例子 n=5：共有 13 个待存位置

## 三对角矩阵：按行压缩映射
- 将三条对角线按原矩阵的行主序依次存入一维数组 b
- 对于满足 $|i-j|\le1$ 的非零带位置
  - i、j 都从 **1** 开始，压缩数组 b 从 **0** 开始
  - **$k=2i+j-3$**，即 `b[k]=a[i][j]`
- 若 b 从 **1** 开始：$k=2i+j-2$
- 检验：$a_{11}\to b[0]$，$a_{12}\to b[1]$
- 检验：$a_{21}\to b[2]$，$a_{22}\to b[3]$
- 检验：$a_{nn}\to b[3n-3]$
- **不能**把 $|i-j|>1$ 的 0 元素塞入这个压缩数组

## 由压缩下标反推行列（进阶）
- 已知 b 的 0 基位置 k，$0\le k<3n-2$
- 行号（1 基）：$i=\left\lfloor\frac{k+1}{3}\right\rfloor+1$
- 列号（1 基）：$j=k-2i+3$
- 例 n=5、`k=10` → `i=4, j=5`，即 `a[4][5]`
- 检验反推位置是否满足 $|i-j|\le1$ 和范围 $1\le i,j\le n$

## 稀疏矩阵与三元组表
- 稀疏矩阵：非零元素占全部元素很小比例（无统一固定阈值）
- 每个非零元素保存三元组 `(row, col, value)`
- 通常另存行数、列数、非零元个数 `nnz`
- 若三元组以**行号优先、列号次之**排列，便于按行扫描
- 三元组表存储空间 O(nnz)，不包含所有 0 元素
- 随机访问某个 `a[i][j]` 通常需要搜索或另建索引，并非 O(1)
- 若同一坐标允许重复记录，必须规定如何合并；规范形式通常不重复

## 稀疏矩阵转置
- 朴素转置：对于每一原列号，扫描所有三元组寻找对应元素
  - 复杂度 O(cols × nnz)
- 快速转置：先统计各列非零元数量，再计算转置表各行起始位置
  - 最后按原三元组逐个填入输出位置
  - 时间 O(cols+nnz)，额外辅助计数空间 O(cols)（另需输出表）
- 转置时每个三元组 `(i,j,v)` 变为 `(j,i,v)`，同时须维持排序规则

## 十字链表（Orthogonal List）
- 结点含：行号 i、列号 j、值 val、行向指针 right、列向指针 down
- 每一行的非零元素沿 `right` 串联
- 每一列的非零元素沿 `down` 串联
- 额外维护行头指针数组、列头指针数组
- 空间 O(nnz+rows+cols)（常见实现）
- 优点：适合需沿行、列遍历和动态增删非零元的场景
- <img src="/images/408-mind-maps/ds-0041.svg" alt="稀疏矩阵十字链表的行、列双向索引示意" width="500" height="221">

## 总结与陷阱
- 三对角矩阵是**固定带宽结构**，不等同于任意稀疏矩阵
- $3n-2$ 是三对角可存的带状位置数，部分位置实际也可能为零
- 三元组适合节省空间，十字链表适合支持双维动态链接
- 压缩映射的 i、j 与 k 是否从 0 开始，必须先说明
