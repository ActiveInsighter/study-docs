# 7.1 查找概念 · 评价指标

## 查找与查找表
- **查找**：在数据集合里按指定条件定位元素或记录，通常按**关键字 key** 查找
- **查找表**：同类型记录的集合；记录由关键字及其他属性组成
- **关键字**：能够标识或区分记录的字段
  - 主关键字：在该表的记录中**唯一**，例如唯一学号
  - 次关键字：可能有多个记录取同一值，例如班级
  - **并非每个查找关键字都天然唯一**，重复关键字需定义返回第一条/全部等策略
- 静态查找表：主要执行查询；允许建立固定索引但不要求动态插删
- 动态查找表：允许查找、插入和删除；BST、AVL、散列表典型应用

## 性能度量：ASL
- 平均查找长度：$ASL=\sum_{i=1}^{k}p_i c_i$
  - $p_i$：该种查找情形发生的概率；$\sum p_i=1$
  - $c_i$：其**关键字比较次数**，须先约定是否计终止判空
- 成功 ASL：条件在**要查的关键字存在**；按记录的访问概率加权
- 失败 ASL：条件在**要查的关键字不存在**；按失败区间/初始散列地址等模型加权
- **等概率只是一种题设假设**；未指定概率时不可武断用简单算术平均
- ASL 是具体比较次数的期望，**不是**时间复杂度本身

## 与渐近复杂度区别
- 最好/最坏/平均时间复杂度：描述输入规模 $n$ 趋大时的增长阶
- ASL：通常把一次查找涉及的关键字比较作为成本；数值可能与扫描和IO开销不同
- 二分查找 ASL 约为对数级；AVL/红黑树最坏查找为 $O(\log n)$
- 无额外优化的 BST 可能退化为链：最坏 $O(n)$
- 散列表在合理负载/函数假设下**期望**接近 $O(1)$，但最坏可到 $O(n)$

## 常见命题辨析
- 记录占用空间很大时，用小关键字/索引组织查找，仍需考虑读取记录的代价
- 查找成功和失败 ASL **必须分开算**；失败区间数通常不同于记录数
- $ASL$ 可含循环、探测中的一次次关键字检查；不代表整个程序所有指令数
