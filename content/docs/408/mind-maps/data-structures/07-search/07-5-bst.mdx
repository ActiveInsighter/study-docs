# 7.5 二叉排序树 BST

## 有序不变式
- 对每个结点 x：左子树关键字小于 x，右子树关键字大于 x（**无重复关键字**教材约定）
- 若允许重复值，必须规定重复数据放置或聚合策略，不能随意打破排序不变式
- 中序遍历得到严格递增序列（不含重复时）
- BST 不是堆：只要求左/右子树相对大小，**不要求完全树形**

## 查找与插入
- 从根开始，等于成功；小于走左，大于走右；遇空指针失败
- 插入新关键字：按查找失败的位置挂接新**叶结点**，不需要改变原结点大小关系
- 若插入顺序本来单调（如 1,2,3,4,5），普通 BST 会退化成单链
- 查找和插入：时间 $O(h)$，h 为树高，最坏 $O(n)$

## 删除三种情况
- **叶结点**：直接去掉
- **只有一个非空孩子**：以孩子接替自身，父子关系重新连接
- **同时有两个孩子**：找中序前驱（左子树最右）或后继（右子树最左）
  - 用前驱/后继的关键字替换待删关键字，再删除那个实际结点
  - 代替结点至多有一个孩子，因此化归第二类删除
- 若目标是根结点，重新连接根指针，不可遗忘

## 与 AVL/红黑树的关系
- BST：只保证中序排序，不保证高度
- AVL：通过旋转始终维持左右子树高度差绝对值≤1
- 红黑树：通过颜色和黑高维持**较弱但充分的平衡**，使最坏高度 $O(\log n)$
- AVL/红黑树仍满足 BST 的查找顺序，故查找路线同“比大小再选子树”

## 考点与反例
- “最小结点必是叶结点”：错，最小结点可能还有右孩子；但**必无左孩子**
- “最大结点必为叶结点”：错，可能还有左孩子；但**必无右孩子**
- “中序有序说明是 BST”：对二叉树（按对应结点值及重复规则）可据此判定排序性质
