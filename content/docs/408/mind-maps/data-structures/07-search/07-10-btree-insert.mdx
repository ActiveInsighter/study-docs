# 7.10 B 树：查找、插入、上溢分裂

## 查找
- 在当前结点中有序比较，若命中关键字立即成功
- 否则选定对应范围子树指针继续；最终空指针失败
- 根到终端的层数为 $O(\log_m n)$（m 为阶，理想页面内比较不免费）
- 页面内若线性比较有 $O(m)$ 次；若局部二分查找可为 $O(\log m)$

## 插入步骤
- 先按查找路线找到**真实终端结点**，把新关键字按顺序放入
- 若当前结点关键字个数 $\le m-1$：完成，不改变高度
- 若插入后有 **m 个关键字**：发生上溢，必须分裂
  - 选择中间关键字 **上移至父结点**
  - 分裂为左、右两个结点；各方需至少 $\lceil m/2\rceil-1$ 个关键字
  - 若父结点因此上溢，继续向上分裂
  - 根结点上溢则新建根，B 树**高度增加 1**
- **分裂上移的是关键字，不是把所有关键字都留在下面两结点**

## 五阶 B 树实例（m=5）
- 原终端 `[10,20,30,40]`，插入 25 → 临时 `[10,20,25,30,40]`
- 选中间关键字 **25** 上移；左 `[10,20]`，右 `[30,40]`
- 若原本只有这一个根，则形成根 `[25]` + 两个终端结点
- 非根合法关键字数：$\lceil5/2\rceil-1=2$ 到 $4$

## 易错校验
- 仅有 **m−1 个关键字**并非上溢；插入至 m 个才需要分裂
- 分裂后不忘将原内部结点的子树指针按范围分配到左/右
- B树插入不同于 BST：插入成功后关键字可能升到父层
