# 7.11 B 树：删除、借位与合并

## 第一步：确定目标结点
- 若待删关键字在真实终端结点，直接删并检查剩余关键字数
- 若在**非终端**结点，可用其**中序前驱/后继**替换
  - 前驱在其左侧子树的最右终端；后继在右侧子树的最左终端
  - 接着删除对应终端里的替代关键字，问题归结为终端删除
- 不存在前驱/后继取值问题时，空树/根的特殊情形另行处理

- <img src="/images/408-mind-maps/ds-0140.svg" alt="B 树删除非终端结点关键字：用直接前驱或直接后继顶替" width="860" height="380">

## 第二步：检查关键字个数下限
- $t=\lceil m/2\rceil$，**非根结点至少 t−1 个关键字**
- 若删后仍 $\ge t-1$，无需再平衡
- 若不足，先查看同一个父结点下**相邻兄弟**是否有至少 t 个关键字

## 情形 A：兄弟能借
- 从富余兄弟借一键，经父结点旋转传递
- 借右兄弟：父**分隔关键字下移到缺额结点**，右兄弟最小键上移填父分隔位
- 借左兄弟：父分隔关键字下移，左兄弟最大键上移填父分隔位
- 若是内部结点，还要转移对应子树指针，保持搜索范围

## 情形 B：相邻兄弟都不能借
- 将“缺额结点 + 父分隔关键字 + 一个相邻兄弟”**合并为一个结点**
- 父结点因此少一个关键字和一个孩子；若父也下溢，则**向上继续修复**
- 若根最后变成 0 个关键字且恰有 1 个孩子：让孩子成为新根，树高减 1

## 五阶 B 树具体检验
- 非根允许 2～4 个关键字；假设根 `[30,60]`
- 终端孩子 `[10,20]`、`[40,50]`、`[70,80,90]`
- 删 20 后左孩子只余 `[10]`，中孩子仅2键不能借
- 合并为 `[10,30,40,50]`，根成为 `[60]`，仍是合法五阶 B 树

## 常见错误
- **不能**把非终端结点删除当成直接抹掉关键字而不调整区间指针
- 借位与合并必须经过父结点的**分隔关键字**，不能兄弟键直接跨区间搬运
- 对根结点的最少关键字要求**不同于非根结点**
