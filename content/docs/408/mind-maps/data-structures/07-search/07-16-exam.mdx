# 7.16 查找算法综合 · 408 考题路径

## 一次定位一个 key
- 无序线性表：顺序查找 $O(n)$；插入尾部一般快（若有容量）
- 有序数组：折半查找 $O(\log n)$，**插删仍可能需 $O(n)$ 搬移**
- 分块查找：块间有序、块内无序；顺序索引 + 块内扫描，均衡分块约 $O(\sqrt n)$
- BST：有序支持动态操作，但最坏可退化 $O(n)$
- AVL：严格高度差≤1；最坏查找、插删 $O(\log n)$
- 红黑树：颜色平衡；最坏查找、插删 $O(\log n)$
- B树/B+树：多路查找，重视**磁盘页IO和范围扫描**
- 散列表：有条件的期望 $O(1)$ 精确查找，**不直接支持有序范围查询**

## 高频计算题分解
- **ASL**：先确认成功/失败概率与比较计数是否包含哨兵/NIL/空桶
- **二分判定树**：写出取中点约定，再统计各层实际记录与失败区间
- **AVL/RBT**：先按 BST 找插点；旋转后核验中序不变
- **B树高度**：n 是关键字**总数**，不要误当作真实结点数
- **B树插入**：m个关键字触发上溢；关键字向父结点提升；根分裂树高加1
- **B树删除**：删除至低于 $\lceil m/2\rceil-1$ 才需要借位/合并
- **B+树**：查数据必须到叶结点，叶链为范围访问提供基础
- **散列 ASL**：同义词冲突也可能造成探测对非同义词的占位阻塞

## 常见真题纠错
- AVL 最小元素“必为叶结点”：错，可能含右子树；只能断言**无左子树**
- 红黑树“调整最多3次旋转，因此更新 $O(1)$”：错，旋转次数有界，仍可能向上变色或搜索
- 对 B树“所有叶都是空”：术语中的**失败外部叶**才为空；真实终端结点含关键字
- 对 B+树“分支键就是记录”：错，分支层可能只有索引键；成功须沿路径到数据叶
- “散列地址不同就不可能互相阻挡”：错，开放定址法后续探测可占同一槽

## 磁盘索引页数例题纠正
- 若数据文件有 $2\times10^7$ 条记录，每条 200B，页容量4000B
- 每页可容纳 $4000/200=20$ 条记录 → 数据部分需 $10^6$ 页
- **数据页数不是索引关键字数**：逐记录建立B树索引会有 $2\times10^7$ 个索引键；每页一键则可能只有 $10^6$ 个索引键
- 若每个索引键5B、记录指针5B、孩子指针5B、结点元数据2B
  - 含 k 键的内部结点需要 $2+k(5+5)+(k+1)5=15k+7$ 字节
  - $15k+7\le4000\Rightarrow k\le266$，最大阶数为 $m=k+1=267$
- 题目若给出了页头/对齐/记录地址字节数不同，则必须**重新按题设计算**

## 选型总结
- 频繁随机精确查找：良好散列函数 + 低装填因子通常适合
- 有序遍历与范围查询：BST/AVL/红黑树/B+树更自然
- 外存海量数据：优先评估B树/B+树的页大小、填充率、访问模式
