# 3.8 特殊矩阵 · 对称与三角压缩

## 压缩存储的思想
- 特殊矩阵：大量元素可以由少量独立参数表示
- 对称矩阵 $a_{ij}=a_{ji}$ → 只需存一侧及主对角线
- 三角矩阵：对角线的一侧全为同一个常数 c
- 计算题先明确
  - n 阶方阵；**存储上三角还是下三角**
  - 行主序还是列主序；数组**0 基还是 1 基**
- 不同约定对应不同下标公式，不能死记混用

## 对称矩阵：独立元素数量
- n 阶对称矩阵中，独立元素数量为
  - $N=1+2+\cdots+n=\frac{n(n+1)}2$
- 主对角线元素仅保留一次
- 对应的另一侧可通过对称性读取
- **访问次数 O(1)**：映射到压缩数组下标即可

## 对称矩阵：存下三角，按行优先
- 存储 $a_{ij}$ 的范围：$1\le j\le i\le n$
- 1 基数组 `b[1..N]` 下标
  - $k=\frac{i(i-1)}2+j$，前 i−1 行共有 i(i−1)/2 项
- 0 基数组 `b[0..N-1]` 下标
  - $k=\frac{i(i-1)}2+j-1$
- 若 $i<j$，先利用 $a_{ij}=a_{ji}$ 交换行列
- 例：`n=4, a[3][2]` → 0 基 k=$3+2-1=4$

## 对称矩阵：存上三角，按行优先
- 存储范围：$1\le i\le j\le n$
- 前 i−1 行共 $\frac{(i-1)(2n-i+2)}2$ 项
- 1 基数组下标
  - $k=\frac{(i-1)(2n-i+2)}2+(j-i+1)$
- 0 基数组下标：上式减 1
- 若 $i>j$，先交换 i、j
- 上三角按行与下三角按列具有对称的存储次序

## 上三角矩阵：常数区在主对角线以下
- 结构：$a_{ij}=c$ 对所有 $i>j$
- 保留上三角共 $n(n+1)/2$ 项
- 若约定**另存常数 c 一项**：占 $n(n+1)/2+1$ 个单元
- 0 基数组 `b[0..N]`
  - $i\le j$：按**上三角行优先公式**定位
  - $i>j$：访问 `b[N]`，$N=n(n+1)/2$
- 若 c 规定为隐含值（如默认 0），也可以无需额外单元；以题意为准

## 下三角矩阵：常数区在主对角线以上
- 结构：$a_{ij}=c$ 对所有 $i<j$
- 保留下三角：$i\ge j$
- 0 基数组：$k=\frac{i(i-1)}2+j-1$
- $i<j$ 时映射到最后一个常数单元 `b[N]`
- 与上三角矩阵的存储公式不能互换
