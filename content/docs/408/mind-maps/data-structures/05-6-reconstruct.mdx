# 5.6 由序列还原树 · 边界与方法

## 为什么只有一种序列不够
- 先序只有根和访问顺序；未知左右子树划分
- 例如先序 `A B`：A 的**左**孩子是 B，或**右**孩子是 B，序列都相同
- 后序 `B A` 同样无法区分这两种情况
- **先序 + 后序**通常也不唯一：单孩子结点无法判定左右

## 两个序列如何唯一还原
- **先序 + 中序**：先序首元素为根；用中序把左右子树分开
- **后序 + 中序**：后序末元素为根；用中序把左右子树分开
- **层序 + 中序**：层序第一个是根；递归按中序区间分离，层序筛选各子树成员
- 这些结论通常要求**结点值互不相同**，并且两序列真实对应同一棵树
- 若允许重复键，单凭遍历值不能保证结构唯一

## 具体例子
- 先序 `A B D E C F`
- 中序 `D B E A C F`
- 由先序确定根 A；中序拆为左 `D B E`、右 `C F`
- 左子树的先序是 `B D E`，右子树是 `C F`
- 继续递归得到：A 左 B 右 C；B 左 D 右 E；C 右 F
- 对照后序应为 `D E B F C A`

## 特殊：先序和后序何时能唯一
- 若已知树为**严格二叉树**（每个非叶结点都有两个孩子），且结点互异
  - 先序 + 后序可以确定左右子树规模，进而唯一恢复
- 若只是“二叉树”或“完全二叉树？”需按具体结构约束判断
  - 已知“完全二叉树 + n 结点”的层次位置，结合序列可有额外信息
- 不要误把“满二叉树”与“严格二叉树”互换概念

## 高频代码题
- **求高度**：`height(T)=1+max(height(L),height(R))`，空树返回 0（按层数）
- **统计叶子**：空结点 0；左右都空返回 1；否则左右递归相加
- **找两个结点最近公共祖先 LCA**：普通二叉树可递归查左右子树
- **从祖先 M 到后代 N 路径**：DFS 维护递归栈/路径数组；找到目标后回溯保持路径
- **后序非递归路径**：遍历栈可用于构造路径，但必须说明栈的结点含义
- **交换所有左右子树**：递归或层序遍历每结点交换 `lchild/rchild`，O(n)

## 选择题注意
- “前序+后序不唯一”是一般结论，附加条件可能改变结论
- 两种序列包含的结点**多重集合、数目**必须一致
- 根分裂后的左右序列长度由中序位置决定，不是各分一半
