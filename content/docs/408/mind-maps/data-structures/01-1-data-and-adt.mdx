# 1.1 数据 · 数据类型 · ADT

## 数据与信息
- **数据**：计算机可识别、存储和处理的符号集合
  - 不限于数值：文本、图像、音频、记录等
  - 数据的语义取决于解释规则
- **信息**：数据经加工后表达的内容或意义
- 考点：数据不等于数字，也不等于其物理表示

## 四个基础术语
- **数据元素**：数据的基本单位
  - 例：学生表中的一条学生记录
- **数据项**：构成数据元素、不可再细分的最小单位（在当前问题语境下）
  - 例：学号、姓名、成绩
- **数据对象**：性质相同的数据元素的集合
  - 例：所有学生记录
- **数据结构**：相互之间存在特定逻辑关系的数据元素集合
  - 既关注元素，也关注元素间的关系
- 图解：<img src="/images/408-mind-maps/ds-0157.svg" alt="数据、数据对象、数据元素和数据项的层级示意" width="300" height="180">

## 数据对象 VS 数据结构
- 数据对象：强调**元素的共同性质**
- 数据结构：强调**元素及其相互关系**
- 同一批学生记录
  - 可组织成顺序表：按位置线性排列
  - 可组织成哈希表：通过学号快速定位
- **数据结构 = 逻辑结构 + 存储结构 + 数据运算**（课程分析的三个方面）

## 数据类型
- 本质：**值的集合 + 可执行的操作集合**
- 原子类型
  - 值不可再分（在该类型定义层面）
  - 例：整型、字符型
- 结构类型
  - 可由其他类型组合
  - 例：数组、记录（结构体）
- 特别注意：**类型**规定值和操作；**变量**是类型的实例

## 抽象数据类型 ADT
- 核心：只规定**做什么**，不规定**怎么实现**
- ADT 的组成
  - 数据对象
  - 数据关系
  - 基本操作集
- 例：栈 ADT
  - 元素遵循后进先出 LIFO
  - `Push` 入栈、`Pop` 出栈、`GetTop` 读栈顶
  - 可由数组或链表实现，接口语义不变
- 区分
  - **抽象**：接口、行为、操作约束
  - **实现**：顺序栈、链栈、动态扩容等细节

## 408 易错辨析
- “数据元素就是数据项” → 错
- “数据类型只是取值范围” → 错，还包含操作
- “同一 ADT 只能有一种存储实现” → 错
- “数据结构只需关注数据类型” → 错，还需关注元素间关系
