# 3.7 数组 · 逻辑下标与存储地址

## 数组基础
- 数组由**相同类型**的元素组成；每维元素下标具有确定范围
- 一维数组是线性排列的同类元素
- 二维数组可看作若干行或若干列组成的数组
- 存储器中的线性排列需要确定**行主序或列主序**
- 元素字节数为 `w`；基地址为 `B`
- 通用思路：`LOC = B + (元素线性偏移量) * w`

## 一维数组地址公式
- 0 基下标：`A[0..n-1]`
  - $LOC(A[i])=B+iw$
- 1 基下标：`A[1..n]`
  - $LOC(A[i])=B+(i-1)w$
- 一般下界 `L`：`A[L..U]`
  - $LOC(A[i])=B+(i-L)w$
- 数组下标合法性是计算的第一步

## 二维数组：行主序 Row-major
- 设 `A` 有 **R 行、C 列**，各元素占 w 字节
- 0 基：`A[0..R-1][0..C-1]`
  - $offset=iC+j$
  - $LOC(A[i][j])=B+(iC+j)w$
- 1 基：`A[1..R][1..C]`
  - $offset=(i-1)C+(j-1)$
  - $LOC(A[i][j])=B+[(i-1)C+j-1]w$
- 每走**下一行**需跳过 C 个元素

## 二维数组：列主序 Column-major
- 仍是 R 行、C 列；存储顺序先逐列后换列
- 0 基：$offset=jR+i$
- 0 基地址：$LOC(A[i][j])=B+(jR+i)w$
- 1 基：$offset=(j-1)R+(i-1)$
- 1 基地址：$LOC(A[i][j])=B+[(j-1)R+i-1]w$
- 每走**下一列**需跳过 R 个元素

## 一题两种答案：R=3、C=4
- 求 1 基 `A[2][3]` 相对于 `A[1][1]` 的元素偏移
- 行主序：$(2-1)\cdot4+(3-1)=6$
- 列主序：$(3-1)\cdot3+(2-1)=7$
- 若每元素 `w=4` 字节，对应地址偏移 24 字节、28 字节
- **先问存储顺序，再问单位**：元素数与字节数不能混淆

## 多维数组推广（行主序）
- 0 基三维 `A[D1][D2][D3]`
- $offset=(iD_2+j)D_3+k$
- 地址：$B+[(iD_2+j)D_3+k]w$
- 推广方式：从左到右逐维累加并乘以后续维长
- 对列主序，换成从右向左按前面维长展开

## 典型陷阱
- 不要把“总元素数 R×C”误用作行宽或列高
- 元素下标 0 基与位序 1 基转换经常只差 1
- 题目若给“首元素地址”与“数组名地址”，先确认它们指的是同一元素
- 编程语言的实际多维数组存储规则可能不同；**按考题假设**求解
