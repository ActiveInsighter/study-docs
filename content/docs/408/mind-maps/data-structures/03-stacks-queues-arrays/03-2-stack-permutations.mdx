# 3.2 栈 · 出栈排列与卡特兰数

## 问题前提
- n 个**互异**元素按**确定的次序**依次入栈
- 入栈与出栈可穿插，但必须遵守 LIFO
- 统计的是**不同合法出栈序列**，不是入栈/出栈操作轨迹数
- 允许栈容量至少为 n，且最终所有元素都要出栈

## 卡特兰数公式
- **合法出栈序列数量**：$C_n=\frac{1}{n+1}\binom{2n}{n}$
- 递推：$C_0=1,\quad C_{n+1}=\sum_{i=0}^n C_iC_{n-i}$
- 前几项
  - $n=1\Rightarrow C_1=1$
  - $n=2\Rightarrow C_2=2$
  - $n=3\Rightarrow C_3=5$
  - $n=4\Rightarrow C_4=14$
  - $n=5\Rightarrow C_5=42$
- **不是 $n!$**：不是所有排列都能通过一个栈生成

## n=3 的具体例子
- 固定入栈顺序为 `A,B,C`
- 可能的出栈序列：`ABC`、`ACB`、`BAC`、`BCA`、`CBA`
- **不可能**：`CAB`
  - 为先出 C，必须先将 A、B、C 全部入栈
  - C 出栈后 B 压在 A 上，无法让 A 先于 B 出栈
- 一眼排除法：不可能越过尚未出栈的栈顶元素

## 用模拟验证任意序列（最可靠）
- 维护一个空栈、下一个待入栈元素的位置 `next=1`
- 按目标出栈序列从左到右处理目标元素 `x`
  - 栈顶不是 `x`：将输入序列中尚未入栈的元素依次压栈
  - 栈顶为 `x`：执行一次出栈
  - 没有可再入栈的元素且栈顶仍非 `x` → **不合法**
- 全部目标成功匹配，则合法
- 每个元素最多入栈、出栈各一次：O(n) 时间；栈 O(n) 额外空间

## 栈的最大容量问题
- 一个确定的**操作序列**：记录任一时刻已入栈数减去已出栈数
  - 最大差值＝完成该操作序列所需最小栈容量
- 一个确定的**目标输出序列**：按模拟过程统计最大栈深度
  - 不要直接把 n 当作必要容量
- 遇到“限制最大栈容量为 k”时
  - 卡特兰数公式通常**不能原样套用**
  - 必须再考虑操作过程中的深度约束

## 括号轨迹的等价模型
- 入栈对应左括号 `(`，出栈对应右括号 `)`
- 任意前缀都必须满足“入栈次数 ≥ 出栈次数”
- 最终入栈次数＝出栈次数＝n
- 与长度 `2n` 的合法括号序列一一对应（固定入栈顺序前提下）

## 易错与速记
- 卡特兰数适用于**一个栈、入栈次序已固定、出栈次序不限**的经典模型
- 交换入栈次序、多个栈、特殊额外规则需重新建模
- 判断是否合法时，优先写栈模拟，不凭肉眼猜
