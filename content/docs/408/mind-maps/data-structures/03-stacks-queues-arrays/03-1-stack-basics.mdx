# 3.1 栈 · 定义、顺序存储与链式存储

## 栈的 ADT
- **栈 Stack**：只允许在一端进行插入与删除的线性表
  - 允许操作的一端：栈顶 Top
  - 另一端：栈底 Bottom
- **后进先出 LIFO**：最后入栈元素最先出栈
- 基本操作
  - `InitStack(S)`：创建空栈
  - `Push(S,x)`：入栈，栈顶增加一个元素
  - `Pop(S,x)`：出栈，返回并删除栈顶元素
  - `GetTop(S,x)`：只读栈顶、不删除
  - `StackEmpty(S)`：判空
- 注意：LIFO 约束的是**操作序列**，不是物理地址

## 顺序栈：top 指向栈顶元素
- 典型 C 表示：`ElemType data[M]; int top;`
- 初始化：`top=-1`；判空：`top==-1`
- 入栈：先检验 `top==M-1`，再 `data[++top]=x`
- 出栈：先检验 `top==-1`，再 `x=data[top--]`
- 读取栈顶：`data[top]`
- 当前元素数：`top+1`
- 复杂度：合法的 `Push/Pop/GetTop` 均为 **O(1)**

## 顺序栈：top 指向下一个空位
- 同样使用 `data[0..M-1]`，**另一种约定**
- 初始化：`top=0`；判空：`top==0`
- 入栈：检验 `top==M` 后 `data[top++]=x`
- 出栈：检验 `top==0` 后 `x=data[--top]`
- 当前元素数：`top`
- **两种 top 约定不能混用**；考试先看初始化和更新方式

## 链栈：头部作栈顶
- 每个结点：`data` + `next`
- 无头结点实现
  - 空栈：`top=NULL`
  - 入栈：`node->next=top; top=node`
  - 出栈：保存 `top`，更新 `top=top->next`，然后释放旧结点
- 带头结点的链栈也可实现；判断条件相应改变
- 时间：已给结点或申请成功时，头部入栈/出栈均 O(1)
- 空间：每个结点额外存一根指针；仍可能因内存不足而失败

## 共享栈：两个栈使用同一数组
- 一端为 0 号栈，另一端为 1 号栈
- 两边向中间增长：`top0` 向右，`top1` 向左
  - 初始化：`top0=-1; top1=M`
  - 0 号栈入栈：`data[++top0]=x`
  - 1 号栈入栈：`data[--top1]=x`
- **栈满：`top0+1==top1`**，没有空闲位置
- 栈 0 空：`top0==-1`；栈 1 空：`top1==M`
- 优点：两个栈大小可动态分配，减少固定分区的浪费
- 不是“必须两栈都各自达到预设容量才溢出”：共享数组无空位即满
- <img src="/images/408-mind-maps/ds-0004.svg" alt="共享栈从数组两端向中间增长" width="430" height="167">

## 408 高频陷阱
- 栈不是“只能顺序存储”：**顺序栈与链栈均成立**
- `Pop` 不等于 `GetTop`：前者删除结点/元素
- `top=0` 未必是空栈：看题目选用何种约定
- 链栈未必绝对不会溢出：只是不受预分配数组容量限制
- 固定容量顺序栈的所有操作应先判满/判空
