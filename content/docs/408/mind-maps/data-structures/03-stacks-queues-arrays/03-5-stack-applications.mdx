# 3.5 栈的典型应用 · 表达式与递归

## 括号匹配
- 从左往右扫描字符串
- 遇左括号：压栈 `(`、`[`、`{`
- 遇右括号：若栈空或栈顶类型不匹配 → 非法
  - 匹配成功时弹出对应左括号
- 扫描结束后：栈必须为空，才算合法
- 例 `[[()][()]]`：可合法匹配，最大栈深 3
- 例 `([)]`：虽然数量相等，但不合法
- 时间 O(n)，最坏辅助空间 O(n)

## 三种表达式
- **中缀表达式**：`(A+B)*C`，运算符位于操作数之间
- **后缀 / 逆波兰式**：`A B + C *`
  - 无须括号，按运算符顺序求值
- **前缀 / 波兰式**：`* + A B C`
- 中缀到后缀的经典方法：**运算符栈 + 输出序列**
- 不能只看加减乘除的优先级，还须考虑**结合性**

## 中缀转后缀：运算符栈
- 操作数：直接加入输出
- 左括号 `(`：直接压入运算符栈
- 右括号 `)`：弹出直到遇到 `(`，并丢弃该左括号
- 读到运算符 `op`：比较栈顶运算符
  - 栈顶**优先级更高** → 先弹栈输出
  - 同级且 `op` **左结合**（如 `+,-,*,/`）→ 先弹栈输出
  - 同级且 `op` **右结合**（如常规定义的 `^`）→ 不弹同级的 `^`
  - 然后将 `op` 压栈
- 输入结束：输出剩余运算符；左右括号必须配对
- 例：`A+B*C` → `A B C * +`
- 例：`(A+B)*C-D/E` → `A B + C * D E / -`
- 原导图“低优先级直接入栈”的描述容易颠倒，正确规则是**先弹高优先级**

## 后缀表达式求值
- 从**左到右**扫描，数字直接入栈
- 遇二元运算符 `op`：先弹出 `b`，再弹出 `a`
- 计算并压栈：`a op b`
- 例 `8 3 - 2 *`：先得 `8-3=5`，再得 `5*2=10`
- **减法与除法不可交换操作数顺序**
- 若中途栈元素不足，或结束后不恰好剩一个结果，则表达式非法

## 前缀表达式求值
- 从**右到左**扫描，数字直接入栈
- 遇二元运算符：先弹 `a`，再弹 `b`
- 计算并压栈：`a op b`
- 例 `* - 8 3 2` → `(8-3)*2=10`
- 与后缀算法的**扫描方向及弹出左右意义均不同**

## 直接中缀求值：两个栈
- 运算数栈：数字与中间计算结果
- 运算符栈：运算符与左括号
- 遇低优先级的入栈运算符前，先规约栈顶高优先级运算符
- 遇右括号规约到对应左括号为止
- 计算一次二元运算：从运算数栈取 `b`、`a`，压回 `a op b`
- 栈空间大小题：**逐步画两栈，记录同时存在的最大元素数**

## 递归与非递归转换
- 函数调用通常靠**调用栈**保存返回地址、局部变量、参数等
- 深度优先搜索可用显式栈模拟递归
- 尾递归有时可改写成循环，避免不断增长的调用栈
- 斐波那契递归可用动态规划改写 → **不必显式使用栈**
- 考题错误说法：“任何递归改非递归都必须使用栈”
- 复杂度：递归层数（最大同时活跃调用帧）决定调用栈占用
