# 8.2 直接插入排序 · 有序前缀

## 基本不变式
- 第 i 趟开始：$A[1\ldots i-1]$ 已有序，待插入记录为 $A[i]$
- 将大于待插记录的元素向右移动一格，最后把待插记录写入空位
- 直到 i=n，即得到整个表有序
- 使用哨兵 $A[0]$ 暂存当前记录是教材常见实现，不参与逻辑记录数
- <img src="/images/408-mind-maps/ds-0168.svg" alt="直接插入排序各趟示意，蓝色有序前缀、橙色待插入记录" width="560" height="437">

## 一趟模拟
- 输入：`[5a, 2, 5b, 3]`（a、b 用于区分相等关键字）
- 插入 2 → `[2, 5a, 5b, 3]`
- 插入 5b → 与 5a 相等，无需跨越 → 顺序不变
- 插入 3 → `[2, 3, 5a, 5b]`
- **稳定性来自严格大于才移动**，若相等也后移，稳定性可能被破坏

## 伪代码与边界
- 以 0 基数组为例：外层 `i=1..n-1`
  - `key=A[i]`，令 `j=i-1`
  - 当 `j>=0 && A[j]>key`：令 `A[j+1]=A[j]`，再 `j--`
  - 循环后 `A[j+1]=key`
- 保存待插元素，避免移动过程把它覆盖掉
- 不加哨兵的实现必须先检查 $j\ge0$，避免越界

## 复杂度、移动和存储适应
- 最好：本来有序；相邻比较 $n-1$ 次；$\Theta(n)$
- 最坏：逆序；内层比较、移动数量都可达 $\Theta(n^2)$
  - 移动次数（只计元素后移）：$1+2+\cdots+(n-1)=n(n-1)/2$
- 平均（典型随机输入）：$\Theta(n^2)$；辅助空间 $O(1)$
- 直接插入**稳定**；基本有序时效率较好
- 适用于数组；链表也能做插入式排序，但需要重新安排指针逻辑、代价模型不同
