# 5.3 满、完全与一般二叉树

## 二叉树是有序树
- 每个结点最多有左、右两棵子树，**左右不可互换**
- 只有一个孩子时必须区分“仅左孩子”与“仅右孩子”
- 二叉树不等于“每个分支结点有两个孩子”
- 二叉搜索树 BST、AVL 是二叉树的**附加约束**，不是完全二叉树的同义词

## 满二叉树
- 高度 h（**层数**）的满二叉树每层都填满
- 总结点数 $n=2^h-1$，叶子结点 $n_0=2^{h-1}$
- 每个非叶结点都有两个孩子；所有叶子在最后一层
- 只有“所有内部结点度为 2”叫**真二叉树/严格二叉树**，不必所有叶子同层

- <img src="/images/408-mind-maps/ds-0176.svg" alt="满二叉树：每层结点数都达到最大" width="600" height="280">

## 完全二叉树
- 按层从左到右编号，位置与**同高度满二叉树的前 n 个**完全一致
- 最后一层可以不满，但**只允许从右往左连续缺失**
- 除最后一层外，其余各层一定填满
- <img src="/images/408-mind-maps/ds-0061.svg" alt="十二结点完全二叉树示意" width="570" height="266">
- 满二叉树一定是完全二叉树，反过来不一定
- 完全二叉树不允许“只有右孩子”的结点

## 非空二叉树结点数关系
- 设度 0、1、2 的结点数为 $n_0,n_1,n_2$
- $n=n_0+n_1+n_2$ 与 $n-1=n_1+2n_2$
- 相减得到关键恒等式：**$n_0=n_2+1$**
- 任意二叉树高度为 h（层数）：$h\le n\le 2^h-1$
  - 最小 h 个结点可构成单链
  - 最大结点数只有满二叉树能达到

## 完全二叉树的进一步性质
- 给定 n 个结点，高度唯一：$h=\lfloor\log_2n\rfloor+1$
- 结点数范围：$2^{h-1}\le n\le2^h-1$
- **度为 1 的结点个数至多 1**；若存在，则一定只有左孩子
- n 为偶数时，$n_1=1$；n 为奇数时，$n_1=0$
- 最后一个非叶结点编号是 $\lfloor n/2\rfloor$

## 典型陷阱
- “叶子数 = 度为 2 的结点数 + 1”要求**非空二叉树**
- “完全”只关心层次编号填充，不保证二叉搜索树的有序键关系
- “所有度为 1 的结点都只有左孩子”：仅对完全二叉树成立
