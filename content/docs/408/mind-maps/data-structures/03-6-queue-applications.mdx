# 3.6 队列的典型应用 · BFS 与系统模型

## 树的层序遍历
- 首先将根结点入队
- 循环：取出队头结点，访问它
  - 依规定顺序将它的各子结点入队
- 所有结点均访问后队列变空
- 对二叉树：通常先左孩子、后右孩子
- 每结点至多入队出队一次 → 时间 O(n)
- 最坏队列规模 O(n)（宽层可能包含大量结点）

## 图的广度优先搜索 BFS
- 起点先标记为已访问，再入队
- 队列非空：弹出 u，遍历 u 的各邻接点 v
  - v 未访问：立刻标记为已访问并入队
- **入队时标记**可防止重复入队
- 适用于按边数求无权图最短路径长度
- 邻接表：时间 O(V+E)，辅助空间 O(V)
- 邻接矩阵：时间 O(V²)
- 非连通图若需要完整遍历，还要从未访问顶点继续 BFS

## FIFO 与进程调度
- **先来先服务 FCFS**：请求按到达顺序排队
- 队列可表示就绪队列、任务队列、打印请求队列
- 注意：操作系统调度未必总是 FIFO
  - 优先级、时间片轮转和多级反馈队列具有不同规则
- 时间片轮转 RR：执行一段时间未结束的进程通常排到队尾

## 缓冲区与生产者消费者
- 生产者把数据放入缓冲队列，消费者从队头取走
- 用于平滑生产速率与消费速率差异
- 有界缓冲区必须处理“队满/队空”
- 多线程还需考虑互斥、同步与可见性
- 环形缓冲区很常见，但**循环数组 ≠ 自带线程安全**

## 基于队列的经典算法
- 拓扑排序的 **Kahn 算法**
  - 初始将入度为 0 的顶点入队
  - 取出 u，删除它的出边；新入度为 0 的顶点入队
  - 输出顶点数小于 V 时存在有向环
- 多源 BFS：多个起点在初始时全部入队
- 层次距离：通过记录各结点距离或逐层处理实现

## 单调队列（拓展）
- 双端队列维护窗口候选元素的**单调性**
- 求滑动窗口最大值：队尾弹出不大于新值的候选
- 窗口左边界移动时从队头移除过期下标
- 每下标至多入队、出队一次，均摊 O(n)
- 这不是普通 FIFO 队列的唯一用途，而是借助**双端队列**

## 栈、队列应用辨析
- 深度优先：栈或递归；广度优先：队列
- 普通 BFS 不应使用按权值出队的优先队列替代
- 有权图最短路径通常需其他算法（如 Dijkstra）
- 匹配嵌套括号：栈；按到达次序服务：队列
