# 6.6 DFS：递归、回溯与搜索森林

## 搜索逻辑
- 深度优先搜索（DFS）：访问顶点后，沿**未访问**的邻点继续深入，直至不能深入再回溯
- 递归版本：`visit(u); visited[u]=true; for v in Adj[u]: if !visited[v]: DFS(v)`
- 迭代版本：显式栈模拟递归；不同的压栈/扫描顺序会影响访问序列
- 不能仅依据“编号从小到大”猜测 DFS 顺序，必须遵守题给邻接表次序

## DFS 树与森林
- 每次从未访问的 v 递归进入，(u,v) 形成一条**树边**
- 连通无向图的一次 DFS 可访问全部顶点并构造一棵 DFS 树
- 全图扫描所有顶点，遇未访问顶点重新 DFS → 形成 DFS 森林
- 无向图的 **DFS 森林棵数 = 连通分量个数**
- DFS 树为原图部分边构成的**生成子图**，与连通分量的全部边不同

## 用 DFS 判断环
- **无向图**：访问相邻顶点时若已访问且不是当前结点的父结点 → 有环
- **有向图**：维护 `WHITE/GRAY/BLACK` 三色状态
  - 遇到指向 **GRAY（递归栈内）** 的有向边 → 有向环
  - 遇到 BLACK 顶点不能据此判环
- 自环与重边可能影响最简单的父结点检查；本章基础证明多以简单图为前提

## 时间和复杂度
- 邻接表：$O(V+E)$；邻接矩阵：$O(V^2)$
- `visited` 为 $O(V)$；最坏递归深度/显式栈为 $O(V)$
- 深度遍历只保证可达性及 DFS 树，**不保证任意源终点最短路径**
- 有向图 DFS 能分析有向环、拓扑排序和强连通分量，但求 SCC 需额外的算法/步骤

## 与 BFS 比较
- BFS：队列、逐层扩展、无权最短路径正确
- DFS：递归/栈、尽量深入、用于回溯与有向环检测
- 两者完整遍历的时间复杂度依赖**存储结构**，而非谁“更快”
