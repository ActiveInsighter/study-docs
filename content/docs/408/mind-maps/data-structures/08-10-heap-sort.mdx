# 8.10 堆排序 · 有序区逐步扩大

## 升序用大根堆
- 初始堆区：$A[1\ldots n]$，用 O(n) 自底向上建成大根堆
- 将根 $A[1]$（当前最大值）与堆末 $A[i]$ 交换
- 此时 $A[i]$ 位于**最终位置**，堆区收缩为 $A[1\ldots i-1]$
- 将新的根从顶部下滤，恢复缩小后堆区的大根堆性质
- i 从 n 递减到 2，结束时整体升序

## 复杂度逐项推导
- 建堆：$\Theta(n)$
- n−1 次取堆顶和交换：$O(n)$ 次常数动作
- 每次恢复堆性质：最坏 $O(\log n)$；累计 $O(n\log n)$
- 整体时间：最好/平均/最坏均为 $\Theta(n\log n)$（标准比较堆排）
- 额外空间：$O(1)$（数组和迭代调整）
- 堆排序**不稳定**：根与堆末跨远距交换可改变相等关键字顺序

## 实现边界
- 1基下标的 `heapSize` 是堆内元素数，不包含末尾已排区域
- 每趟堆区减1；不能把已确定最大值再次纳入下滤
- 最后只有1个元素时无需下滤；循环到 i=2 即可
- 注意“建堆”与“堆排序全程”的时间不同：O(n) vs O(n log n)

## 应用与考试辨析
- 需最坏 $O(n\log n)$、又希望少额外空间，可优先考虑堆排序
- 对初始有序状态不敏感：即使已排好，仍通常需要大量堆维护
- 堆上“取最大值”O(1)，但**删除根后恢复堆**需要 O(log n)
- 堆的父子约束不能按中序遍历得到有序序列
