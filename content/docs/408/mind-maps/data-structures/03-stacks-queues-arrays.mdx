# 第三章 栈、队列与数组

## 堆栈

- 考频：高
  - 09、10、11、13、17、18、20、22
- 一种操作受限的线性表，可顺序可链式
  - 只允许在线性表的一端进行插入和删除
- n个不同元素的输入队列，一共有多少种输出队列（Catalan公式）
  - 公式

    $\frac{1}{n+1}C_{2n}^{n}$

    - n = 2 -&gt; 2<br>n = 3 -&gt; 5<br>...
- 顺序栈
  - 配图

    ```cpp
    #define MaxSize 50  // 定义栈中元素的最大个数
    typedef struct {
        ElemType data[MaxSize];  // 存放栈中元素
        int top;                // 栈顶指针
    } SqStack;
    ```

    - 注意初始化top = 0，则说明top指向栈顶元素的下一个元素
    - 如果top = -1，则说明top指向栈顶元素
- 共享栈

    - 作用：

## 队列

- 一种操作受限的线性表，可顺序可链式
  - 只允许在线性表的一端进行插入，另一端进行删除
- 性质
  - 队头删除元素，队尾插入元素（头删尾插）
    - 所以是队尾先行，然后队头紧跟
  - 尾部向后扩展的线性结构
  - front -= 1; rear += 1
- 普通队列
  - 配图

    <a href="/images/408-mind-maps/ds-0107.svg" target="_blank" rel="noopener noreferrer"><img src="/images/408-mind-maps/ds-0107.svg" alt="普通队列" width="240" height="80" loading="lazy" /></a>

    - 判断队空
      - Q.front == Q.rear == 0
    - 判断队满
      - Q.rear == MaxSize &amp;&amp; Q.front == 0
      - Q.rear == MaxSize 代表队列不可再插入元素
    - 批注：顺序存储
- 循环队列
  - 如果队列没有使用“循环功能”，rear &gt; front
  - 如果队列使用了“循环功能”, front &gt; rear
  - 判断队空和队满
    分组说明：最常考；对应：[1. 牺牲一个存储单元](#focus=1.%20%E7%89%BA%E7%89%B2%E4%B8%80%E4%B8%AA%E5%AD%98%E5%82%A8%E5%8D%95%E5%85%83)

    - 1\. 牺牲一个存储单元
      - 队满：Q.front == (Q.rear+1)%MaxSize
      - 队空：Q.front == Q.rear
      - 队列长度：(Q.rear - Q.front + MaxSize)%MaxSize
    - 2\. 记录长度
      - 队满：Q.front == Q.rear &amp;&amp; len == n
      - 队空：Q.front == Q.rear &amp;&amp; len == 0
    - 3\. 增加tag
      - 队满：Q.front == Q.rear &amp;&amp; tag == 1
      - 队空：Q.front == Q.rear &amp;&amp; tag == 0
  - 基本操作
    - 初始化：Q.front = Q.rear = 0
    - 插入元素：Q.rear == (Q.rear + 1)%MaxSize
    - 删除元素：Q.front == (Q.front + 1)%MaxSize
    - 队列长度：(Q.rear - Q.front + MaxSize)%MaxSize
  - 配图

    <a href="/images/408-mind-maps/ds-0094.svg" target="_blank" rel="noopener noreferrer"><img src="/images/408-mind-maps/ds-0094.svg" alt="循环队列" width="240" height="101" loading="lazy" /></a>

  - 概要：与普通队列的front、rear功能同步
    概要范围：[如果队列没有使用“循环功能”，rear &gt; front](#focus=%E5%A6%82%E6%9E%9C%E9%98%9F%E5%88%97%E6%B2%A1%E6%9C%89%E4%BD%BF%E7%94%A8%E2%80%9C%E5%BE%AA%E7%8E%AF%E5%8A%9F%E8%83%BD%E2%80%9D%EF%BC%8Crear%20%3E%20front)、[如果队列使用了“循环功能”, front &gt; rear](#focus=%E5%A6%82%E6%9E%9C%E9%98%9F%E5%88%97%E4%BD%BF%E7%94%A8%E4%BA%86%E2%80%9C%E5%BE%AA%E7%8E%AF%E5%8A%9F%E8%83%BD%E2%80%9D%2C%20front%20%3E%20rear)

- 链式队列
  - 最好用带头节点的形式，方便编写
- 双端队列
  - 输入受限的双端队列
  - 输出受限的双端队列
    - 这种队列难度较高
- 程序中需要多个队列 or 堆栈
  - 使用链式，就不容易分配不合理
- 考频：高
  - 10、11、14、16、18、21、19大

## 应用

- 考频：中

- 表达式求解
  - 中缀
  - 后缀
  - 前缀
  - 概要：中缀转后缀：左优先原则<br>中缀转前缀：右优先原则
    概要范围：[中缀](#focus=%E4%B8%AD%E7%BC%80)、[后缀](#focus=%E5%90%8E%E7%BC%80)、[前缀](#focus=%E5%89%8D%E7%BC%80)

- 机算
  - 由表达式求值
    - 表达式手算（后/前缀）
      - 比较简单，直接算即可
    - 机算
      - 后缀表达式的机算
        - 使用堆栈，从左往右扫描。出现数字push进入堆栈。出现运算就pop两个数字，然后算出来后再push进去。
      - 前缀表达式的机算
        - 从右往左，同理
        - 注意：在pop后数字的次序需要特别注意（和后缀是相反的）
  - 求表达式
    - 步骤
      - 用一个栈来存储运算符
      - 遇到‘数’，直接输出
      - 遇到‘操作符’，如果与栈顶元素比较优先级，如果优先级低，直接入栈。否则，弹出所有比这个符号优先级高或者相等的操作符
      - 遇到‘界限符’，遇到"("，直接入栈。如果遇到")"，就依次弹出操作数，直到找到"("为止
  - 直接计算
    - 一个操作数栈
    - 一个符号栈
