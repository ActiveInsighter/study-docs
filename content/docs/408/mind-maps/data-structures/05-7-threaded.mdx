# 5.7 线索二叉树 · 借用空指针

## 动机和结构
- n≥1 个结点的普通二叉链表有 **n+1 个空孩子指针域**
- 线索化：把**原本为空**的左/右指针分别改存某遍历序的前驱/后继
- **仅空域才改为线索**；原有孩子指针必须保留
- 每结点增加 `ltag`、`rtag`：0 表示孩子，1 表示线索
- 访问 `lchild/rchild` 之前先检查对应 tag，避免把线索当孩子再递归

## 线索的对象与方向
- 必须指定**先序/中序/后序**中的一种；不同线索树不是同一结构
- 某遍历序第一结点无前驱、最后结点无后继（可指向 NULL 或头结点）
- `ltag=1` 的 lchild 指向该遍历序**前驱**
- `rtag=1` 的 rchild 指向该遍历序**后继**
- 含头结点的循环线索树会额外规定头结点的链接方式

## 建立中序线索的核心
- 采用**中序遍历**，维护变量 `pre` 表示刚访问过的结点
- 访问当前结点 `p` 时
  - 若 `p->lchild==NULL`：令 `p->ltag=1; p->lchild=pre`
  - 若 `pre!=NULL && pre->rchild==NULL`：令 `pre->rtag=1; pre->rchild=p`
  - 最后 `pre=p`；收尾处理最后结点的后继
- 线索化过程中不能把已改成前驱线索的指针再次当子树遍历

## 中序找前驱/后继
- 后继：若 `rtag==1`，直接取 `rchild`；否则到**右子树中最左下**结点
- 前驱：若 `ltag==1`，直接取 `lchild`；否则到**左子树中最右下**结点
- “最左/最右”移动时只沿**实际孩子指针（tag=0）**走
- 线索可避免遍历时递归栈；建树和线索化预处理仍需 O(n)

## 先序和后序线索的难点
- **先序线索**：后继通常易定位；一般无 parent 指针时前驱可能难找
  - 若有真左孩子，先序后继是左孩子；否则优先真右孩子或使用后继线索
- **后序线索**：前驱一般易定位；无 parent 指针时后继可能难找
  - 若有真右孩子，其后序最后结点是根的**直接前驱**
  - 若仅有真左孩子，左孩子是其直接前驱
  - 后继若有后继线索可直达；否则可能需要双亲/祖先信息
- 不要笼统说“后序线索二叉树没有后继”——只是**对所有结点常数时间直接定位**不总成立

## 考点与失误
- 线索数 ≠ 总指针数；孩子链仍有 n−1 条
- 不能把 tag=1 的线索箭头计为原树的边
- 结构的逻辑树关系不因线索改变，**物理指针含义**增加
- 使用循环线索头结点时，前驱/后继与 NULL 约定须逐题核对
