# 8.3 折半插入 · 减少比较但不减少移动阶数

## 直接插入的改进点
- 第 i 趟已有序区间为 $A[0\ldots i-1]$
- 用二分查找找到新元素的**最终插入位置**
- 对插入点及之后的记录整体右移，而不是在后移时逐个比较
- **只减少用于定位的比较次数**，没有减少最坏的记录搬移数量级

## 稳定插入：相等放后面
- `low=0, high=i-1`, `key=A[i]`
- 当 `low<=high` 时取中点 `mid`
  - 如果 `A[mid] > key`，则 `high=mid-1`
  - 否则 `low=mid+1`：**相等也向右定位**，新记录排在旧相等记录之后
- 循环结束后插入点 `low=high+1`
- 将 `A[low..i-1]` 从右往左搬移一个位置，令 `A[low]=key`
- 错误风险：把“相等”归入左侧会让新记录插到旧相等值前面，破坏稳定性

## 比较次数与时间
- 每趟二分比较 $\Theta(\log i)$，累计 $\Theta(n\log n)$（n较大时）
- 即使原序列已有序，每次都需要按上述二分定位：**最好时间仍为 $\Theta(n\log n)$**
- 逆序或随机输入仍需大量移动：最坏/典型平均时间 $\Theta(n^2)$
- 辅助空间 $O(1)$，稳定（按相等右插的实现）
- 折半定位要求**高效随机访问**；普通单链表不能像数组那样实现真正 $O(\log n)$ 的中点访问

## 举例和对照
- 有序前缀 `[(2,a),(4,b),(4,c),(7,d)]`，要插入 `(4,e)`
  - 正确插入位置在 `(4,c)` 后：`[(2,a),(4,b),(4,c),(4,e),(7,d)]`
- 对比直接插入：直接法在已经有序时可一眼判断不移动，故更适合几乎排好序的数据
- 对比归并：二分插入不是 $O(n\log n)$ 的完整排序算法，因为移动可能是 $\Theta(n^2)$
