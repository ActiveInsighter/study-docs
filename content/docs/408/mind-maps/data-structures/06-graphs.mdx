## 图的遍历

- BFS
  - 队列
    - 邻接表 O(v + e)
    - 邻接矩阵 O(v^2)
  - 广度优先生成树
    分组说明：如果给定的是邻接矩阵，则生成树唯一，如果是邻接表，则生成树不唯一；对应：[只针对无权图进行BFS即可得到最小生成树](#focus=%E5%8F%AA%E9%92%88%E5%AF%B9%E6%97%A0%E6%9D%83%E5%9B%BE%E8%BF%9B%E8%A1%8CBFS%E5%8D%B3%E5%8F%AF%E5%BE%97%E5%88%B0%E6%9C%80%E5%B0%8F%E7%94%9F%E6%88%90%E6%A0%91)

    - 只针对无权图进行BFS即可得到最小生成树
      - 时间复杂度：O(v^2)/O(v+e)
  - 要求掌握代码（队列实现）
    - 配图

      ```cpp
      void BFS_MIN_Distance(Graph G, int u) {
          // d[i] 表示从 u 到 i 的最短路径
          for (int i = 0; i < G.vexnum; i++)
              d[i] = INF;
          visited[u] = true;
          d[u] = 0;
          EnQueue(Q, u);
          while (!IsEmpty(Q)) {
              DeQueue(Q, u);
              for (int w = FirstNeighbor(G, u); w >= 0; w = NextNeighbor(G, u, w)) {
                  if (!visited[w]) {
                      visited[w] = true;
                      d[w] = d[u] + 1;
                      EnQueue(Q, w);
                  }
              }
          }
      }
      ```

- DFS
  - 递归/堆栈
    - 邻接表 O(v + e)
    - 邻接矩阵 O(v^2)
  - 深度优先生成树
    分组说明：如果给定的是邻接矩阵，则生成树唯一，如果是邻接表，则生成树不唯一；对应：[只针对无权图进行DFS即可得到最小生成树](#focus=%E5%8F%AA%E9%92%88%E5%AF%B9%E6%97%A0%E6%9D%83%E5%9B%BE%E8%BF%9B%E8%A1%8CDFS%E5%8D%B3%E5%8F%AF%E5%BE%97%E5%88%B0%E6%9C%80%E5%B0%8F%E7%94%9F%E6%88%90%E6%A0%91)

    - 只针对无权图进行DFS即可得到最小生成树
      - 时间复杂度：O(v^2)/O(v+e)
  - 要求掌握代码（递归实现）
    - 配图

      ```cpp
      bool visited[MAX_VERTEX_NUM];  // 访问标记数组

      void DFSTraverse(Graph G) {
          for (int v = 0; v < G.vexnum; v++)
              visited[v] = false;
          for (int v = 0; v < G.vexnum; v++)
              if (!visited[v])
                  DFS(G, v);
      }

      void DFS(Graph G, int v) {
          visit(v);
          visited[v] = true;
          for (int w = FirstNeighbor(G, v); w >= 0; w = NextNeighbor(G, v, w))
              if (!visited[w])
                  DFS(G, w);
      }
      ```

  - 无权图：
    - BFS/DFS都可以找最小生成树
  - 有权图
    - Prim算法
      - 从头到尾只有一个集合，不断扩大 <img src="/images/408-mind-maps/ds-0137.svg" alt="从头到尾只有一个集合，不断扩大" width="300" height="181">

        - 时间复杂度 $O(V^2)$

        - 掌握伪代码：英文代码+每一句话都写注释

          ```text
          /* G：图；T：生成树；树空。以下为 Prim 算法伪代码。 */
          void Prim(G, T) {
              T.V = {w};  // 添加任意一个顶点 w 到顶点集
              while (G.V - T.V != {}) {
                  (u, v) = find_min_weight(G);
                  // 选择满足 u ∈ T.V、v ∈ (G.V - T.V) 的最小权值边
                  T.E = T.E ∪ {(u, v)};
                  T.V = T.V ∪ {v};
              }
          }
          ```

      - 批注：Party
    - Kruskal算法
      - 每次直接找图中最小边，如果不成环，就加进去 <img src="/images/408-mind-maps/ds-0045.svg" alt="每次直接找图中最小边，如果不成环，就加进去" width="300" height="181">

        - 时间复杂度 $O(elog_2e)$

        - 掌握伪代码：英文代码+每一句话都写注释

          ```text
          /* V：图的顶点集；T：生成树。以下为 Kruskal 算法伪代码。 */
          void Kruskal(V, T) {
              T.V = V;  // 初始时每个顶点都是一个独立连通分量
              while (compute_connect(T) > 1) {
                  // compute_connect(T) 返回生成树的连通分量个数
                  (u, v) = find_min_weight(T);
                  // 选择连接不同连通分量的最小权值边 (u, v)
                  T.E = T.E ∪ {(u, v)};
              }
          }
          ```

- Kruskal算法
  - Kruskal算法的实现一定需要并查集来判断新的最短路径会不会成环
    - 算法实现
      - 把所有的边按权值大小递增排序

      - 从小到大，使用Find操作检查是否在同一个集合

      - 如果不再同一个集合，就用Union把两个集合加入到同一个集合中

    - 所以时间复杂度为：
      - 公式 $O(elog_2e)$

        - 原因：一共有e条边，执行e轮，并查集Find的时间复杂度为log\_2e
