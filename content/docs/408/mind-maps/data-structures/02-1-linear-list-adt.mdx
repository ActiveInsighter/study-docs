# 2.1 线性表 · 逻辑结构与 ADT

## 严格定义
- **线性表**：具有相同数据类型的 n 个数据元素的有限序列
  - 可表示为 $L=(a_1,a_2,\ldots,a_n)$
  - $n\ge 0$；$n=0$ 为**空表**
- 强调：是**逻辑结构**，不指明物理存储方式
- 线性表不同于数学中的无序集合：**有先后次序**

## 线性关系的特点
- 非空表有且仅有一个表头元素 $a_1$
  - 表头元素没有**直接前驱**
- 非空表有且仅有一个表尾元素 $a_n$
  - 表尾元素没有**直接后继**
- 其余元素均有唯一直接前驱与直接后继
- 逻辑关系：$a_i$ 的直接后继是 $a_{i+1}$
- 一个表的元素类型相同，但**元素值允许重复**

## 位置、下标与长度
- **位序 i**：通常按 1, 2, …, n 计数
- **数组下标**：C/C++ 通常从 0 开始
  - 逻辑第 i 个元素 ↔ `data[i-1]`
- **表长**：当前实际元素数 `length`
- **容量**：当前可容纳元素数 `capacity`，且 `0 <= length <= capacity`
- **合法操作区间**
  - 取第 i 个元素或删除：$1\le i\le n$
  - 在第 i 个位置插入：$1\le i\le n+1$

## 线性表 ADT
- 创建：`InitList(&L)`；销毁：`DestroyList(&L)`
- 长度与判空：`Length(L)`、`Empty(L)`
- 按位获取：`GetElem(L, i)`
- 按值查找：`LocateElem(L, e)`
- 插入：`ListInsert(&L, i, e)`
- 删除并返回元素：`ListDelete(&L, i, &e)`
- 遍历输出：`PrintList(L)`
- 注意：接口语义相同，**不同存储实现的代价不同**

## 两种典型存储实现
- **顺序表**：用地址连续的存储单元表示逻辑次序
  - 基于数组；支持常数时间按位访问
- **链表**：通过指针或游标表示逻辑关系
  - 结点可在内存中分散分配；通常要遍历定位
- 不应混淆“逻辑相邻”与“物理相邻”

## 408 判断题陷阱
- “表头元素的前驱是头结点” → 错，**头结点是可选的存储辅助结点**
- “一个元素没有前驱就说明它的下标为 0” → 错，位序与下标不同
- “线性表必须有至少一个元素” → 错，允许空表
- “线性表中元素的值不能重复” → 错
- “线性表一定连续存储” → 错
