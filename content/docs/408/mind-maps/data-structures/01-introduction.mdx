# 第一章 绪论

## 概念

- 数据分类
  - 数据结构
    - 关系
      - 存在一种或多种特定关系的数据元素的集合
  - 数据对象
    - 相同性质
      - 具有相同性质的数据元素的集合
  - 数据元素
  - 数据项
  - 图片
    - <img src="/images/408-mind-maps/thumb/ds-0157.webp" alt="图片" width="240" height="176">

- 数据类型
  分组说明：一个完整的ADT可以定义一个数据结构；对应：[抽象数据类型（ADT）](#focus=%E6%8A%BD%E8%B1%A1%E6%95%B0%E6%8D%AE%E7%B1%BB%E5%9E%8B%EF%BC%88ADT%EF%BC%89)

  - 数据类型
    - 概念
      - 一个值的集合
      - 在这个集合上可以进行的操作
    - 分类
      - 原子类型
        - 不可再分
      - 结构类型
        - 可以再分
  - 抽象数据类型（ADT）
    - 抽象的数据组织与之相关的操作
    - 数据
      - 数据对象
        - 数据类型就已经隐含在了数据对象里面了，例如定义的时候的 int a，或者ElemType e
      - 数据关系
        - 【数据对象的集合结构】，例如一对一（线性表），一对多（树）
    - 基本操作集
      - 就是数据的存取方法
- 考频：低

## 数据结构三要素

- 考频：低
- 逻辑结构

  分组说明：22年考纲新增；对应：[集合结构](#focus=%E9%9B%86%E5%90%88%E7%BB%93%E6%9E%84)

  - 集合结构
    - 和数学里的集合概念一致
  - 线性结构
    - 特点：
      - 每个元素都是一对一的关系，除了第一个元素都有前驱，除了最后一个元素都有后继
  - 树形结构
    - 一对多
    - OS中的目录结构就是树形结构
  - 图结构
    - 多对多
  - 或者王道上的分类方式：
    - 线性结构
      - 一般线性表
      - 受限线性表
        - 栈和队列
        - 串
      - 线性表的推广
        - 数组
    - 非线性结构
      - 集合
      - 树
        - 一般树
        - 二叉树
      - 图
        - 有向图
        - 无向图
- 数据的运算

- 物理结构 【类比OS中的 文件物理结构 来理解】

  - 线性存储
    - （OS文件：顺序存储），在物理上相邻的存放
  - 链式存储
    - 链表，离散存储，每个物理内容中含有指向下一个的指针
  - 索引存储
    - 用索引表来存地址
      - 通过索引表的索引信息来查
  - 散列存储
    - 哈希
  - 概要：非线性存储
    概要范围：[链式存储](#focus=%E9%93%BE%E5%BC%8F%E5%AD%98%E5%82%A8)、[索引存储](#focus=%E7%B4%A2%E5%BC%95%E5%AD%98%E5%82%A8)、[散列存储](#focus=%E6%95%A3%E5%88%97%E5%AD%98%E5%82%A8)

- 关系：
  - 逻辑结构是设计者独立思考后采用的抽象表示方式，独立于存储结构
  - 存储结构是逻辑结构在计算机上的映射，它不能独立于逻辑结构而存在
    - 例如int\[\]就是连续空间，ListNode就是离散空间

## 算法

- 概念
  - 对特定问题求解步骤的描述
- 特性
  - 有穷性（时间、步骤）
  - 确定性
  - 可行性
  - 输入
  - 输出
- 好算法的特质
  - 正确性
  - 可读性
  - 健壮性
    - 非法数据的处理
  - 时间复杂度低
  - 空间复杂度低
- 考频：低

## 算法复杂度

- 考频：高
  - 11、12、13、14、17、19、22
- 时间复杂度
  - 计算：
    - 1\. 找到基本操作（最深层的循环）
    - 2\. 分析该基本操作的执行次数 x 和问题的规模 n 的数学形式关系 $x = f(n)$

    - 3\. x 的数量级 O(x) 是算法时间复杂度 T(n)
  - 常用技巧：
    - 加法规则 $O(f(n)) + O(g(n)) = O(max(f(n), g(n)))$

    - 乘法规则 $O(f(n)) \times O(g(n)) = O(f(n) \times g(n))$

    - 咸鱼口诀：“常对幂指阶” $O(1) < O(log_2n) < O(n) < O(nlog_2n)<O(n^2)<O(n^3)<O(2^n) < O(n!) < O(n^n)$

  - 三种复杂度：
    - 最坏时间复杂度：考虑输入数据“最坏”的情况
    - 平均时间复杂度：考虑所有输入数据等概率出现的情况
    - 最好时间复杂度：考虑输入数据“最好”的情况
- 空间复杂度
  - 如何计算
    - 1\. 算法空间大小和问题规模的关系
    - 2\. 数学形式分析：空间x，问题规模n $x = f(n)$

    - 3\. x 的数量级 O(x) 就是算法的空间复杂度S(n)
    - 注：如果是递归程序，则各层算法所需存储空间不同，分析方法有所区别
  - 常用技巧：
    - 同上 ↑
  - 原地工作
    - 空间复杂度O(1)
      - 程序消耗的空间和问题规模没有相关性

## 存取存储器

- RAM随机存取存储器
  - 可以直接访问任一个存储单元，只要知道该单元所在记忆行和记忆列的地址即可。
  - 分为三个部分
    - 存储矩阵
    - 地址译码器
    - 读写电路
- SAM顺序存取存储器
  - SAM中的数据存储单元按照线性顺序排列，因而只能依顺序访问（类似于盒式录音带）。如果当前位置不能找到所需数据，就必须依次查找下一个存储单元，直至找到所需数据为止。SAM非常适合作缓冲存储器之用，一般情况下，缓存中数据的存储
- 考频：低
