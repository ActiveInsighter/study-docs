# 4.5 KMP 基础 · 最长相等真前后缀与 next

## 为什么能避免重新比较
- 若模式 P 已匹配一段前缀，主串对应区间的内容已知
- 当下一字符失配，依据已经匹配部分中**相等的前缀/后缀**决定可重用长度
- 无须再回退主串指针 i；只移动模式指针 j
- 预处理的信息仅依赖模式串，与主串 S **无关**

## 前缀、后缀与 border
- 例：`P="ababa"`
  - 真前缀：`"a"`,`"ab"`,`"aba"`,`"abab"`
  - 真后缀：`"a"`,`"ba"`,`"aba"`,`"baba"`
  - 相等真前后缀：`"a"`、`"aba"`；最长长度 **3**
- **真**：长度必须小于整个所讨论串的长度
- border：某串的一个既是真前缀又是真后缀的连续片段
- `"aaaa"` 的最长相等真前后缀是 `"aaa"`，长度 3

## 先规定本章教材版本
- 模式串 $P[1..m]$（**1 基**）
- `next[1]=0`：首字符失配后无可重用前缀
- 对 $2\le j\le m$ ：
  - $next[j]=1+L(P[1..j-1])$
  - $L(X)$ 为 X 的**最长相等真前后缀长度**
- 例如 `P="ababaa"` → `next = [0,1,1,2,3,4]`
  - **注意**：`next[j]` 看的是**前 j−1 个字符**，不包含 `P[j]`

## 手算速查表（1 基）
- `P="google"`（g,o,o,g,l,e）
  - `next = [0,1,1,1,2,1]`
- `P="ababaa"`
  - `next = [0,1,1,2,3,4]`
- `P="aaaab"`
  - `next = [0,1,2,3,4]`
- `P="abaabc"`
  - `next = [0,1,1,2,2,3]`
- 区分：长度 m 的 `next` 数组**只计算到 `next[m]`**，但也可定义额外的 `next[m+1]` 用于拓展题目

## next 的经典递推
- 初始化：`i=1, j=0; next[1]=0`
- 当 `i<m` 时
  - 若 `j==0` 或 `P[i]==P[j]`：`++i; ++j; next[i]=j`
  - 否则：`j=next[j]`，沿已知可重用前缀继续退让
- `j=0` 是哨兵状态；此时**不要访问 `P[0]`**
- 每步要么 `i` 增大，要么 `j` 减小，建表时间 O(m)

## 与 0 基 LPS 的关系
- 常见 0 基 `lps[k]` 表示 `P[0..k]` 的最长相等真前后缀长度
- 对上述 1 基教材 next：$next[1]=0$
- 对 $j\ge2$：$next[j]=lps[j-2]+1$
- **不能**把同一下标的 `next[j]` 和 `lps[j]` 直接相等
- 多种教科书 `next` 有不同定义：解题先确认例子或首两项约定

## 高频判断陷阱
- 相等前后缀是**连续子串**，不是任意散列字符的公共子序列
- 不能把整段 P 自身算作“真”前后缀
- 出现相同字符不意味着 border 立即增长：需匹配**整段后缀和前缀**
- 前后缀可以重叠，`"aaaa"` 的 `"aaa"` 合法
