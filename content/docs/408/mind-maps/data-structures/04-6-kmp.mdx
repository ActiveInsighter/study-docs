# 4.6 KMP · 失配转移、完整算法与匹配位置

## 状态与不变量
- $S[1..n]$ 主串，$P[1..m]$ 模式串；二者均为 1 基
- i 指向主串中**下一个待比较的字符**
- j 指向模式串中**下一个待比较的字符**
- 已经相等的部分：`S[i-j+1 .. i-1]` 与 `P[1 .. j-1]`
- 失配时：`i` 保持不动，`j=next[j]`

## 匹配状态转移
- `j==0`：视为当前主串字符尚无可复用比较，令 `i++、j++`
- `j>=1` 且 `S[i]==P[j]`：令 `i++、j++`
- `j>=1` 且 `S[i]!=P[j]`：令 `j=next[j]`
- `j>m`：已完整匹配，返回**1 基起点** `i-m`
- `i>n` 且尚未匹配完毕：返回 0
- **重要**：回退 `j` 并不意味着主串 i 也倒退

## 核心伪码（教材 1 基约定）
- `next[1]=0`，预处理 `P[1..m]`
- `i=1; j=1`
- `while(i<=n && j<=m)`
  - `if(j==0 || S[i]==P[j]) { ++i; ++j; }`
  - `else { j=next[j]; }`
- `if(j>m) return i-m; else return 0;`
- 上述约定假设 **m≥1**，不在本流程内处理空模式

## 实际匹配轨迹：失配无需主串回退
- 主串：`S="abababacaba"`
- 模式：`P="ababaca"`
  - 1 基 `next=[0,1,1,2,3,4,1]`
- 比较到主串 i=6 时：`S[6]='b'`、`P[6]='c'` → 失配
- `j=next[6]=4`，i 仍是 6
  - 再比 `S[6]='b'`、`P[4]='b'` → 相等
- 继续匹配 `S[7]='a' / P[5]='a'`、`S[8]='c' / P[6]='c'`、`S[9]='a' / P[7]='a'`
- 首次完整匹配起点 **3**；匹配区间为 `S[3..9]`

## 算法复杂度
- 构造 `next`：O(m) 时间、O(m) 存储
- 主串匹配：O(n) 时间，复用前缀不回溯 i
- 整体时间：**O(n+m)**
- 额外存储：**O(m)** 保存 next（已给 next 时匹配过程本身 O(1)）
- `next` 预处理成本应计入“完整算法”复杂度

## 408 易错点
- 失配只调整 j，不把 `i` 设回原起点
- `next[j]` 给**新的模式串待比较位序**，不是“向右移动的位数”
- 输出匹配起点应是 `i-m`，不是 `i-m+1`（依本章 `i` 为比较后自增指针）
- 不要在 `j==0` 时读取 `P[0]`；利用短路求值或单独分支
