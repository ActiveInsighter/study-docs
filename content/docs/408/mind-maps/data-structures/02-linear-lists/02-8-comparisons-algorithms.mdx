# 2.8 线性表 · 高频算法与选型

## 顺序表 vs 单链表 vs 双链表
- **按位访问（已知位序）**
  - 顺序表 O(1)
  - 单/双链表 O(n)
- **按值查找（无序）**：一般最坏均 O(n)
- **已知插入位置前驱**
  - 顺序表通常要挪动元素 O(n)
  - 单/双链表链接修改 O(1)
- **已知结点的前驱**
  - 单链表找前驱一般 O(n)
  - 双链表沿 prior 获取 O(1)
- **存储与访问局部性**
  - 顺序表连续、少指针、缓存友好
  - 链表须存指针域、地址可能离散、利于频繁改链

## 模板 1：单链表原地逆置
- 三指针：`prev = NULL; curr = first; next = NULL`
- 循环：先保存 `next = curr->next`
  - 再改 `curr->next = prev`
  - 然后前进 `prev = curr; curr = next`
- 结束时 `prev` 指向新的表头数据结点
- 带头结点时设置 `head->next = prev`
- 时间 O(n)，额外空间 O(1)，**反转链接不复制数据**

## 模板 2：快慢指针
- 求中点：`slow` 每轮走 1 步，`fast` 每轮走 2 步
- 判环：从同一起点出发，先移动再比较；若运动中相遇则存在环
- 找环入口：首次相遇后，一指针回到表头，再同步每轮走 1 步，相遇处为入口
- 求倒数第 k 个结点：先让快指针领先 k 步，再同步走
- 注意空表、偶数长度以及 `fast` / `fast->next` 的空指针检查

## 模板 3：链表归并与拆分
- 合并两个递增有序单链表
  - 用哨兵 `dummy` 和尾指针 `tail` 重接较小结点
  - 接上剩余部分 → 时间 O(m+n)、辅助空间 O(1)
  - 已排序和可重排原结点是前提
- 快慢指针找中点 → 分成两段
- 归并排序链表 → 时间 O(n log n)，递归版额外调用栈 O(log n)
- 空表、单结点表是递归终止条件

## 模板 4：两指针保序筛选
- 顺序表原地删除特定值、去重、稳定筛选
- `read` 指针扫描，`write` 指针紧凑地保留
- 时间 O(n)，额外空间 O(1)
- **与链表“摘除结点”本质不同**：数组移动数据，链表修改链接

## 模板 5：有序线性表与交集
- 两表均有序 → 双指针同步推进
  - 相等时按题意保留并推进两者
  - 较小元素一侧推进，避免退回
- 单调推进时间 O(m+n)
- “按题意去重”不能隐含为自动去重；题目可能允许重复值

## 判断 O(1) 的前提
- “已知结点地址” ≠ “已知它的前驱”
- “已知顺序表的下标” ≠ “已知链表相应结点地址”
- “顺序表尾插”若触发扩容，单次可能 O(n)
- “链表插入”若需先按位定位，整体可能 O(n)

## 实战边界检查清单
- 空表与只含一个元素
- 表头／表尾／第 n+1 个插入位置
- 连续待删元素与全部元素均待删
- `NULL`、悬空指针、野指针与释放时机
- 非循环 `NULL` 终止 vs 循环表的哨兵终止
- `length`、`capacity`、`head`、`tail` 的同步维护
