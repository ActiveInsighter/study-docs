# 6.8 Prim：扩大一棵生成树

## 贪心不变式
- 维护已经纳入生成树的顶点集合 $S$，初始选一个起点
- 每轮从一端在 S、一端在 $V\setminus S$ 的边中选**权值最小**者
- 将新顶点和这条边加入树，直到有 V 个顶点、V−1 条树边
- 所选边是当前割的安全边，因此最终构成 MST
- <img src="/images/408-mind-maps/ds-0137.svg" alt="Prim 按跨割的最轻边扩展顶点集合的六个步骤" width="650" height="392">

## lowcost 与 parent 数组
- `inMST[v]`：v 是否已经在集合 S
- `lowcost[v]`：当前从 S 连接到 v 的**最小边权**，不是从起点到 v 的路径长度
- `parent[v]`：使 lowcost[v] 最小的树内端点
- 初始化：`lowcost[s]=0`；其余为起点到各顶点的直接边权或 INF
- 每轮取尚未入树的最小 lowcost 顶点 v，加入边 `(parent[v],v)`
- 更新：若 $w(v,u)<lowcost[u]$，则改写 `lowcost[u]` 与 `parent[u]`

## 复杂度与边界
- 邻接矩阵 + 线性扫描找最小：$O(V^2)$，即使稀疏图也一样
- 邻接表 + 最小堆（适当实现）：$O(E\log V)$
- 空间主要是图和 O(V) 辅助数组
- 若某轮所有待选 lowcost 都是 INF：**原图不连通**，不能得到整图 MST
- 相同边权时可能有多种合法选择，答案的边集合未必唯一

## 易错纠正
- 不能从**全图所有未选边**里取最小：它必须跨越当前 S 的割
- 不能把 lowcost 当作 Dijkstra 的 `dist`：前者只比较**单条跨割边**
- Prim 允许负权边；Dijkstra 的**非负权限制**不能套到 MST
- 如果原图只有一个顶点，MST 边集为空、权值和 0
