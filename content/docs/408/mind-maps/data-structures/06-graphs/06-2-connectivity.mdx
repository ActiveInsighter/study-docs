# 6.2 连通 · 极大 / 极小 · 子图

## 子图的精确定义
- $G'=(V',E')$ 是 $G=(V,E)$ 子图，要求 $V'\subseteq V$、$E'\subseteq E$
- **边的两端都必须出现在** $V'$；删点时须同时删掉其关联边
- 真子图：$G'\neq G$ 的子图；生成子图：**顶点集完全相同**，$V'=V$
- **诱导子图**：选定 $V'$ 后，保留原图中两端都在 $V'$ 的**全部**边
- 生成子图≠诱导子图：前者可删边，后者不得任意删保留顶点间的原边

## 无向图连通性
- 连通：对任意不同顶点 u、v，有 u 到 v 的无向路径
- 连通分量：**极大连通子图**，不能再添加原图中的其他顶点而保持连通
- 每个连通分量是其顶点集对应的**诱导子图**；不同分量顶点不交
- 无向连通图恰有 **1 个连通分量**；孤立顶点也单独构成一个分量

## 有向图可达与强连通
- u 可达 v：存在沿弧方向 u→…→v 的路径
- **强连通**：任意 u、v 均双向可达
- **强连通分量 SCC**：极大强连通子图；单顶点也可构成 SCC
- 单向可达不代表强连通；**弱连通**是忽略所有弧方向后连通
- 有向图中“不能完成拓扑排序”意味着存在**有向环**
  - 因而至少存在一个顶点数 ≥2 的强连通分量（简单图中）
  - 但**不意味着整张图强连通**

## 有向树 / 有向根树
- 若一棵底层无向图为**树**的有向图有一个根，其余顶点均由根经有向路径可达，则称外向有向根树（arborescence）
- 外向根树满足：根入度 **0**，其他顶点入度 **1**，有 $V-1$ 条弧
- **仅凭**“一个入度 0、其余入度 1”**不足以**保证有向树：还需全图由根可达/底层无向连通
- 例如：孤立根 + 另一个顶点集合组成有向环，入度条件成立但不是根树

## 极大与极小：包含关系不同
- **极大连通子图（分量）**：无法继续加入**原图中的顶点/边**而保持连通且仍为更大的连通子图
- **极小连通生成子图**：不能再删任何边而保持**所有原顶点连通**，即生成树
- 连通分量由原图唯一划分；生成树通常不唯一
- 不连通无向图：没有整图生成树；可构建**生成森林**，每个分量一棵树
- <img src="/images/408-mind-maps/ds-0150.svg" alt="图、连通分量、极小连通子图与生成树包含关系" width="560" height="360">

## 判断题速记
- “极大连通子图有全图边数最多的意思”：**错**，极大指“不能再扩展”，非全局最大边数
- “一个连通图所有连通子图都连通”：只有按定义取出的连通子图连通，任意子图可不连通
- “BFS/DFS 的树就是连通分量”：错，树通常只保留其发现边
- “有向图若存在环则一定强连通”：错，可能只有局部环
