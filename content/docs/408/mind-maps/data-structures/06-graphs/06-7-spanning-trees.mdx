# 6.7 生成树、最小生成树（MST）

## 生成树的定义
- 仅讨论**无向连通图**的生成树；从原图选取**全部 V 个顶点**和部分边
- 连通 + 无环 ⇒ 恰好 $V-1$ 条边
- 等价：有 $V-1$ 条边且连通；或有 $V-1$ 条边且无环（前提含全部 V 顶点）
- 从一棵生成树**再删一条边必不连通**；**再加原图任意一条非树边必有环**
- 不连通图没有全图生成树；对应各分量构造生成森林
- <img src="/images/408-mind-maps/ds-0138.svg" alt="生成子图加极小连通得到生成树" width="560" height="260">

## 最小生成树与最短路径的区别
- 带权连通无向图的**最小生成树 MST**：所有生成树中**边权和最小**者
- MST 目标是 $\sum_{e\in T}w(e)$ 最小，**不是**两顶点间路径最短
- BFS/DFS 选出的任意生成树不一定是 MST，即便图每条边等权，只是因等权才都属于 MST
- **最短路径树 SPT**：对固定源点，每个终点在树中的路径最短；SPT 不保证 MST
- MST 的权值和是唯一的最优值，但 MST 边集合可能不唯一

## 割性质（Prim/Kruskal 的正确性来源）
- 把顶点集划分为两侧 $S$ 和 $V\setminus S$（割）
- 当前待选边中，**跨越割的最小权边**可作为某棵 MST 的安全边
- 若跨割最轻边唯一，它一定出现在所有 MST 中
- Kruskal 等价地维护若干连通分量，挑选连接不同分量的最轻可用边

## 环性质与唯一性
- 一个环中，若某条边的权**严格大于**环上所有其他边，则该边不会出现在任何 MST 中
- 当所有边权互不相同时，MST 一定唯一（**充分**不必要条件）
- 存在相同边权不必然不唯一；应看可替代的等权边是否构成其他同代价生成树
- 负权边、零权边可以用于 MST：Prim/Kruskal **不要求非负权**

## 典型选型
- 稠密无向带权连通图：邻接矩阵 + Prim $O(V^2)$ 比较直观
- 稀疏图：边排序 + Kruskal $O(E\log E)$ 比较自然
- 并查集负责判“是否连接同一分量”，不负责比较边权
