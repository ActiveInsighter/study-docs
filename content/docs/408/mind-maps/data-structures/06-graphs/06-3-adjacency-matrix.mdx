# 6.3 邻接矩阵：表示与运算

## 结构与权值约定
- 按顶点编号 0…n−1 构造 $n\times n$ 的二维数组 A
- 无权图：有边 A[i][j]=1，无边 A[i][j]=0；自环禁止时对角线为 0
- 带权图：有边记实际权值，无边记 $+\infty$（也可搭配 `hasEdge` 独立标志）
  - 最短路初始化常令 $D[i][i]=0$，不代表存在自环
  - 当边权可能为 0 或 −1 时，**不能**用 0 或 −1 混作“无边”
- 无向图邻接矩阵**对称**；有向图一般不对称
- 空间：$\Theta(V^2)$，与边数 E 无关

## 入度、出度与边数
- 对无权简单有向图：$\deg^+(i)=\sum_j A[i][j]$（**行和**）
- 对无权简单有向图：$\deg^-(i)=\sum_j A[j][i]$（**列和**）
- 无向图第 i 行 1 的个数即 $\deg(i)$
- 无向图的边数 $E=\tfrac12\sum_i\sum_jA[i][j]$
- 有向图的弧数 $E=\sum_i\sum_jA[i][j]$
- **带权矩阵不能求权值和当作度**：必须统计“有无边”

## 操作复杂度
- 判断 u、v 是否相邻：$O(1)$（直接访问 A[u][v]）
- 扫描 u 的所有出邻点：$O(V)$（遍历一整行）
- 计算入/出度：单点 $O(V)$，即使点度很小也要扫对应列/行
- BFS 或 DFS 用邻接矩阵：$O(V^2)$
- 适用情形：**稠密图**、频繁判边、顶点数量相对较小

## 矩阵幂与长度为 k 的通路
- 无权图普通整数矩阵 A 的 $(A^k)_{ij}$：从 i 到 j 的 **k 步通路数**
- k≥1；可重复经过顶点/边，因此计算的是**通路**，不是简单路径数
- 例：有向 1→2→3，$(A^2)_{13}=1$，$A_{13}=0$
- 是否存在恰好 k 步通路：判断 $(A^k)_{ij}>0$
- 注意：布尔矩阵乘法用于可达性存在性，不用于整数通路计数

## 常见失误
- 混淆“行=出度、列=入度”，画弧时首项是**起点**
- 负权/零权图用 0 表示无边，将误判真正的零权边
- 无向图矩阵存储一条边会占两个对称单元
