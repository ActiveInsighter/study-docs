# 2.5 单链表 · 插入、删除、指针顺序

## 在已知结点 p 后插入 s
- 前提：`p != NULL && s != NULL`；`s` 为待接入的新结点
- **先接后继**：`s->next = p->next`
- **再改前驱**：`p->next = s`
- 已知 p 时两次指针修改为 $\Theta(1)$
- 若反过来先做 `p->next = s`，旧后继可能丢失

## 在第 i 位插入
- **带头结点**：寻找第 $i-1$ 个结点 p（i=1 时 p 是头结点）
  - 允许 $1\le i\le n+1$
  - 定位 p 需 $O(n)$；后插操作本身 $O(1)$
- **不带头结点**：i=1 单独处理
  - `s->next = L; L = s`
  - i>1：找第 i−1 个数据结点执行后插
- 操作需检查越界、空指针、结点申请失败

## 已知结点 p 的前插
- 如果已知**前驱**，直接在前驱后插入即可 O(1)
- 若**只有 p 且是单链表**，常规前插要先找到 p 的前驱 $O(n)$
- 教材“偷换数据法”：在 p 后插 s，再交换/搬移 p 与 s 的数据
  - **值序列**表现为在 p 前插一个值；结点身份没有真正前移
  - 若外部保存了结点指针、数据不可随意复制或结点身份具有含义，则不等价
  - 不能把该技巧无条件推广为普通的 O(1) 前插

## 按位删除
- 带头结点：定位待删结点的前驱 p
- `q = p->next; p->next = q->next; free(q)`（C 分配时）
- 若需返回删除值：释放前保存 `e = q->data`
- 第 i 位合法范围：$1\le i\le n$
- 定位最坏 $O(n)$，改链与释放 $O(1)$

## 删除已知结点 p 的优化
- 若 p **不是尾结点**、允许覆盖结点数据：
  - `q = p->next; p->data = q->data`
  - `p->next = q->next; free(q)`
  - 可在 $O(1)$ 时间实现**值序列意义上**的删除
- 若 p 是**尾结点**：必须找前驱（若无前驱或尾指针辅助通常 O(n)）
- 若业务依赖结点地址/身份，复制后继数据不等价于删除原 p 结点
- 绝不能对 `NULL` 解引用或重复释放结点

## 指针操作可视化
- <img src="/images/408-mind-maps/ds-02-singly-insert.svg" alt="单链表在已知结点 p 后插入 s 的两步操作" width="410" height="141">
- 基本不变量：每个数据结点的 `next` 都应指向**其逻辑后继**
- 插入检查：新结点是否可达？旧后继是否仍可达？
- 删除检查：前驱是否跳过被删结点？返回值是否先保存？

## 时间复杂度辨析
- 已知前驱 `p` 的后插/后删：$\Theta(1)$
- 仅给逻辑位序 i 的插入/删除：需定位，最坏 $\Theta(n)$
- 单链表不能在 O(1) 时间内**通常意义上**直接得到某结点的前驱
