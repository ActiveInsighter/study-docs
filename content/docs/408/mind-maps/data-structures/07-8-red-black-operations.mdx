# 7.8 红黑树：插入与删除

## 查找与普通 BST 相同
- 只比较关键字，决定左或右子树；不依赖颜色参与键值比较
- 失败走到黑色 NIL；查找最坏 $O(\log n)$
- <img src="/images/408-mind-maps/ds-0101.svg" alt="红黑树查找沿二叉排序树路径进行" width="720" height="333">

## 插入规则
- 先按 BST 位置插入**红色新结点**（若作为根，则调整为黑）
- 父结点为黑：没有破坏红黑性质，结束
- 父结点为红：祖父结点必黑（插入前树合法），分类看“叔叔”
  - **红叔**：父和叔转黑、祖父转红；以祖父为新检查点，向上继续
  - **黑叔（含 NIL）**：单旋或双旋 + 调整父/祖父颜色；结束本次局部修复
- 注意新结点与父/祖父的方位决定 LL/RR/LR/RL，旋转前后 BST 中序不变
- 插入收尾：确保**根最终为黑色**
- <img src="/images/408-mind-maps/ds-0090.svg" alt="红黑树插入过程及旋转配色练习" width="740" height="386">

## 删除：核心是修复黑高
- 先进行 BST 删除；若待删结点有两个孩子，与后继/前驱交换或转移删除目标
- 删除红色结点且其他条件不变：通常无需补偿黑高
- 删除黑色结点可能导致某侧**缺少一个黑结点**，常称“双黑”问题
- 依兄弟颜色及其子结点颜色处理：旋转/变色；情况可能向上传播
- 删除算法的精确“黑色替代结点”位置须按实现中的 NIL/sentinel 约定
- 考试画图必须遵照题设所用的**删除伪代码与选择后继策略**，不同合法结果不一定完全同形

## 旋转次数 vs 总维护代价
- 标准红黑树插入**最多 2 次单旋**（一次双旋算两次）
- 标准红黑树删除**最多 3 次单旋**；变色和沿祖先传播仍可能耗费 $O(\log n)$
- **“最多三次旋转”只说旋转次数，不能据此断言插删是 $O(1)$**
- AVL/红黑树均可在 $O(\log n)$ 完成搜索和更新

## 作图自检
- 中序序列仍有序吗？根黑吗？有没有红红相邻？每条 NIL 路径黑数相同吗？
- 若叔叔为红却直接旋转，通常属于遗漏“先变色向上”
