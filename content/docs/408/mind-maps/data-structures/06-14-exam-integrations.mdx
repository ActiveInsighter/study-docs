# 6.14 图论综合：考题算法选型

## 先看目标：题目到底要什么
- 判断“能不能到达”：BFS 或 DFS（有向图注意方向）
- 求“几个无向连通分量”：遍历森林 / 并查集
- 判断“有向图有环”：DFS 三色 / Kahn 拓扑排序
- 求“经过最少条边”：BFS（单位边权）
- 求“单源最短**权值和**”：Dijkstra（权值非负）
- 求“所有点对最短距离”：Floyd（允许负边但需排除相关负环）
- 求“连接全图成本最小”：Prim / Kruskal → MST
- 求“合法活动先后序”：拓扑排序；“工程完成时间”：AOE 关键路径

## 先看图的限制
- **无向连通？** 原图不连通则没有整图生成树，MST 应转为最小生成森林
- **边权为负？** 不妨碍 Prim/Kruskal，却破坏标准 Dijkstra 的贪心前提
- **有向图？** 强连通需要双向可达，普通并查集不能直接求强连通分量
- **稀疏/稠密？** 邻接表通常 $O(V+E)$ 空间；矩阵为 $O(V^2)$
- **有向环？** 不可能存在覆盖全部顶点的拓扑序/合法 AOV 调度 DAG

## 四类“树/路径”不要混
- **BFS/DFS 生成树**：遍历过程的发现边，任意生成树即可
- **MST**：**整棵树边权总和**最小；不保证源到所有点路径最短
- **SPT（单源最短路径树）**：从固定源点到各点路径最短；整体总权值未必最小
- **关键路径**：AOE 源到汇的**最长工期路径**，不是短路径
- 四者目标完全不同，不能互相替代

## 数量与复杂度速查
- 无向简单图最大边数：$\frac{V(V-1)}2$
- 有向简单图最大弧数：$V(V-1)$
- 连通无向图生成树：**V−1** 条边；森林 V−c 条边（c 个连通分量）
- BFS/DFS：邻接表 $O(V+E)$，矩阵 $O(V^2)$
- Prim：常规矩阵 $O(V^2)$
- Kruskal：$O(E\log E)$
- Dijkstra：常规矩阵 $O(V^2)$
- Floyd：$O(V^3)$
- Kahn 拓扑排序：邻接表 $O(V+E)$
- AOE 关键路径：已给拓扑序时 $O(V+E)$

## 典型错误逐项纠正
- “DFS 能求无权最短路”：**不能保证**；应 BFS
- “BFS 可以求最小生成树”：等权条件下遍历树恰为某棵 MST，但一般加权图不能
- “Floyd 遇负边即失效”：错误；**负环**才使相应最短路无有限解
- “极大连通子图按边数最大”：错误；关键是**不可继续扩展**
- “Kruskal 的 $\log E$ 来自并查集”：错误，主要来自**边排序**
- “求出一条关键路径即确定全部关键路径”：错误，可能多条
