## 定义

- 定义
  - 输入n个记录
  - 进行算法实现后
  - 输出n个记录
- 稳定性
  - 关键字大小相同元素能否做到每次输出后前后位置关系保持不变
- 排序分类
  - 内部
    - 排序元素全在内存中
    - 概要：优化思路：时间空间复杂度
      概要范围：[排序元素全在内存中](#focus=%E6%8E%92%E5%BA%8F%E5%85%83%E7%B4%A0%E5%85%A8%E5%9C%A8%E5%86%85%E5%AD%98%E4%B8%AD)

  - 外部
    - 排序元素需要从外存调入内存
    - 概要：优化思路：减少读写次数
      概要范围：[排序元素需要从外存调入内存](#focus=%E6%8E%92%E5%BA%8F%E5%85%83%E7%B4%A0%E9%9C%80%E8%A6%81%E4%BB%8E%E5%A4%96%E5%AD%98%E8%B0%83%E5%85%A5%E5%86%85%E5%AD%98)

- 一个难点
  - n个关键字基于比较进行排序，问至少要多少次两两比较能够变得有序
    - 有个n个关键字，则这n个关键字的'数组'有 【n!】种形成方式
    - 设至少t次两两比较，则这t次两两比较后数组会有【 2^t 】种结果
    - 故形成结果数【一定要 &gt; 】形成方式数
      - t 为整数，最后取上整数 $2^t \ge n! 即\ t\ge log_2(n!)$

- 考频：低
  - 无

## 插入排序

- 考频：低
  - 09、12
- 排序表
  - 配图

    |有序序列|当前元素|无序序列|
    |---|---|---|
    |$L[1,\ldots,i-1]$|$L[i]$|$L[i+1,\ldots,n]$|

- 代码
  - 配图

    ```cpp
    // 插入排序，A[0] 用作哨兵
    void InsertSort(ElemType A[], int n) {
        int i, j;
        for (i = 2; i <= n; i++) {
            if (A[i] < A[i - 1]) {
                A[0] = A[i];  // 复制为哨兵
                for (j = i - 1; A[0] < A[j]; j--)
                    A[j + 1] = A[j];  // 大于哨兵的元素向后移动
                A[j + 1] = A[0];      // 插入哨兵值
            }
        }
    }
    ```

- 分析&amp;特点

    - O(1)
  - 时间复杂度
    - 最好O(n)
    - 平均O(n^2)
    - 最坏O(n^2)
  - 稳定性
    - ✅
  - 特点：
    - 可以用于链式存储的排序

## 折半插入

- 思路：
  - 对插入排序的改进
    - 插入边比较边移动
      - 所以单个元素一次比较和移动的总复杂度为O(n) + O(n)
  - 折半插入把移动中的比较和插入分开了
    - 比较用二分查找O(logn)，插入就可以直接移动了O(n)
- 代码：
  - 配图

    ```cpp
    // 折半插入排序，A[0] 用作哨兵
    void HalfInsertSort(ElemType A[], int n) {
        int i, j, low, high, mid;
        for (i = 2; i <= n; i++) {
            A[0] = A[i];
            low = 1;
            high = i - 1;
            while (low <= high) {
                mid = (low + high) / 2;
                if (A[mid] > A[0]) high = mid - 1;
                else low = mid + 1;
            }
            for (j = i - 1; j >= high + 1; j--)
                A[j + 1] = A[j];
            A[high + 1] = A[0];
        }
    }
    ```

    > 整理说明：原图函数形参写为 nt，但循环使用 n；统一为 n。

    - 找完、再换位置
- 分析&amp;特点
  - 空间复杂度
    - O(1)
  - 时间复杂度
    - 最好O(n)
    - 平均O(n^2)
      - 比普通的插入好，折半是O(nlogn)+ O(n^2)
    - 最坏O(n^2)
  - 稳定性
    - ✅
  - 特点：
    - 相比直接插入，不能用于链表了，但是依然稳定
- 考频：低
  - 12

## 希尔排序

- 考频：中
  - 10、14、15、18
- 属于插入排序
- 又称：
  - 缩小增量排序
- 思路：
  - 将整个数组分割成若干个特殊字表，对各个字表进行直插排序，最后对总表进行一次直插
    - 优化点：每次进行直插的时候很大概率都会在中间停下，是和【概率/数组情况】有关的
- 示意图：
  - <img src="/images/408-mind-maps/ds-0175.svg" alt="示意图：" width="300" height="169">

- 代码：
  - 配图

    ```cpp
    // 希尔排序：缩小增量排序
    void ShellSort(ElemType A[], int n) {
        for (int dk = n / 2; dk >= 1; dk /= 2) {
            for (int i = dk + 1; i <= n; i++) {
                if (A[i] < A[i - dk]) {
                    A[0] = A[i];
                    int j;
                    for (j = i - dk; j > 0 && A[0] < A[j]; j -= dk)
                        A[j + dk] = A[j];
                    A[j + dk] = A[0];
                }
            }
        }
    }
    ```

- 分析&amp;特点
  - 空间复杂度
    - O(1)
  - 时间复杂度
    - O(n^1.3)
      - n在某个特定范围内指数为1.3
  - 稳定性
    - ❎
  - 特点：
    - only for 顺序表

## 冒泡排序

- 思路：
  - 像泡泡一样，每次都两两交换把最大/最小交换到对应位置
- 示意图：
  - <img src="/images/408-mind-maps/ds-0063.svg" alt="示意图：" width="300" height="196">

- 代码：
  - 配图

    ```cpp
    // 冒泡排序
    void BubbleSort(ElemType A[], int n) {
        for (int i = 0; i < n - 1; i++) {
            bool flag = false;
            for (int j = n - 1; j > i; j--) {
                if (A[j] < A[j - 1]) {
                    swap(A[j], A[j - 1]);
                    flag = true;
                }
            }
            // 完成最后一位的确定；若未交换，说明序列已有序
            if (flag == false) return;
        }
    }
    ```

- 分析&amp;特点
  - 空间复杂度
    - O(1)
  - 时间复杂度
    - 最好O(n)
      - 因为有那个剪枝操作
    - 平均O(n^2)
    - 最坏O(n^2)
  - 稳定性
    - ✅
  - 特点：
    - 可以用于链表
- 考频：低
  - 10

## 快速排序

- 考频：中
  - 10、14、19、涉及排序的大题
- 思路：
  - 每次快排，选择一个值为pivot，把比其小的放在左边，比其大的放在右边。然后再对pivot左右的数组进行快排
    - 默认pivot选择最左边的元素
- 示意图：
  - <img src="/images/408-mind-maps/ds-0148.svg" alt="示意图：" width="300" height="223">

- 代码：
  - 配图

    ```cpp
    // 快速排序（包括划分操作）
    void start(ElemType A[], int n) {
        QuickSort(A, 1, n);
    }

    void QuickSort(ElemType A[], int low, int high) {
        if (low < high) {
            int mid = Partition(A, low, high);
            QuickSort(A, low, mid - 1);
            QuickSort(A, mid + 1, high);
        }
    }

    int Partition(ElemType A[], int low, int high) {
        ElemType pivot = A[low];  // 默认选第一个元素作为枢轴
        while (low < high) {
            while (low < high && A[high] >= pivot) high--;
            A[low] = A[high];    // 比枢轴小的元素移到左端
            while (low < high && A[low] <= pivot) low++;
            A[high] = A[low];    // 比枢轴大的元素移到右端
        }
        A[low] = pivot;
        return low;
    }
    ```

- 分析&amp;特点
  - 空间复杂度
    - 最好O(log2n)
    - 平均O(log2n)
    - 最坏O(n)
  - 时间复杂度
    - 最好O(nlog2n)
      - 因为每次都要遍历，所以最好情况就是每次pivot都正好在最中间
    - 平均O(nlog2n)
      - 递归调用栈的深度为O(log2n)，每层递归调用都是O(n)的复杂度
    - 最坏O(n^2)
  - 稳定性
    - ❎
  - 特点：
    - 快排是所有排序中平均性能最佳的排序算法
  - 概要：即递归栈的深度
    概要范围：[空间复杂度](#focus=%E7%A9%BA%E9%97%B4%E5%A4%8D%E6%9D%82%E5%BA%A6)

## 简单选择排序

- 思路：
  - 每次遍历，选择最大or最小的一个元素，放到对应的位置
- 代码：
  - 配图

    ```cpp
    // 简单选择排序
    void SelectSort(ElemType A[], int n) {
        int min;
        for (int i = 0; i < n - 1; i++) {
            min = i;  // 默认后面最小的为第一个
            for (int j = i + 1; j < n; j++)
                if (A[j] < A[min]) min = j;
            swap(A[i], A[min]);
        }
    }
    ```

- 分析&amp;特点
  - 空间复杂度
    - O(1)
  - 时间复杂度
    - 始终是O(n^2)
  - 稳定性
    - ❎
- 考频：低
  - 无

## 堆排序

- 考频：高
  - 09、11、15、18、20、21、22大
- 思路：
  - 把整个数组看做一颗完全二叉树，每个结点的父节点都比其左右孩子的值大/小。
    - 动态的维护这一个完全二叉树
    - 每次找最大/最小就直接取根节点即可
- 存储方式：
  - 顺序存储，使用完全二叉树的顺序存储结构
    - 让数组从 1 开始
- 建大根堆：
  - 思路：
    - 从倒数第一个非叶子结点开始，调整其下属的堆，使得自己是这个堆中的最大值
  - 示意图：
    - <img src="/images/408-mind-maps/ds-0062.svg" alt="示意图：" width="300" height="200">

  - 代码：
    - 配图

      ```cpp
      // 建立大顶堆：数组下标从 1 开始
      void BuildMaxHeap(ElemType A[], int len) {
          for (int i = len / 2; i > 0; i--)
              AdjustHeap(A, i, len);
      }

      // 从 p 开始向下调整
      void AdjustHeap(ElemType A[], int p, int len) {
          A[0] = A[p];  // 暂存待调整元素
          for (int i = 2 * p; i <= len; i *= 2) {
              if (i < len && A[i + 1] > A[i])
                  i++;  // 两个子结点中取较大者
              if (A[0] >= A[i]) break;
              A[p] = A[i];
              p = i;
          }
          A[p] = A[0];
      }
      ```

      > 整理说明：原截图混用了 n/len、k/p，且向下更新写为 p=p*2；整理为统一参数 len、p，并用实际选中的较大孩子 i 更新 p。

      - 算法考虑的情况：每个非叶子结点的左右孩子堆都是设置好的大/小顶堆，故需要考虑自己的值非常的小，比左右孩子都还要小，不断的向下移动直到碰到最底部
  - 分析：
    - 空间复杂度：
      - O(1)
    - 时间复杂度：
      - 一个元素的调整：
        - O(h)
          - h是树高度
      - 总的元素调整：
        - O(n)
          - 总的元素比较次数不会超过4n
          - 概要：记住就行
            概要范围：[总的元素比较次数不会超过4n](#focus=%E6%80%BB%E7%9A%84%E5%85%83%E7%B4%A0%E6%AF%94%E8%BE%83%E6%AC%A1%E6%95%B0%E4%B8%8D%E4%BC%9A%E8%B6%85%E8%BF%874n)

- 堆排序算法
  - 思路：
    - 每次都把根节点和树的最后一个结点交换，交换后把这个节点和树的联系切断
  - 示意图：
    - <img src="/images/408-mind-maps/ds-0070.svg" alt="示意图：" width="300" height="236">

  - 代码：
    - 配图

      ```cpp
      void HeapSort(ElemType A[], int n) {
          BuildMaxHeap(A, n);
          for (int i = n; i > 0; i--) {
              swap(A[1], A[i]);
              AdjustHeap(A, 1, i - 1);  // 堆长度减 1
          }
      }
      ```

  - 分析：
    - 空间复杂度：
      - O(1)
    - 时间复杂度：
      - O(n)
- 总算法分析：
  - 空间复杂度：
    - O(1)
  - 时间复杂度：
    - O(nlog2n)
      - 最好平均最坏都是nlog2n
  - 稳定性：
    - 当然不稳定

## 归并排序

- 思路：
  - 把多个有序表组合成一个有序表
- 图示：
  - 一般讨论只说红色部分，但是真正的代码实现是蓝色+红色来实现的 <img src="/images/408-mind-maps/ds-0215.svg" alt="一般讨论只说红色部分，但是真正的代码实现是蓝色+红色来实现的" width="300" height="206">

- 代码：
  - 递归
    - 配图

      ```cpp
      // 归并排序：辅助数组需要容纳 A[1..len]
      ElemType *B;

      void start(ElemType A[], int len) {
          B = (ElemType *)malloc((len + 1) * sizeof(ElemType));
          MergeSort(A, 1, len);
      }

      void MergeSort(ElemType A[], int low, int high) {
          if (low < high) {
              int mid = (low + high) / 2;
              MergeSort(A, low, mid);
              MergeSort(A, mid + 1, high);
              Merge(A, low, mid, high);
          }
      }
      ```

      > 整理说明：原截图在全局用未声明的 n 分配 B；将分配移到已知 len 的入口中。保留原算法片段结构，未补充完整程序及资源释放逻辑。

  - 归并
    - 配图

      ```cpp
      void Merge(ElemType A[], int low, int mid, int high) {
          // A[low..mid] 和 A[mid+1..high] 都有序；B 为辅助数组
          int i, j, k;
          for (i = low; i <= high; i++)
              B[i] = A[i];
          i = low;
          k = i;
          j = mid + 1;
          while (i <= mid && j <= high) {
              if (B[i] <= B[j])
                  A[k++] = B[i++];
              else
                  A[k++] = B[j++];
          }
          while (i <= mid) A[k++] = B[i++];
          while (j <= high) A[k++] = B[j++];
      }
      ```

- 分析：
  - 空间复杂度：
    - O(n)
      - 递归也有O(log2n)可以忽略
  - 时间复杂度：
    - 递归O(log2n)，归并O(n)
      - 总共为O(nlog2n)
  - 稳定性：
    - ✅
- 可以用来给外部排序用，10TB数据请用归并排序
- 考频：低
  - 16、17、22

      - 原图合并了直接插入和折半插入：直接插入在有序时最好为 $O(n)$；折半插入的比较次数通常仍为 $O(n\log n)$。
      - 希尔排序复杂度依赖增量序列，原图的 $n^{1.3}$ 是经验性记法，不能视为对所有增量序列成立的统一上界。
      - 快速排序空间栏是平均递归栈量级；最坏情况递归栈可到 $O(n)$。
      - 基数排序的 $r$ 表示基数，$d$ 表示趟数；额外空间是否计入记录搬移数组取决于具体实现。

      > 校注：保留原表所有格子的数值，并在表后明确列出容易误用的复杂度条件。

- 小结：
  - n 较小时
    - 使用直插/简单选择排序即可
      - 如果元素的空间较大，可以选择简单选择，移动次数没有这么多
  - 如果被排序列已经基本有序
    - 使用直插or冒泡
      - 因为有剪枝
  - n 较大时
    - 用快排、堆排、归并
      - 快排
        - 随机情况下最好的
      - 堆排
        - 可以不用辅助空间的O(nlog2n)
      - 归并
        - 是具有稳定性的O(nlog2n)
  - n 很大，关键字可拆解
    - 基数排序

        - 应该补充多少个归并段呢
          - 公式法：
            - k叉归并树：严格的k叉树，设有n0个叶子，nk个分支，总结点为n个。其中nk是整数 $\left\{ \begin{array}{l} n=n_0+n_k \\ kn_k = n-1 \end{array} \right.  \Longrightarrow  n_k = \frac{n_0-1}{k-1}$

              > 整理说明：修复 XMind 公式源码中无效的 array 列格式 {**l**}，改为 {l}；不改变公式数值。

              - 需要补充的虚段个数： $u = (n_0-1)\%(k-1), 补充 (k-1) - u个$

                - <img src="/images/408-mind-maps/ds-0029.svg" alt="需要补充的虚段个数：" width="300" height="146">

          - 考场现推法：
            - 例：n₀ = 112 个初始归并段做 11 路归并，需补多少个虚段？
              - 公式：$(n_0-1)\%(k-1) = 111\%10 = 1 \ne 0$，补 $(k-1)-1 = 9$ 个
              - 现推：设 112 个结点权值都为 1，每 11 个合并为 1 个
                - 112 = 11 × 10 + 2：第一次合并生成 10 个结点，剩下 2 个权值为 1 的结点
                - 这 2 个结点再凑成一组需要 11 个，所以在最底层补 9 个虚段
              - 再练：n₀ = 111 时 $110\%10=0$，不需补；n₀ = 122 时 $121\%10=1$，补 9 个
