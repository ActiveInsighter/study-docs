# 7.14 哈希冲突 · 开放定址和拉链

## 开放定址（探测）
- 所有记录都保存在表槽位内，冲突时沿**确定的探测序列**寻找空位置
- 一般形式 $H_i(key)=(H(key)+d_i)\bmod m$
- **线性探测**：$d_i=0,1,2,\ldots$，连续占位易产生**一次聚集**
- **平方探测**：典型 $d_i=0,1,-1,4,-4,9,-9,\ldots$
  - 有助于缓解连续聚集，但同一初始 H 的关键字仍走同样路径，可产生**二次聚集**
  - 探测序列**未必走遍表中全部槽位**，要结合表长/探测方案判断能否插入
  - “表长必须为 4k+3 的素数”只对应某些特定覆盖性条件，不能当成所有平方探测的普适约束
- **双重散列**：$H_i(key)=[h_1(key)+i h_2(key)]\bmod m$
  - 步长与表长互素有利于遍历全部槽位；题目会给出两个散列函数
- **伪随机探测**：采用**可重复的确定序列**；查找必须复现插入探测路径

## 开放定址删除：不能直接变空
- 若一条记录被删，后续同一路径上仍可能存放同义词或探测后的非同义词
- 删除用特殊标记 **DELETED（墓碑）**，区别 EMPTY 和 OCCUPIED
- 查找遇 DELETED 必须**继续探测**；遇到从未使用的 EMPTY 才可按规则认定失败
- 插入可按策略复用 DELETED，但必须继续排除重复键

## 拉链法（链地址法）
- 每个散列地址对应一个桶，桶里存链表（也可采用树化等实现）
- 发生相同原始哈希地址时，记录挂到同一桶的链中
- 删除可直接移除链结点，无需保留开放定址式墓碑
- **链内依旧可能多次比较**；“不堆积”不等于“无冲突或必 $O(1)$”

## 计数要领
- 成功比较次数由该键**实际插入位置对应的探测路线**决定
- 失败要以可能的**原始散列地址**出发，模拟遇到首个 EMPTY 为止
- 不同 probing 方案得出的 ASL 可能不同，即使装填因子相同
