# 1.3 算法的定义与评价

## 算法是什么
- 为解决特定问题而规定的**有限步骤序列**
- 与特定编程语言无关
- 算法描述：自然语言、伪代码、流程图、程序代码
- **程序**是算法的一种实现载体；程序未必满足算法的有穷性

## 五大特性（必辨析）
- **有穷性**：执行有限次步骤后结束
- **确定性**：每一步在给定条件下语义明确
- **可行性**：每步可通过有限次基本操作实现
- **输入**：有零个或多个输入
- **输出**：至少有一个输出
- 易错：算法允许没有输入，**不允许没有输出**

## 优质算法的评价维度
- 正确性：满足问题规格；边界条件也正确
- 可读性：结构清晰、命名与注释明确
- 健壮性：面对非法输入或异常条件有合理处理
- 效率：时间开销与空间开销均需考虑
- 工程折中：时间换空间、空间换时间

## 三种典型时间情况
- **最好情况**：在规模相同的输入中运行次数最少
- **最坏情况**：在规模相同的输入中运行次数最多
- **平均情况**：对指定输入概率分布求期望
- 注意：**平均复杂度不必假设所有输入等概率**
- 例：顺序查找
  - 最好：第一个元素命中
  - 最坏：末尾命中或查找失败
  - 平均：需给出命中分布和失败概率

## 算法设计的边界意识
- 空序列、只有一个元素
- 输入是否有序、是否可能重复
- 整数溢出、下标越界、空指针
- 递归终止条件与规模是否缩小
- 最坏情况是否触发退化

## 复杂度的使用边界
- 复杂度刻画随输入规模增长的**数量级**
- 不直接代表运行秒数或内存字节数
- 同数量级的算法仍可能有不同常数因子
- 分析时先说清 **n 是什么**
