# 4.4 朴素模式匹配 · BF 算法

## 模式匹配任务
- 主串 $S$ 长度 n；模式串 $P$ 长度 m，常设 $1\le m\le n$
- 寻找主串中**首次**连续出现完整模式的位置
- 模式起点可以从 1 到 $n-m+1$（1 基）
- 不存在则按教材 `Index` 接口返回 **0**
- 匹配的比较对象是**对应字符**，不是字符集合

## 朴素算法的两层逻辑
- 外层枚举候选起点 $s=1,2,\ldots,n-m+1$
- 内层从模式开头比较：`S[s+j-1]` 与 `P[j]`
- 发生失配：把候选起点 `s` 向右移动一位
- 匹配到模式最后一个字符：返回 `s`
- 所有合法起点都尝试失败：返回 0

## 教材双指针写法
- 初始：`i=1`（主串指针），`j=1`（模式串指针）
- 匹配：`S[i]==P[j]`，令 `i++、j++`
- 失配：`i = i-j+2`；`j = 1`
  - **为什么是 +2**：失配时旧候选起点 `s=i-j+1`，新起点 `s+1`
- 若 `j>m`：说明 P 已匹配完毕，返回 `i-m`
- 若 `i>n` 且未完成：返回 0

## 经典手算示例
- `S="aaaaab"`，`P="aaab"`
  - 候选起点 1：前三位 `aaa` 匹配，第四位 `a!=b`
  - 起点 2：前三位仍匹配，第四位仍失败
  - 起点 3：`aaab` 完全匹配，返回 3
- 造成大量重复的原因：失配后将已经比较过的主串字符再次访问
- 模式重叠合法；不能把前一候选跳过的重叠位置永久丢弃

## 时间与空间复杂度
- 最坏：每个候选起点需比较 O(m) 次，外层 O(n)
  - $O((n-m+1)m)$，通常简写 **O(nm)**
- 常见最坏情形：主串大段同字符，模式末尾一字符不同
  - 例如 `S="aaaaaaaa..."`，`P="aaaab"`
- 最好：第一个候选匹配成功，需 O(m) 次比较
  - 有些教材讨论固定 m 下的整体输入族会写成 O(n) 最好，需要先明确成功/失败和 n、m 的变化条件
- 额外空间：双指针 O(1)（不算输入的存储）

## 与 KMP 的区别
- BF 失配：候选起点向右 1 位，**主串指针可能回退**
- KMP 失配：依据已知前后缀结构调整 `j`，**主串指针不回退**
- 两者正确性一致，返回首次出现的位置一致
- 线性时间的关键不在于“永不失配”，而在于**避免重复比较大量主串字符**

## 题目边界
- `m>n` 必然不匹配；`m=0` 的结果依题目定义（常归为边界特例）
- 返回位序从 1 开始，C++ `find` 返回 0 基且无匹配为 `npos`
- 某一候选前缀相同不能判成功：必须匹配**完整模式串**
