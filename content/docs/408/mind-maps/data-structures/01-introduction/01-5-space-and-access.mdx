# 1.5 空间复杂度 · 访存补充

## 空间复杂度：先定口径
- 关注算法运行过程中随输入规模增长的空间需求
- 通常考察**辅助空间复杂度**
  - 不把输入自身占用的空间算入辅助空间
  - 需计入动态数组、临时表、递归栈等额外开销
- 整体存储开销与辅助空间复杂度不是一个概念

## 常见空间模型
- 常数变量：固定数量的标量和指针
  - $S(n)=O(1)$
- 新建长度为 n 的数组
  - $S(n)=\Theta(n)$
- 新建 n×n 矩阵
  - $S(n)=\Theta(n^2)$
- 就地交换数组元素
  - 仅使用固定个临时变量，$S(n)=O(1)$

## 原地算法
- 通常指**额外工作空间是常数级**
- 例：通过一个临时变量交换两元素
- “原地”不表示没有变量、没有输入数组
- **就地操作**与**时间最优**没有必然关系
- 注意：不同教材对原地算法细节可能略有约定，408 以辅助空间常数级判断

## 递归程序的栈空间
- 每次递归调用通常保存参数、返回位置和局部变量
- 关键是**最大同时活跃的调用层数**，不是总调用次数
- 线性递归：$S(n)=\Theta(n)$（每层额外开销常数）
- 平衡折半递归：$S(n)=\Theta(\log n)$
- 二叉递归树：不等于自动使用 $\Theta(2^n)$ 栈空间
  - 深度优先执行时，通常按最大递归深度计算

## 时间—空间权衡
- 哈希表：通过额外存储加速查找（平均意义上）
- 归并排序：常见数组实现有 $\Theta(n)$ 额外空间
- 堆排序：常见原地实现额外空间为 $O(1)$
- 动态规划：记忆化存储可减少重复计算
- 结论：**复杂度需与具体算法实现绑定**

## 跨课程扩展：RAM 与 SAM
- RAM：Random Access Memory（随机存取存储器）
  - 存储单元通常可依地址直接访问
  - 在算法的 RAM 抽象模型中，基本机器操作按单位成本计
- SAM：Sequential Access Memory（顺序存取存储器）
  - 定位代价与当前访问位置和目标位置有关
  - 典型类比：磁带顺序读取
- 严格区分
  - “RAM 存储器”是硬件类别
  - “RAM 模型”是算法分析的抽象假设
  - “顺序存取”不等于“数据结构中的顺序存储”
  - 不能把 CPU Cache 简单归类为 SAM

## 一图辨析
- 顺序表
  - **逻辑结构**：线性
  - **存储结构**：顺序
  - **访问**：若底层支持随机寻址，按下标可常数时间定位
- 链表
  - **逻辑结构**：线性
  - **存储结构**：链式
  - **访问**：按位置查找一般需要逐结点遍历
- SAM 是访问介质/模型概念，和上述分类维度不同

## 408 自测
- “递归次数为 n，空间复杂度必为 n” → 错，取决于最大同时活跃栈帧数
- “原地算法不需要任何内存” → 错
- “数组元素连续就一定是 O(n) 访问” → 错，按下标可 O(1)
- “空间复杂度包括程序所有静态文本字节数” → 通常不按此口径分析
