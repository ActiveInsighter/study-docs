# 5.9 树与森林 · 遍历对应关系

## 普通树的三种遍历
- **先根遍历**：访问根 → 依次先根遍历每棵子树
- **后根遍历**：依次后根遍历每棵子树 → 访问根
- **层次遍历**：按层从左至右访问，通常借助队列
- 本章普通树默认**孩子次序有意义**，因此输出序列可稳定复现
- <img src="/images/408-mind-maps/ds-0205.svg" alt="普通树先根遍历与对应孩子兄弟二叉树" width="670" height="467">

- <img src="/images/408-mind-maps/ds-0100.svg" alt="树的后根遍历：序列 K E F B G C H I J D A" width="860" height="600">

## 森林先序遍历
- 从左到右，依次对每棵树进行**先根遍历**
- 转换为孩子兄弟二叉树后，对**二叉树先序**遍历
- 直观：访问当前树根 → 访问第一棵子树 → 后续兄弟子树
- <img src="/images/408-mind-maps/ds-0036.svg" alt="森林先序对应二叉树先序" width="665" height="356">

## 森林后序遍历
- 从左到右，依次对每棵树进行**后根遍历**
- 转换为孩子兄弟二叉树后，对**二叉树中序**遍历
- 原因：二叉树中序的左侧代表“第一棵孩子子树”；右侧代表“下一个兄弟”
- <img src="/images/408-mind-maps/ds-0011.svg" alt="森林后序对应二叉树中序" width="665" height="356">

## 四种常见对应（记忆表）
- 普通树**先根** ↔ 转换后二叉树**先序**
- 普通树**后根** ↔ 转换后二叉树**中序**
- 森林**先序** ↔ 转换后二叉树**先序**
- 森林**后序** ↔ 转换后二叉树**中序**
- **不存在**森林“后序 ↔ 二叉树后序”的一般规则

## 例子与边界
- 森林：T1 根 A，孩子 B、C；T2 根 D，孩子 E
  - 森林先序：`A B C D E`
  - 森林后序：`B C A E D`
- 转换后：A 左子 B、右兄弟 D；B 右兄弟 C；D 左子 E
  - 二叉树先序：`A B C D E`
  - 二叉树中序：`B C A E D`
- 如果无序森林，遍历前先明确孩子排列顺序

## 典型题型
- 给树/森林与其孩子兄弟二叉树，手算两种序列
- 给二叉树中序输出，逆推**森林后序**
- 区分“访问树根先”与“访问原树全部孩子前”，勿误写层序
