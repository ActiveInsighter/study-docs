# 5.12 哈夫曼树 · 最优前缀编码

## 带权路径长度 WPL
- 叶结点权重 $w_i$：出现频率、代价等非负权值
- 从根到叶的路径长度 $l_i$ 按**边数**计算
- 树的带权路径长度：$WPL=\sum_{i=1}^{n} w_i l_i$
- 哈夫曼树：在给定 n 个叶权的二叉树中，使 WPL **最小**的树
- 权通常落在**叶结点**；内部结点权是两个孩子权之和，用于构造

## 贪心构造：每次取最小的两个
- 将 n 个权值分别作为单结点树
- 每次选当前权值**最小的两棵树**，作为新结点左右子树
- 新根权值是左右子树根权之和，重新放回候选集合
- 重复 n−1 次，剩一棵树即哈夫曼树
- n≥2 时有 n 个叶子、n−1 个内部结点，总数 **2n−1**
- 构造通常用小根堆 O(n log n)；相等权重时形状可不同

## 具体算例：权 2、5、7、13
- 先合并 `2+5=7`，再 `7+7=14`，最后 `13+14=27`
- 所有合并产生的新权重之和 = $7+14+27=48$
- 一种编码方案（左 0、右 1）
  - `13→0`（码长 1）
  - `7→10`（码长 2）
  - `2→110`、`5→111`（码长 3）
- 于是 $WPL=13×1+7×2+2×3+5×3=48$
- 这只是一种最优树；互换同层孩子不会改变 WPL

## 前缀编码
- 若任一字符编码都**不是另一个编码的前缀**，称前缀码
- 取每条左边为 0、右边为 1，根到各叶子的码字自然具有前缀无歧义性质
- 只有**叶子**表示被编码的字符，不用内部结点作字符码字
- 哈夫曼编码为权重已知时的**最优二进制前缀码**之一
- 码字不一定唯一：左右 0/1 互换、同权处理顺序可变

## 典型陷阱
- WPL 必须乘**边数路径长度**，不是结点数
- 不能把“新建根的权重”直接当成码长
- 带权路径长度与普通树的内部路径长度 IPL 是**不同的量**
- 单个字符时，理论上可有长度 0 的空码；实际系统常用 1 位编码——先看题目约定
