# 5.10 二叉排序树 BST · 搜索与删除

## 核心不变式
- 对任何结点 x：其**左子树所有关键字 < x.key**
- 其**右子树所有关键字 > x.key**（本节按无重复键）
- 约束适用于整棵子树，不只是直接左右孩子
- BST 的**中序遍历**输出严格递增的关键字序列
- 允许重复键时需约定重复键处理策略，不可盲套严格不等式

## 查找与插入
- 查找：从根开始比较，较小走左、较大走右、相等返回
- 插入：沿查找失败路径到空位置后**新增叶结点**
- 一棵 BST 的形状取决于键的**插入顺序**
- 例：`50,30,70,20,40,60,80` 形成 3 层近乎满树
- 如果按已排序顺序 `10,20,30,...` 依次插入，会退化成右斜链

## 删除的三种情形
- **无孩子**：直接删除结点
- **只有一个孩子**：让唯一子树接到被删位置
- **左右孩子均有**：用中序前驱或后继替代其键，再删除被替代位置的结点
  - 前驱 = **左子树的最大**结点
  - 后继 = **右子树的最小**结点
- 删除前驱/后继时，它至多拥有**一个孩子**，操作可归约
- 若被删除结点就是根，必须同步更新根指针

## 查找代价
- 单次成功或失败比较次数与沿路径遇到的真实结点个数相关
- 对 n 个结点：平衡程度好时高度 h=O(log n)，退化时 h=O(n)
- 查找、插入、删除的时间复杂度均受高度 h 控制：**O(h)**
- **二叉排序树本身不自动保证平衡**；AVL 等才维持额外平衡约束

## 平均查找长度 ASL
- 查找成功：$ASL_s=\sum_i p_i c_i$，p_i 是每个键的查找概率
- 查找失败：$ASL_f=\sum_j q_j d_j$，q_j 是落到相应空区间的概率
- 若题目**明确等概率**，才可以取各自均匀概率；不能默认等概率
- 计数约定必须明确：失败时是否把“访问空指针”计为一次比较

## 考场解题顺序
- 插入序列 → 精确画树 → 按层写每个结点的比较次数
- 删除两孩子结点 → 先标记前驱/后继 → 再更新真实指针
- ASL 分母先核对：成功时实际键数，失败时**空区间数及概率模型**
