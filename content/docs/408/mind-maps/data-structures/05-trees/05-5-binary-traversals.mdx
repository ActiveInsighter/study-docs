# 5.5 二叉树遍历 · DFS 与 BFS

## 三种深度优先遍历（DFS）
- **先序 NLR**：先根 → 左子树 → 右子树
- **中序 LNR**：左子树 → 根 → 右子树
- **后序 LRN**：左子树 → 右子树 → 根
- 递归算法结构相同，改变 `visit(root)` 所在位置即可
- 空结点不访问，递归遇 `NULL` 直接返回

## 用同一棵树核对
- 根 A；左孩子 B、右孩子 C；B 的孩子 D、E；C 仅有右孩子 F
- 先序：`A B D E C F`
- 中序：`D B E A C F`
- 后序：`D E B F C A`
- 层序：`A B C D E F`
- 实际手算：先画树并**严格区分左、右**，不要凭序列猜

## 递归框架（伪代码）
- `Pre(T): if(!T) return; visit(T); Pre(T->l); Pre(T->r);`
- `In(T): if(!T) return; In(T->l); visit(T); In(T->r);`
- `Post(T): if(!T) return; Post(T->l); Post(T->r); visit(T);`
- n 结点每次只访问一次：**时间 O(n)**
- 递归辅助栈最大深度与树高 h 同阶：**空间 O(h)**
  - 退化链 h=O(n)；近似平衡 h=O(log n)

## 非递归算法
- **先序**：弹出并访问；先压右孩子，再压左孩子
- **中序**：不断将当前结点及其左链入栈；出栈访问后转右
- **后序**：可用双栈，或单栈加 `lastVisited` 记录已访问右子树
- 非递归显式栈最坏 O(h) 或 O(n)，依算法实现与树形
- 不能把“堆栈先入后出”误写成“先压左后压右、访问左先”

## 层序遍历（BFS）
- 根入队，循环：出队访问 → 左孩子入队 → 右孩子入队
- 时间 O(n)；队列最大长度 O(w)，w 是最大层宽，最坏 O(n)
- 层序可以逐层统计叶子数、层数、最大层宽
- 判断完全二叉树：层序出现**第一个空孩子位置之后**不得再遇非空孩子

## 小结与错题规则
- DFS 三序都遵守**先左后右**；因此叶子结点的相对访问次序相同
- 空树四种遍历都得到空序列；仅凭一条遍历序列一般不能唯一还原树
- 先序的“根在前”指每棵子树的根先访问；但左子树整体仍先于右子树访问
