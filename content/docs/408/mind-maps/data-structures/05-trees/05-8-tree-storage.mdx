# 5.8 普通树的存储 · 左孩子右兄弟

## 普通树与二叉树不同
- 普通树每结点孩子数可 >2；其双亲唯一（根除外）
- 不能直接用固定 `lchild/rchild` 存三个以上孩子
- 三种教材常用结构：**双亲表示法、孩子表示法、孩子兄弟表示法**
- <img src="/images/408-mind-maps/ds-0146.svg" alt="普通树结点分支示例" width="510" height="255">

## 双亲表示法
- 数组每项保存 `data` 和双亲位置 `parent`
- 根的双亲域通常用 `-1`（具体哨兵依约定）
- **求双亲 O(1)**；找孩子通常要遍历整个数组 O(n)
- 适合需要频繁向上追溯祖先的场景
- <img src="/images/408-mind-maps/ds-0080.svg" alt="双亲表示法中的数组索引与parent字段" width="570" height="374">

## 孩子表示法
- 每个树结点关联**孩子链表**，只存直接孩子关系
- 便于遍历某结点的全部孩子；找双亲可能需扫描
- 组织方式与有向图的**邻接表**类似，但树有更强结构限制
- <img src="/images/408-mind-maps/ds-0022.svg" alt="孩子链表示意" width="610" height="392">

## 孩子兄弟表示法（左孩子右兄弟）
- 每结点只有两个指针：`firstchild`、`nextsibling`
  - **左指针** → 本结点的第一个孩子
  - **右指针** → 与本结点同层的下一位兄弟
- 对所有兄弟按顺序连接，最后一个兄弟右指针为空
- 一棵树转换成二叉树：保留最左孩子边，兄弟之间连右孩子边
- <img src="/images/408-mind-maps/ds-0007.svg" alt="普通树转换为左孩子右兄弟二叉树" width="610" height="417">

## 森林与二叉树的转换
- 对森林中的每棵树采用孩子兄弟变换
- 再把**各棵树根结点按顺序**用右指针相连
- 此时转换后二叉树的根结点右孩子是下一棵树的根
- 逆转换：左孩子链看作一组孩子，顺着右指针找兄弟；主根右链还原多棵树
- **森林有序时**，根的先后顺序不可随意交换
- <img src="/images/408-mind-maps/ds-0020.svg" alt="三棵树组成的森林与其二叉表示" width="600" height="380">

## 复杂度与易错点
- 孩子兄弟法使**普通树的兄弟关系**转成二叉树的**右子树关系**
- 转换后的右指针通常不是原普通树的孩子边
- 双亲表示法的 parent 下标不同于链式存储的指针地址
- “孩子表示法=邻接表”只是实现形式相近，不能把一般图任意当成树
