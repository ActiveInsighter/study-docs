# 5.4 顺序编号与二叉链表

## 顺序存储 · 最适合完全二叉树
- 用数组依**层序**存结点，编号从 1 开始最易套公式
- 根在 `a[1]`；结点 i 的父结点（i>1）是 $\lfloor i/2\rfloor$
- 左孩子为 `2*i`，右孩子为 `2*i+1`（**仅编号存在时**）
- 在 n 结点完全二叉树中
  - `2*i<=n` 才有左孩子；`2*i+1<=n` 才有右孩子
  - i 为偶数时是左孩子，奇数时是右孩子（根除外）

- <img src="/images/408-mind-maps/ds-0032.svg" alt="非完全二叉树的顺序存储：空位补 0" width="720" height="280">

## 0 基数组的公式
- 根下标 0；下标 i 的孩子为 `2*i+1`、`2*i+2`
- i>0 时，父下标 $\lfloor(i-1)/2\rfloor$
- 注意：**不能把 1 基的 2i 直接搬到 0 基实现**
- 这两套公式只根据**层序位置**，不涉及 BST 的关键字大小

## 一般二叉树的顺序存储
- 为保留左右孩子的位置，空缺位置也必须**留占位**
- 高度为 h 的最右斜单支树，最深结点在 1 基下标 $2^h-1$
- 虽仅 h 个实际结点，数组仍可能需要接近 $2^h$ 的空间
- <img src="/images/408-mind-maps/ds-05-sparse-sequential-redrawn.svg" alt="右斜单支树在顺序存储中索引指数增长（修复原图失控字号与裁切）" width="760" height="328">
- 因而非完全二叉树一般使用**二叉链表**，不是直接密排层序数组

## 二叉链表
- 结点一般含 `data`、`lchild`、`rchild` 三个域
- `lchild/rchild == NULL` 表示缺失该方向孩子
- 由 `lchild` 与 `rchild` 即可区分左右子树
- <img src="/images/408-mind-maps/ds-0111.svg" alt="二叉链式存储结点和左右孩子指针" width="600" height="316">
- 若频繁查询双亲，可增加 `parent` 指针形成**三叉链表**

## 经典空链域计数
- n≥1 个结点的二叉链表中，孩子指针域共有 2n 个
- 非空孩子指针恰好 n−1 个（对应树的 n−1 条边）
- 所以**空指针域 = 2n−(n−1)=n+1 个**
- 线索二叉树会利用这些空指针域存前驱/后继，但必须增加 tag 区分
- 这里的 n+1 不是说有 n+1 个空结点对象

## 实现与考点
- 链式查找孩子 O(1)，但随机访问**任意编号结点**没有 O(1) 保证
- 顺序数组定位结点 O(1)；一般二叉树可能非常浪费空间
- 真正的树结点数由实际数据结点决定，不能把空占位计入 n
