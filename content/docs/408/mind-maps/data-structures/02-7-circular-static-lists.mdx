# 2.7 循环链表 · 静态链表

## 循环单链表是什么
- 尾结点的 `next` 不指向 `NULL`，而指回首结点或头结点
- 若带头结点，空表常定义 `head->next == head`
- 若不带头结点，空表常定义 `head == NULL`
- 遍历的终止条件由**是否回到起点**决定，而非遇见 `NULL`
- 循环结构让从尾结点跳到表头成为常数时间

## 只保存尾指针的好处
- 带头结点的循环单链表若已知尾指针 `rear`
  - 头结点可通过 `rear->next` 获取
  - 表头插入：O(1)
  - 尾部追加：更新 `rear` 后 O(1)
- 如果只保存**头指针**，追加时可能需要遍历找尾结点 O(n)
- 注意 `rear->next` 究竟是头结点还是首数据结点，取决于是否带头结点

## 循环双链表
- 每个结点有 `prior` 与 `next`，且双向首尾成环
- 带头结点空表：`head->next == head && head->prior == head`
- 非空：`head->next` 指首数据结点；`head->prior` 指尾数据结点
- 头尾两端访问与已知结点插删均可 O(1)
- 不存在“自然的 `NULL` 终点”，遍历必须避免无限循环

## 循环结构常见陷阱
- `while (p != NULL)` 不适用于正常成环的循环单链表
- 从任意结点出发遍历，应记录起点并检查“是否回到起点”
- 删除尾结点或唯一数据结点时，必须维持环及头/尾指针
- 单向循环表仅知道待删结点 p 时，找前驱仍可能 O(n)

## 静态链表的存储方式
- 使用**数组中的下标（游标）**代替指针域
- 每个数组元素包含 `data` 与 `next`（下一个结点的数组下标）
- 常用特殊值如 `-1` 表示链尾；具体应以题设定义为准
- 逻辑次序可以不等于数组下标顺序
- 分配一般使用自由链表或空闲结点表管理未占用数组槽

## 静态链表的复杂度与限制
- 已知游标所指元素 → 定位其数组单元为 O(1)
- 按逻辑位序查找 → 沿 `next` 逐步走，O(n)
- 已知插入位置前驱游标且空闲槽可获得 → 链接修改 O(1)
- 存储槽数固定或受预分配数组限制
- 适合不便使用动态指针／需要定长存储池的场景

## 对照与复习
- 普通单链表：尾结点 `next == NULL`
- 带头循环单链表：尾结点 `next == head`
- 循环双链表：首尾通过 `prior/next` 双向连通
- 静态链表：存储物理上是数组，但**逻辑上依然是链式关系**
