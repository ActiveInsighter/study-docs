# 8.18 408 排序综合 · 做题检查清单

## 排序过程模拟的第一步
- 先判定**排序算法和具体实现**：冒泡从哪侧走、快排用什么划分、堆下滤先比较哪边
- 在输入中标注相等关键字身份：如 `5a、5b`，据此检验稳定性
- 每一趟只根据该算法保证的性质填空
  - 插入：有序前缀扩大一位
  - 冒泡：一端逐个记录被固定
  - 选择：最值固定到未排序区的首位
  - 快排：枢轴位置固定，左右未必已排序
  - 堆排：堆区缩小、末端有序区扩大
  - 归并：有序段长度逐层翻倍

## 高频复杂度组合
- **折半插入**：比较 O(n log n)，移动最坏 O(n²)，不能因此把总时间写成 O(n log n)
- **希尔**：时间依增量序列；O(n^1.3) 并非统一上界
- **快速**：平均 O(n log n)，最坏 O(n²)；栈平均 O(log n)，朴素最坏 O(n)
- **堆**：建堆 O(n)；完整堆排序 O(n log n)
- **归并**：标准数组实现 O(n log n)，辅助数组 O(n)，相等取左才稳定
- **基数**：O(d(n+r))，桶实现选择决定 O(r) 或 O(n+r) 空间

## 典型计算题
- n 个不同关键字比较排序：最坏比较次数至少 $\lceil\log_2(n!)\rceil$
  - n=4：$4!=24$，比较次数至少 $\lceil\log_2 24\rceil=5$
- 简单选择排序 n=7：关键字比较次数 $6+5+4+3+2+1=21$
- 直接插入 n=7 逆序：仅计已排序记录的后移，共 $1+2+3+4+5+6=21$
- 初始 r=17 段，四路平衡归并：$\lceil\log_4 17\rceil=3$ 趟
- r=17 段，k=4 严格四叉最佳归并树：$(17-1)\bmod3=1$，需补2个0权虚段

## 外部排序综合要点
- 总读写量约 2WPL 的**条件**：每次归并都完整读写该节点的全部记录
- 败者树每输出一条重新比较 $O(\log k)$，不能减少段形成时已产生的 I/O
- 置换选择可延长段、减少段数，但**平均2M不是上界**
- 最佳归并树的虚段补齐：$u=((k-1)-((r-1)\bmod(k-1)))\bmod(k-1)$

## 从性能到算法选型
- 稳定优先：直接/折半插入、冒泡、标准归并、稳定LSD基数
- 仅限典型标准实现：希尔、快排、简单选择、堆排序**不稳定**
- 最坏比较复杂度 O(n log n) 且数组就地：堆；稳定且可付额外数组空间：归并
- 注意考试中“最佳”常取决于数据是否有序、内存容量、记录大小与是否有重复键
