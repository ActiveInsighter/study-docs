# 4.1 串的概念 · 连续性与位序

## 定义与线性表联系
- 串（String）是由**零个或多个字符**构成的有限序列
  - 记作 $S=s_1s_2\cdots s_n$，长度 $|S|=n$
  - 字符是数据元素；相邻字符具有线性次序
- 串是特殊的线性表：通常处理的是**整个串或一段连续区间**
- 空串 `""`：长度为 0，是合法的串
  - 空格串 `" "`：含一个空格，长度为 1，**不是空串**
- 串的值：字符组成及其顺序；长度仅反映字符数

## 子串、主串与子序列
- **子串**：取主串一段**连续**字符构成的串
  - `S="abcde"`，`"bcd"` 是子串
  - `"ace"` 是子序列，**不是子串**
- **子序列**：保留相对顺序，但元素可以不相邻
- 主串：容纳待查找子串的原串
- 模式串：作为查找目标的串；在匹配问题中也叫模式 `P`
- 非空子串由一个起点和一个长度唯一确定

## 串的长度与位序
- 教材 ADT 常用**字符位序从 1 开始**
  - `S[1]` 是第 1 个字符；`SubString(S, pos, len)` 的 `pos` 也是 1 基
- C/C++ 数组与 `std::string` 默认**下标从 0 开始**
  - 数组 `s[0]` 对应教材第 1 个字符
- **同一解题过程中绝不可混用** 1 基与 0 基
- 本章 KMP 手算与伪码统一采用**教材式 1 基 `P[1..m]`**

## 常见关系与计数
- 长度为 n 的串，**非空子串按起止位置计数**为 $n(n+1)/2$
  - 若包含按位置选取的空区间，可有 n+1 个空区间
  - 按“不同内容”去重后数量可能更少
- 长度为 n 的串共有 $2^n$ 种选取下标的子序列方式
  - 可能对应相同字符内容，不能说一定有 $2^n$ 个**不同子序列**
- 完全相等：长度相同且各对应字符相等

## 真实语言实现对照
- `std::string s`：可 `s[i]`、`s.at(i)`、`s.size()`
  - `at(i)` 检查边界；`operator[]` 不进行相同的越界检查
  - C++ 中常见实现为连续字符存储，但不等于教材定长串
- C 字符串 `char *s` 通常以 `\0` 标识结束
  - `strlen` 不包含终止符，且需从头扫描到终止符
- **编码问题（拓展）**：UTF-8 的 `char` 字节数不必等于可见字符数

## 易错判断
- `"abcd"` 的 `"ad"` 不是子串，只能是子序列
- 空串与空格串不同；空串仍然是**任何串的子串**（按通常数学定义）
- 教材中的“字符位序=1”和 C++ 的“数组下标=0”只是表达约定
- 主串与模式串只是在匹配时的角色，不是不同的数据结构
