# 4.2 串的 ADT · 操作契约

## 创建、赋值、复制
- `StrAssign(&T, chars)`：用字符序列 `chars` 的值生成串 T
- `StrCopy(&T, S)`：把 S 的字符序列复制到 T
- `StrEmpty(S)`：串长为 0 时返回真
- `StrLength(S)`：返回**有效字符个数**，不包含额外保存的长度字段、结束标志
- 注意：参数中 `&` 表示按引用 / 输出参数的教材伪码习惯，并非所有语言中的同一种语法

## 清空、销毁及分配责任
- `ClearString(&S)`：把 S 清为长度 0 的**有效空串**
- `DestroyString(&S)`：销毁对象或释放其存储资源，操作后通常不再认为它是可直接使用的有效串
- **不能简单等同**：“空串”与“被销毁的串”是两种状态
- 堆分配时释放、重新分配规则取决于 ADT 的具体实现
- 定长数组实现可只重置 `length`；不一定逐一覆盖原字符

## 连接、提取与定位
- `Concat(&T, S1, S2)`：T 等于 S1 后接 S2
  - $|T|=|S_1|+|S_2|$
  - 需要考虑目标缓存是否有足够容量
- `SubString(&Sub, S, pos, len)`：提取从位序 `pos` 开始的 `len` 个字符
  - 1 基常见合法条件：`pos≥1`、`len≥0`、`pos+len−1≤|S|`
  - 空子串在末尾的 `pos=|S|+1,len=0` 是否允许须以实现契约为准
- `Index(S,T)`：返回 T 在 S 中**第一次出现**的起始位序
  - 常见王道/教材约定：不匹配时返回 **0**，找到时返回**1 基位置**

## 串比较 `StrCompare(S,T)`
- 从左到右逐字符比较
  - 第一个不等的字符决定结果正负
  - 若公共前缀完全相等，较长串通常排在后面
- `S==T` 返回 0；`S>T` 返回正值；`S<T` 返回负值
- 不要求返回值只能是 `-1/0/1`：正负号才是约定的核心
- 比较顺序依赖**字符编码/排序规则**，不能脱离题目假定

## 典型边界考题
- `SubString("abcde",2,3)` → `"bcd"`（教材 1 基）
- `Concat("ab","cd")` → `"abcd"`
- `Index("ababa","aba")` → `1`；下一次从 3 开始，但首次位置仍是 1
- `Index("abc","d")` → `0`（按上述教材约定）
- `StrCompare("abc","ab")` → 正值（若采用通常字典序）
- 字符串查找对**空模式**的返回约定依 API 不同而变：考研计算题通常设 `m≥1`

## 操作代价：依实现分析
- `StrLength` 若另存有效长度：**O(1)**
- `StrLength` 若仅有 `\0` 结尾、无长度字段：**O(n)**
- 一般串比较最坏 **O(min(n,m))**（再比较长度）
- 复制、连接、提取：需要输出字符，时间通常与处理字符数成正比
- `Index` 的时间取决于匹配算法：朴素 **O(nm)**，KMP **O(n+m)**

## 容易混淆的词
- `Copy`：按值复制，可能申请内存
- `Concat`：串联接，**不是字符串集合运算**
- `Clear` vs `Destroy`：区别在是否仍拥有合法可使用的对象
- 位序 `pos` vs C 字符下标 `pos-1`
