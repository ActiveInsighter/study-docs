## 基本概念

分组说明：概念不能忘了；对应：[基本术语](#focus=%E5%9F%BA%E6%9C%AC%E6%9C%AF%E8%AF%AD)

- 基本术语
  - 节点关系 <img src="/images/408-mind-maps/ds-0050.png" alt="节点关系" width="240" height="120">

    - 祖先 &amp; 子孙
    - 双亲 &amp; 孩子
    - 兄弟
    - 分支结点/非终端节点
      - 度 &gt; 0
    - 叶子结点/终端节点
      - 度 = 0
  - 属性
    - 结点的层次
      - 从根节点（第一层）开始，越往下层数+1
    - 结点的高度
      - 叶子高度为0，自底向上
    - 结点的深度
      - 根节点深度为0，自顶向下
    - 树的高度/深度
      - 结点的层次的最大值
    - 树的路径长度
      - 从根节点开始到每个结点的路径长度之和
        - 结点总数的二叉树，完全二叉树的路径长度最小
    - 结点的度
      - 结点拥有的孩子数目
    - 树的度
      - 树中所有结点的度的最大值
    - 概要：0还是1 ---&gt; 看题目
      概要范围：[结点的高度](#focus=%E7%BB%93%E7%82%B9%E7%9A%84%E9%AB%98%E5%BA%A6)、[结点的深度](#focus=%E7%BB%93%E7%82%B9%E7%9A%84%E6%B7%B1%E5%BA%A6)

  - 路径
    - 两结点之间的路径 (vector&lt;Node&gt;)
      - 路径是由第一个结点到第二个结点的路径，从上到下的
      - 路径是两个节点之间经过的结点序列构成的
    - 两结点之间的路径长度 (int)
      - 路径上边的个数
  - 有序树和无序树
    - 有序树：
      - 每个结点的孩子节点顺序是固定的，不可换
      - 比如：struct是Node\* left, Node\* right
    - 无序树：
      - 每个结点的孩子节点顺序可以改变
      - 比如：struct是vector/set&lt;Node\*&gt;
    - 概要：默认谈的就是有序树
      概要范围：[有序树：](#focus=%E6%9C%89%E5%BA%8F%E6%A0%91%EF%BC%9A)

- 森林
  - 多个互不相交的树的【集合】
- 考点
  - 算结点数和高度、度的关系
- m叉数的性质 <img src="/images/408-mind-maps/ds-0050.png" alt="m叉数的性质" width="240" height="120">

  - 树中节点数 = 所有节点的度数之和 + 1

    - 除了根节点，其他节点都是某个节点的孩子
    - 如果树的节点为n个，则所有结点度为 n-1
    - 也即：具有n个节点的树的边数为 n-1
  - 度为m的树的第i层上至多有

    - 公式 $m^{i-1}个节点$

      - （想象成满m叉树）
  - 高度为h的m叉树最多有

    - 公式 $1 + m + m^2 + .... + m^{h-1} = \frac{ 1 - m^{h}}{1 - m}个节点$

      - （想象成满m叉树）
  - 具有n个节点的m叉树的最小高度

    - 反解上面的h
      - 公式 $log_m(n(m-1)+1)$

  - 批注：举特例

- 考频：中

- 特殊的二叉树
  - 满二叉树
    - <img src="/images/408-mind-maps/ds-0176.png" alt="满二叉树" width="240" height="139">

  - 完全二叉树
    - 和满二叉树的结点编号一样 <img src="/images/408-mind-maps/ds-0061.png" alt="和满二叉树的结点编号一样" width="240" height="139">

      - 三角形缺右下角
  - 二叉排序树
    - 二叉树中的每个结点的值一定比左孩子的大，一定比右孩子的值小
  - 平衡二叉树
    - 树上任意一个结点的左右子树 的深度之差不超过1
      - 会有更高效的排序搜索效率
- 二叉树的常考性质

  - 非空二叉树中度为0、1、2的 结点个数分别为n0, n1, n2 故
    - 总结点数为三种之和
      - n = n0 + n1 + n2
    - 总结点 = 总度数 + 1
      - n = 2\*n2 + n1 + 1
        - n个节点，总度数n-1
    - 可推出： 叶子节点数 = 度为2的节点数 + 1
      - n0 = n2 + 1
  - 完全二叉树
    - 配图

      对完全二叉树从上到下、从左到右依次编号 $1,2,\ldots,n$：

      1. 当 $i>1$ 时，结点 $i$ 的双亲编号为 $\lfloor i/2\rfloor$。$i$ 为偶数时是双亲的左孩子，为奇数时是双亲的右孩子。
      2. 当 $2i\le n$ 时，结点 $i$ 的左孩子编号为 $2i$，否则无左孩子。
      3. 当 $2i+1\le n$ 时，结点 $i$ 的右孩子编号为 $2i+1$，否则无右孩子。
      4. 结点 $i$ 所在层次（深度）为 $\lfloor\log_2 i\rfloor+1$。

      - <img src="/images/408-mind-maps/ds-0187.png" alt="完全二叉树" width="130" height="220">

      - 批注：22年算法题（一半）

- 线索二叉树
  - 逻辑、物理结构定死了
  - 考点：1. 基本概念
    - 每个二叉树都有有很多结点的指针空了，无法利用
      - 给二叉树的每个结点再分别设置左右两个tag标记
        - tag=0 表明左右指针是结点的孩子
        - tag=1 表明左右指针是结点的前驱/后继
      - 批注：n个结点、n-1个边，n+1个空指针
    - 代码：
      - 配图

        ```cpp
        typedef struct ThreadNode {
            ElemType data;                       // 数据元素
            struct ThreadNode *lchild, *rchild;   // 左、右孩子指针
            int ltag, rtag;                      // 左、右线索标志
        } ThreadNode, *ThreadTree;
        ```

  - 2\. 构造
    - 在树的遍历中，设置前后两个结点指针，来进行前驱/后继的连接
  - 3\. 代码查找前驱后继
    - 先序线索二叉树
      - 前驱不好找
      - 后继好找
    - 中序线索二叉树
      - 前驱好找
      - 后继好找
    - 后序线索二叉树
      分组说明：故需要堆栈的支持；对应：[后继不好找](#focus=%E5%90%8E%E7%BB%A7%E4%B8%8D%E5%A5%BD%E6%89%BE)

      - 前驱好找
      - 后继不好找
        - 1\. 如果为根节点
          - 后继为NULL
        - 2\. 如果为双亲的右孩子 or 双亲的左孩子+双亲无右孩子
          - 后继是双亲（rtag = 1 时的rchild）
        - 3\. 其他情况
          - 需要找到双亲右子树的第一个被遍历的节点
            - 无法用过指针找到
    - 概要：访问l/rchild后设置他们的tag和child，以及设置自己的tag和child
      概要范围：[中序线索二叉树](#focus=%E4%B8%AD%E5%BA%8F%E7%BA%BF%E7%B4%A2%E4%BA%8C%E5%8F%89%E6%A0%91)

    - 批注：难、没考过
- 一些树的引申题目：
  - 1\. 已知两节点MN，M是N的祖先，如何找从M到N的路径：
    - 通过【后序遍历 + 辅助栈】的办法就可以找到路径
  - 2\. 在二叉树的前中后序遍历中，叶子结点的访问顺序
    - 完全相同，因为叶子结点一定不是根节点，一定是子树的访问又一定是先左后右的

## 二叉数的应用

- 二叉排序树 （BST）
  - 每个结点：左节点值 &lt; 根节点值 &lt; 右节点值
  - 作用：
    - 用来进行搜索，”排序“体现在建树的过程
  - 算法：
    - 搜索
      - 进行比较，确定向左 or 向右
    - 插入
      - 如果树为空，则直接插入
      - 树不为空
        - 和结点值进行比较，如果比它小，就插到左边
        - 如果比它大，就插到右边
        - 插入时如果发现对应边的结点不为NULL，则继续比较
    - 构造
      - 从零开始一个一个插
    - 删除
      - 如果是叶子结点，直接删
      - 如果只有单子树，则把子树移动上来
      - 既有左子树又有右子树
        - 用直接前驱
          - 左子树的最右
        - 用直接后继
          - 右子树的最左
  - ASL
    - 平均查找长度
      - 查找次数一定不会超过高度，所以BST越矮越好
      - 查找成功
        - <img src="/images/408-mind-maps/ds-0177.png" alt="查找成功" width="240" height="114">

      - 查找失败
        - <img src="/images/408-mind-maps/ds-0174.png" alt="查找失败" width="240" height="116">

          - 失败节点视为等概率，不要钻牛角尖
- 平衡二叉树 （AVL）
  - 定义：树上面任意一个节点的左右子树的高度差不超过1
    - 即左子树高 - 右子树高 = -1, 0, 1
  - 节点数据结构
    - 配图

      ```cpp
      // 平衡二叉树的结点
      typedef struct AVLNode {
          int key;                    // 数据域
          int balance;                // 平衡因子
          struct AVLNode *lchild, *rchild;
      } AVLNode, *AVLTree;
      ```

  - 插入
    - 插入一个节点过后，调整最小的不平衡子树
    - 四种不同的调整
      - LL
        - 右旋，BL &lt; B(※) &lt; BR &lt; A &lt; AR <img src="/images/408-mind-maps/ds-0132.png" alt="右旋，BL &amp;amp;lt; B(※) &amp;amp;lt; BR &amp;amp;lt; A &amp;amp;lt; AR" width="240" height="120">

          - 代码实现就是改几个指针
      - RR
        - 左旋，AL &lt; A &lt; BL &lt; B(※) &lt; BR <img src="/images/408-mind-maps/ds-0103.png" alt="左旋，AL &amp;amp;lt; A &amp;amp;lt; BL &amp;amp;lt; B(※) &amp;amp;lt; BR" width="240" height="114">

          - 代码实现就是改几个指针
      - LR
        - 先对B左旋再对A右旋，BL &lt; B &lt; CL &lt; C(※) &lt; CR &lt; A &lt; AR <img src="/images/408-mind-maps/ds-0072.png" alt="先对B左旋再对A右旋，BL &amp;amp;lt; B &amp;amp;lt; CL &amp;amp;lt; C(※) &amp;amp;lt; CR &amp;amp;lt; A &amp;amp;lt; AR" width="240" height="113">

      - RL
        - 先对B右旋再对A左旋，AL &lt; A &lt; CL &lt; C(※) &lt; CR &lt; B &lt; BR <img src="/images/408-mind-maps/ds-0186.png" alt="先对B右旋再对A左旋，AL &amp;amp;lt; A &amp;amp;lt; CL &amp;amp;lt; C(※) &amp;amp;lt; CR &amp;amp;lt; B &amp;amp;lt; BR" width="240" height="90">

  - 查找效率
    - 树上任意一个结点的左右子树高度只差不超过 1，设n(h)表示为深度为h的平衡树中含有的最少节点数
      - 故有n(h)  = n(h-1) + n(h-2) + 1
        - 批注：第二类数学归纳法
    - 平衡二叉树高度为h，最少的节点数为n，最多的节点数为m：
      - h
        - 0
          - 1
            - 2
              - 3
                - 4
                  - ...
                    - 公式 $O(log_2n) = k$

      - n
        - 0
          - 1
            - 2
              - 4
                - 7
                  - ...
                    - n
      - m
        - 0
          - 1
            - 3
              - 7
                - 15
                  - ...
                    - 公式 $k^2 -1$

    - 故平衡二叉树的查找效率为：
      - 公式 $O(log_2n)$

## 哈夫曼树

- 考频：高

- 定义：
  - 在二叉树中，每一个节点都赋予一个具有意义的数值，称为该节点的权
- 前缀编码：
  - 前缀编码的定义是在一个字符集中，任何一个字符的编码都不是另一个字符编码的前缀。
    - 哈夫曼编码就是前缀编码
- 带权路径长度
  - 结点的：
    - 根到结点的边数 \* 权值
  - 树的：
    - 树中所有【叶子】节点带权路径长度之和 $WPL = \sum_{i=1}^{n}w_il_i$

- 定义
  - n个【带权叶节点】的二叉树中，WPL最小的二叉树称为哈夫曼树

  - 就是离散数学中的集合的概念
    - 只支持查找和合并
- 代码：
  - 初始化
    - 配图

      ```cpp
      // 并查集的结构定义（双亲指针数组）
      #define SIZE 100
      int UFSets[SIZE];

      // 并查集初始化：每个自成单元素集合
      void Initial(int S[]) {
          for (int i = 0; i < SIZE; i++)
              S[i] = -1;
      }
      ```

  - 查找：
    - 配图

      ```cpp
      // 查找 x 所属集合；根结点的 S[x] 小于 0
      int Find(int S[], int x) {
          while (S[x] >= 0)
              x = S[x];
          return x;
      }
      ```

      - 优化：路径合并
        - 把集合最后变成类似“菊花树”的样子

          ```cpp
          // 并查集的查找：路径压缩
          int find(int x) {
              if (x == fa[x])
                  return x;
              else {
                  fa[x] = find(fa[x]);  // 父节点改为根节点
                  return fa[x];       // 返回父节点
              }
          }

          // 同一操作的简写
          int find(int x) {
              return x == fa[x] ? x : (fa[x] = find(fa[x]));
          }
          ```

  - 合并：
    - 配图

      ```cpp
      // 合并两个不相交集合。Root1、Root2 是不同集合的根。
      void Union(int S[], int Root1, int Root2) {
          S[Root2] = Root1;  // 将 Root2 连接到 Root1 下
      }
      ```

- 优化：
  - 查找的时间复杂度和树高一样，所以要控制树高
  - 每次并查集的合并都是小树并到大树里面 $时间复杂度O(log_2n)$

    - 用根节点的”绝对值“来表示当前结点个数，例如-3即为这个树里面有3个节点
    - 合并后树高不会超过 ⌊log2n⌋+1
      - 证明：数学归纳法
    - 实现代码

      ```cpp
      void Union_2(int S[], int Root1, int Root2) {
          if (Root1 == Root2) return;
          if (S[Root2] > S[Root1]) {
              // Root2 中的节点数量少，Root2 合并到 Root1
              S[Root1] += S[Root2];
              S[Root2] = Root1;
          } else {
              // Root1 中的节点数量少，Root1 合并到 Root2
              S[Root2] += S[Root1];
              S[Root1] = Root2;
          }
      }
      ```

        每次 Find 操作先找根，再“压缩路径”，可使树的高度不超过 $O(\alpha(n))$。$\alpha(n)$ 是一个增长很慢的函数；对常见的 $n$ 值，通常有 $\alpha(n)\le4$。因此优化后并查集的 Find、Union 操作的均摊时间开销很低。

  - 优化的总结
    - 初始版本：
      - 用数组、双亲表示法来描述元素之间的集合关系。根节点为-1，非根节点指向父节点下标。
    - Union优化后：
      - 用根节点的负值表示一棵树的节点总数，每次Union的时候是用小树合并到大树根节点下面
    - Find优化后：
      - 使用了压缩路径的策略，每次Find操作先找到了x所属的根节点，再将查找路径上的所有节点都直接挂载到根节点下面。
