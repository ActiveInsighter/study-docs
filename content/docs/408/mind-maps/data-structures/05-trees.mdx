# 第五章 树与二叉树 · 十三节导览

## 基础定义与公式（5.1—5.4）
- [5.1 树的术语与路径](/docs/408/mind-maps/data-structures/05-1-tree-concepts)
  - 双亲、孩子、兄弟、祖先、度、层次、高度、深度
  - 普通树的路径和有序树/无序树
- [5.2 树和 m 叉树性质](/docs/408/mind-maps/data-structures/05-2-tree-properties)
  - 非空树：结点度数之和 = 边数 = n−1
  - 最大每层结点数、最小可能高度
- [5.3 二叉树的类别与结点关系](/docs/408/mind-maps/data-structures/05-3-binary-types)
  - 满二叉树、完全二叉树、二叉排序树、平衡树
  - 非空二叉树：**n0=n2+1**；完全二叉树的度为 1 的结点至多一个
- [5.4 二叉树的两种存储](/docs/408/mind-maps/data-structures/05-4-binary-storage)
  - 顺序编号 i → 父节点 ⌊i/2⌋，孩子 2i、2i+1
  - 二叉链表非空树 n 个结点有 n+1 个空孩子指针

## 遍历及线索（5.5—5.7）
- [5.5 先序、中序、后序与层序](/docs/408/mind-maps/data-structures/05-5-binary-traversals)
  - 根访问次序、递归栈、显式栈、层序队列
- [5.6 遍历序列重建与综合算法](/docs/408/mind-maps/data-structures/05-6-reconstruct)
  - **先中 / 后中 / 层中**可确定唯一二叉树（结点互异）
  - **仅先后**通常不能唯一确定；遍历的叶子访问次序相同
- [5.7 线索化与前驱后继](/docs/408/mind-maps/data-structures/05-7-threaded)
  - 线索占用空链域；ltag、rtag 指示类型
  - 中序前驱/后继易找；先序前驱、后序后继受限

## 树和森林（5.8—5.9）
- [5.8 双亲、孩子、孩子兄弟表示法](/docs/408/mind-maps/data-structures/05-8-tree-storage)

- [5.9 树/森林遍历与二叉树对应](/docs/408/mind-maps/data-structures/05-9-forest-traversal)
  - 先根或森林先序 ↔ 二叉树先序
  - 后根或森林后序 ↔ 二叉树中序
