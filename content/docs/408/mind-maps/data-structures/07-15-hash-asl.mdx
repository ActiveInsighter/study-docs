# 7.15 散列表 ASL · 完整例题

## 题目设置（线性探测）
- 散列表长 $m=11$，函数 $H(k)=k\bmod11$
- 顺序插入 `22、33、44、12、23、34`
- 探测：`H, H+1, H+2, ...` 依次加 1，模 11 循环
- 计数约定：探测**每个槽位**计一次；成功到命中槽为止，失败到遇 EMPTY 为止

## 构表逐项检查
- 22：原始地址0，直接放入 0 → 1 次
- 33：原始地址0；0 已占 → 放 1 → 2 次
- 44：原始地址0；0、1 已占 → 放 2 → 3 次
- 12：原始地址1；1、2 已占 → 放 3 → 3 次
- 23：原始地址1；1、2、3 已占 → 放 4 → 4 次
- 34：原始地址1；1、2、3、4 已占 → 放 5 → 5 次
- 最终 `0..5` 六个槽已满，`6..10` 为空
- 装填因子 $\alpha=6/11$

## 成功 ASL
- 六条已存记录等概率查找
- $ASL_{成功}=\frac{1+2+3+3+4+5}{6}=\boxed{3}$
- **不可**用记录最终地址作为比较次数；要从**原始散列地址**重新探测
- 若各记录访问概率不等，则对比较次数加权，不能除以 6

## 失败 ASL（等概率初始地址）
- 以原始散列地址 $0,1,\ldots,10$ 各出现概率 $1/11$ 为条件
- 查找失败检查次数：`0→7, 1→6, 2→5, 3→4, 4→3, 5→2`
- `6,7,8,9,10` 每个开头都是 EMPTY，各只需 **1 次**
- $ASL_{失败}=\frac{7+6+5+4+3+2+1+1+1+1+1}{11}=\boxed{32/11}$
- 失败概率若按未出现的**具体关键字集合**分布，不应自动套用“初始地址等概率”

## 成功与失败的统计口径
- 成功：实际表里 n 条记录/各成功权重（这里 6）
- 失败：通常按原始地址 m 个位置/各失败权重（这里 11）
- 对拉链法：可定义是否把空桶检查算作一次；要看题目比较计数约定
- 对开放定址法：要明确遇到墓碑时继续、遇 EMPTY 停止

## 算法选择与复杂度
- 即便该例成功 ASL=3，也不能推导所有 11 槽线性探测永远为 3
- $\alpha$ 上升往往使期望查找次数增大，最坏仍可能 $O(n)$
