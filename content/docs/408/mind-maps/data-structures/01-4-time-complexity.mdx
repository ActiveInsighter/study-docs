# 1.4 时间复杂度 · 高频

## 核心分析流程
- 第一步：明确输入规模 `n` 与计数的基本操作
- 第二步：求基本操作次数 `T(n)`，允许忽略与规模无关的常数
- 第三步：保留最高增长阶（渐近表达）
- 第四步：核对循环条件、整除、边界及最好/最坏情况
- 注意：**不一定只需数“最内层循环”**，要结合真实执行次数

## 渐近符号
- `O(g(n))`：渐近上界
- `Ω(g(n))`：渐近下界
- `Θ(g(n))`：渐近紧确界
- 例：若 $T(n)=3n^2+5n+7$
  - 则 $T(n)=\Theta(n^2)$
  - 也可写 $T(n)=O(n^2)$
- 408 通常用大 O 描述复杂度，但它**不等于**严格意义上的 Θ

## 增长速度比较
- 常见阶：
  - $1 \prec \log n \prec n \prec n\log n$
  - $n\log n \prec n^2 \prec n^3$
  - $n^3 \prec 2^n \prec n! \prec n^n$
- 对数底数为大于 1 的常数时，复杂度数量级不变
- 多项式阶只保留最大指数项
- 固定指数的幂函数优于指数函数的渐近增长

## 顺序执行与分支
- 连续片段：$T(n)=T_1(n)+T_2(n)$
  - 以增长较快的一项为主
- 分支：先分析条件判定，再取具体输入路径
  - 最坏：取执行次数最多的分支
  - 最好：取执行次数最少的分支
- 独立循环嵌套：次数可用乘法估算
  - **但循环边界相关时必须求和**

## 基本循环模型
- 单重循环：`i = 0; i < n; i++`
  - $T(n)=\Theta(n)$
- 等比增长：`i = 1; i < n; i *= 2`
  - 迭代次数约为 $\lceil\log_2 n\rceil$
  - $T(n)=\Theta(\log n)$（$n\ge 2$）
- 平方根型：`i = 1; i*i <= n; i++`
  - $T(n)=\Theta(\sqrt n)$
- 三角求和：`for i=1..n: for j=1..i`
  - $\sum_{i=1}^{n}i=\frac{n(n+1)}{2}$
  - $T(n)=\Theta(n^2)$

## 相互依赖的循环
- `for i = 1..n: for j = 1; j <= n; j *= 2`
  - 每层内循环约 $\log_2 n$ 次
  - $T(n)=\Theta(n\log n)$
- `for i = 1; i <= n; i *= 2: for j = 1..i`
  - $1+2+4+\cdots+2^{\lfloor\log_2 n\rfloor}$
  - $T(n)=\Theta(n)$，**不是** $\Theta(n\log n)$
- 注意：循环体中修改控制变量时，不能机械套模板

## 递归与递推
- 二分查找：$T(n)=T(n/2)+\Theta(1)$
  - $T(n)=\Theta(\log n)$
- 归并排序：$T(n)=2T(n/2)+\Theta(n)$
  - $T(n)=\Theta(n\log n)$
- 朴素递归斐波那契：指数级重复子问题
- 方法：递归树、代入展开、主定理（满足适用前提时）

## 高频陷阱
- “二重循环一定是平方阶” → 错
- “对数循环加在 n 循环内一定是 nlogn” → 还要看界限
- “平均复杂度就是最好与最坏的算术平均” → 错
- “忽略常数意味着实际耗时完全相同” → 错
