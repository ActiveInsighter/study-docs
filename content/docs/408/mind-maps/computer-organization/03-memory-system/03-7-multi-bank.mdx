# 3.7 并行主存组织

## 双端口RAM
- 同一个存储阵列设两个独立端口，可分别提供地址、数据与控制接口
  - 不限于“两颗CPU访问内存条”，还用于缓冲与数据交换
- 同时访问**不同地址**通常可并行；同地址同时读通常可用
  - 同地址至少一个写：可能存在读写/写写冲突，需要仲裁或约定优先级
  - busy/冲突检测可暂停一端；不能假定所有双端口实现行为完全相同

## 高位交叉与低位交叉
- 高位交叉：**高位**选择存储体，连续地址大多落同体
  - 有利于按块分配，但连续访存很难掩蔽该体恢复时间
- 低位交叉：**低位**选择存储体，连续地址轮流落不同体
  - 体号 $bank=address\bmod m$（按访问单位对应的地址）
  - 第 $i$ 次可从 $i\bmod m$ 的体发起，利用多个存储体重叠工作

## 时间与体数计算
- 假设一体完整存取周期 $T$，总线允许每隔 $r$ 时间启动新一体（无冲突）
  - 理想连续启动要求 $m\ge\lceil T/r\rceil$，体数少于该值会发生体冲突或等待
  - 连续读 n 个字，第一字在 T 后完成，后续每隔 r 完成：$T_{total}=T+(n-1)r$
  - 示例 $T=80\,\mathrm{ns},\ r=20\,\mathrm{ns}$，至少4体；连续5字耗160ns
- 单体多字：一个存储体一次并行读多个字，在总线上按约定传输
  - 和多体交叉不同：**访问粒度、独立控制与非连续请求性能**不相同
- 并行带宽上界 $\text{每次总线传送字节数}/r$，还受总线协议及存储体实际时序约束
