# 3.10 高速缓冲存储器 Cache

## Cache是什么
- Cache存储主存**块(block)的副本**，通常用SRAM实现；多级缓存常称L1/L2/L3
  - CPU读命中：从Cache取数据；读不命中：从下一级装入块，再完成访问
  - Cache的行(line) = **数据块 + tag + valid + 写策略/替换元信息**
  - 主存块与Cache数据行的**字节大小相同**，但两者总容量完全不同
- 容量常有两种口径：数据容量（行数 × 块大小）与**总物理位数**（加tag等）

## 局部性来源
- 时间局部性：刚访问的地址在短期内再访问；如循环变量、热点指令
- 空间局部性：访问某地址后不久访问同一Cache块内相邻地址
  - C二维数组行优先：`a[i][j]`中 **j连续变化**通常利用连续字节空间
  - 列优先跨行：步长约 $N\times sizeof(element)$，不一定每次都miss
  - 具体命中率要结合每行元素数、数组规模、组相联、对齐和已有缓存状态

## 三类典型Miss（3C）
- 冷启动/强制缺失：第一次访问某块时，不可能已在空Cache中
- 容量缺失：工作集大于能容纳的数据量，理想全相联同容量Cache也会失败
- 冲突缺失：直接/组相联的映射限制导致，同容量全相联本可保存但现在被挤出
  - “替换”和“读缺失”区分：Cache首次装入空行不需要替换已有有效行
- 写策略下写miss是否发生数据块填充，由写分配/非写分配决定

## 快速自测
- 32 KiB数据Cache、64B块 → 512行；若4路组相联 → 128组
  - 32位物理地址按字节编址 → 块内偏移6位、组号7位、tag19位
- 需分开统计：访存次数、块传输次数、miss次数、主存实际读/写次数
