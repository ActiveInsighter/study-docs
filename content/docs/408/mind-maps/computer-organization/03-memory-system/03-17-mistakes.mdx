# 3.17 存储系统易错辨析

## 不要混淆这些层次
- **地址位数**：虚址位宽/物理地址位宽/芯片外部地址引脚/Cache组索引位 ≠ 同一个概念
- **访问单位**：CPU字、主存编址单位、Cache块、虚存页、SSD物理页、闪存擦除块 ≠ 相同粒度
- **性能**：首次响应延迟、存储体恢复周期、突发传输间隔、总体带宽 ≠ 相同指标
- **“随机存取”**：RAM与ROM都可按地址任意读；磁盘通常属于直接访问存储器

## 六组最常考判断
- “DRAM只在读时刷新” → 错：存储单元必须按照刷新时限周期性恢复
- “高位交叉可让连续地址依次访问不同体” → 通常错：连续地址常落同一体
- “Cache tag位数 = 主存块号位数” → 仅全相联（常规物理地址模式）
- “2路组相联每行必有2位LRU” → 错：真LRU可在**每组1位**记录哪路更旧
- “TLB缺失说明当前页不在主存” → 错：可以只需要页表遍历和TLB填入
- “Cache miss就代表缺页” → 错：CPU物理地址已合法，Cache miss常只去主存

## 高质量计算的统一步骤
- 先写明 **bit/B 与 KiB/MiB，按字还是按字节编址**
  - 再拆宽度：地址 → 块号/偏移；块号 → tag/index
  - 题有虚存：先虚页号/页偏移转换，再考虑物理Cache
- 在表中维护访问序列与每组有效数据；替换前更新LRU顺序
  - 遇写操作要标dirty及有无分配；计算主存访问量不能遗漏写回流量
- 总线/外存计算：明确是否“首次访问延迟”“稳态每隔r传一次”“平均机械旋转等待”
