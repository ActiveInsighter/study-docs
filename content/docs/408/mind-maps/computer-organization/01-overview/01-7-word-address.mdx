# 1.7 字长、编址单位与容量

## 常混淆的四类“位宽”
- **机器字长**：机器一次整数运算所能处理的典型二进制数据位数（按教材语境）
- **存储字长**：一个存储字所包含的位数；不一定等于机器字长
- **指令字长**：一条机器指令编码占用的位数；可定长或变长
- **数据通路宽度/带宽**：需先看题意
  - 数据通路**宽度**常用 bit 表示一次并行传输多少位
  - 数据通路**带宽**通常以 bit/s 或 B/s 表示单位时间吞吐能力
  - 两者不是同一物理量；仅“数据总线位数”不能得出每秒吞吐量
- 地址宽度与机器字长也不必相同；如64位CPU可提供少于64位的物理地址位数

## MAR、MDR与主存
- **MAR** 容纳访存地址；在**抽象模型**中，若有效宽度a位，可编码至多$2^a$个不同地址
- **MDR** 保存一次访存传送的数据；其位宽取决于模型的数据传输组织
- 两者的位数与容量关系要满足题目的**寻址单位和接口假设**
- 现代存储控制器、缓存与总线可分层设计：**不能机械认定MAR位数=PC位数或MDR位数=物理总线位数**

## 编址单位决定“一个地址”多大
- 按**字节编址**：每个连续地址代表一个字节（通常8 bit）
- 按**字编址**：每个地址对应一个规定存储字（大小由题目给出）
- 容量公式：$C = N_{address}\times B_{unit}$
  - $N_{address}=2^a$（完整使用a位地址空间时）
  - $B_{unit}$是**每个地址对应的位/字节数**
- 若主存有$2^{16}$个32位存储字，则容量$=2^{16}\times4B=256KiB$
- 若同样16位地址改为**字节编址**，地址空间容量仅$2^{16}B=64KiB$

## KiB/KB及地址空间 vs 实装内存
- $1KiB=2^{10}B$，$1MiB=2^{20}B$，$1GiB=2^{30}B$
- 十进制SI：$1kB=10^3B$，$1MB=10^6B$；考试若未说明常按题给约定
- **逻辑/虚拟地址空间容量不等于物理内存实际容量**
- 地址编码能力是**理论上限**，不等于所有地址都已安装RAM或实际可用

## 典型解题路线
- 先确定：**地址位数 → 编址方式 → 每地址对应位数 → 容量换算**
- 易错：$16$位MAR与$32$位MDR并不自动意味着“容量$2^{16}\times32$bit”
  - 只有题目明确**按32位存储字编址**等前提时可这样计算
