# 1.4 系统软件与应用软件

## 软件的两大类别
- **系统软件**：为应用程序与系统运行提供通用基础服务
  - 操作系统OS：进程、内存、设备、文件、权限等资源管理
  - 编译器、汇编器、链接器、装载器：程序构建与执行支持
  - DBMS：数据定义、查询、事务、权限、恢复等通用管理功能
  - 设备驱动程序、系统工具与相关运行时组件
- **应用软件**：直接服务具体用户任务
  - 文本处理、浏览器、播放器、业务系统、普通数据库应用程序等
- 现实系统的软件分工可能交叠，考试通常按**教材语境的主要职能**分类

## DBMS 与 DBS 的区别
- **DBMS（数据库管理系统）**：一种软件系统，通常属于系统软件
- **DBS（数据库系统）**：数据库、DBMS、应用程序、人员及运行环境的整体
- DBS不是“一个应用软件”，也不是“操作系统安装数据库后就自动成为DBS”
- DBMS通常依赖操作系统/运行环境执行；不能因概念含“系统”就推导为无需OS
- 数据库应用软件是基于DBMS、业务需求开发的具体程序

## 语言处理软件
- 机器语言：以ISA规定的机器指令形式表示，处理器直接执行
- 汇编语言：助记符、符号地址、伪指令等，通常由汇编器翻译
- 高级语言：C/C++、Java等，依实现采用编译、解释、虚拟机、JIT等
  - **编译 != 必然一步从高级语言直接转机器码**
  - **解释 != 必然将每条高级语句翻译成一条机器指令再执行**
- 同一高级语言可由不同实现采用不同执行路线（如字节码与即时编译）

## 典型408判断
- 编译程序是**系统软件**而不是用户层业务应用
- 连接程序/链接器属于**系统支持工具**
- 操作系统提供系统调用接口，不等于所有用户程序都直接控制硬件
- 伪指令由汇编器等工具处理，通常不由CPU作为ISA指令直接执行
