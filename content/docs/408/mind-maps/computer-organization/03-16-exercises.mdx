# 3.16 存储系统高频综合题

## 题型一：芯片组织与引脚
- 目标 `64K×8`，用 `16K×4` → 每组2片，4组 → **8片**
  - 片内地址14位，分组译码2位；按字节编址64KiB地址空间需要16位
- 若题问“总引脚”：按芯片控制引脚与是否复用计算，**不能把内部译码线算作封装引脚**

## 题型二：四体低位交叉
- T=80ns，r=20ns，至少 $\lceil80/20\rceil=4$ 体
  - 连续读取6个字：$T_{total}=80+5\times20=180$ ns
  - 5次访问同一存储体不满足无冲突流水假设，不能照套公式

## 题型三：Cache地址计算
- 物理主存256MiB，Cache8行，每块64B；2路组相联
  - 物理地址28位；偏移6位；组数4→组号2位；tag20位
  - 给定地址a：先 $block=\lfloor a/64\rfloor$，再 $set=block\bmod4$
  - tag = $\lfloor block/4\rfloor$；组内两行由tag匹配与替换状态共同决定

## 题型四：页表/快表与Cache联合
- 32位虚址、4KiB页，VPN20位/偏移12位
  - 查TLB若失效不等于缺页，先查PTE是否驻留
  - PFN与偏移拼接成物理地址，之后再计算Cache tag/index/offset
- 例 $VA=0x12345678$，PFN=`0x89ABC` → $PA=0x89ABC678$

## 题型五：平均访存时间
- Cache查询2ns、miss率5%、**附加**主存惩罚60ns
  - $AMAT=2+0.05\times60=5$ ns
  - 若给出的是包含首次Cache查找的总缺失时间，要重新按加权平均计算
- 注意存取时间与连续传输吞吐、主存带宽/总线宽度是不同问题

## 题型六：磁盘平均访问
- 7200 rpm：平均旋转等待 $30/7200$ s = **4.167ms**
  - 假定平均寻道8ms，传送一个4KiB块有效速率100MiB/s → 约0.039ms
  - 不计控制开销时平均访问约12.206ms；随机IO主要被机械延迟限制

## 通用五步检查
- **题设**：单位、行/页/字/块、编址粒度；**公式**：只选适用模型
- **拆分**：tag/index/offset或VPN/PFN/offset；**过程**：检查合法/命中/替换
- **最终核算**：比特总数/地址区间/性能百分比有无漏乘、重复计数
