# 2.1 数制、编码与差错检验

## 进位计数制与位权
- 基数为 $r$，每位数字取 $0,1,\ldots,r-1$
  - $(d_md_{m-1}\cdots d_0.d_{-1}\cdots d_{-k})_r=\sum_{i=-k}^{m}d_ir^i$
  - 十进制、二进制、八进制、十六进制分别按 10、2、8、16 计权
- 整数十进制→二进制：除2取余，从下往上读；小数：乘2取整，自上往下读
  - 二进制→八进制：小数点两侧分别每3位一组，向高位/低位补零
  - 二进制→十六进制：每4位一组，补零只影响表示长度，不改变数值
- 例 $18.375_{10}=10010.011_2=22.3_8=12.6_{16}$
  - 整数18=16+2；小数0.375=1/4+1/8
  - $0.1_{10}$ 在二进制中循环，有限位不能精确表示
- 为什么用二进制：双稳态器件易实现、抗噪声、布尔运算与电路设计方便

## BCD与机器数
- 真值：人按数学规则理解的实际数值；机器数：按既定编码规则写入的位模式
  - 相同位模式在 unsigned、补码、浮点数下可有不同真值
- **8421 BCD**：十进制每位单独写成4位二进制
  - 例十进制 59 → `0101 1001`（BCD），并非二进制整数59=`00111011`
  - 8421 BCD 六个无效4位码：`1010`～`1111`
- **2421码**：常见加权、自补码；须使用指定编码表，不能把8421形式硬套
- **余3码**：每个十进制数字先加3再按8421编码，属于无权码、自补码
  - 示例十进制5 → 5+3=8 → `1000`

## 字符编码与字节序区分
- ASCII：**7位**编码0—127；通常以字节为单位存储
  - `'0'`=48 (0x30)，`'A'`=65 (0x41)，`'a'`=97 (0x61)
- GB2312传统区位码：区号/位号各从1开始；国标码是在区位码两字节各加0x20
  - 以“啊”为示意：区位16-01 → 国标 `3021H` → 常见内码 `B0A1H`
  - “内码=国标+0x8080”仅适用于这里的特定GB2312双字节转换模型
- Unicode是字符集/码点体系；UTF-8/UTF-16是不同**编码格式**
  - UTF-8为变长字节编码；不能将“一个汉字总占2字节”泛化至现代文本
- 低地址放哪一个**有效字节**属于端序问题；字符数组中逐字节存放的顺序另议
  - [2.9 专讲大端/小端](/docs/408/mind-maps/computer-organization/02-data-representation/02-9-endian-conversion)

## 差错检测与纠正：三个方向
- 奇偶校验：附加1位使1的个数为偶/奇；能发现**奇数位翻转**，不能定位纠错
- CRC：数据多项式 $M(x)$ 补 $r$ 个零，按生成多项式 $G(x)$ 做模2除法
  - 余数为冗余码；接收端除以 $G(x)$ 检查余数是否为0
  - 模2运算是异或，无进/借位；CRC是检错，不是一般性的纠错算法
- 海明码：若有 $m$ 个数据位、$r$ 个校验位，要单比特纠错需 $2^r\ge m+r+1$
  - 校验位通常置于序号1、2、4、8...；综合校验定位出错位置
  - 扩展海明码增加总体奇偶校验可用于SECDED：纠1位、检2位
- 易错：不可将“海明码能纠1位”说成可纠任意多位；CRC是否能发现特定错误取决于多项式与错误模式
