# 7.13 串行帧与通道：边界扩展

## 异步串行有效速率
- 一帧由起始位、数据位、可选校验位、停止位组成
- 如果有效数据 $d$ 位、起始位 $s$、校验位 $p$、停止位 $e$：
  - **线路比特数**：$n=d+s+p+e$
  - **有效数据率**：$R_{\mathrm{useful}}=R_{\mathrm{line}}\,d/n$
- `8N1`：$n=8+1+0+1=10$，有效率80%
- `7E2`：7数据位、1起始、1偶校验、2停止位，$n=11$，有效率 $7/11$
- 题目给的每秒字符数与比特率不等价；要先看**每字符多少帧开销**

## 帧传输时间例题
- 线路速率 $9600\,\mathrm{bit/s}$，采用 `8N1`
- 单字符实际发送10位：$t_{\mathrm{char}}=10/9600\,\mathrm s\approx1.0417\,\mathrm{ms}$
- 有效吞吐约 $960\,\mathrm{B/s}$，不是 $1200\,\mathrm{B/s}$
- 1000个字符纯线路发送至少 $1000\times10/9600\approx1.0417\,\mathrm s$（假定无额外间隔和控制开销）

## CPU忙碌与设备工作可以重叠
- CPU启动外设后，可在设备传输期间执行其他任务
- **任务总历时**按依赖关系和可重叠部分排列，不是机械地“设备时间 + 全部CPU时间”
- **CPU利用率**只统计CPU真正执行相关指令的周期，不把设备独立工作的时间统统算CPU占用
- **中断服务**可能发生在下一字符准备/发送期间，但是否可重叠由题目中的控制流程限制
- 解题先画时间轴：`启动 → 设备工作 → 中断 → 后处理 → 下一次启动`，再判定哪些区间允许并行

## 通道程序是什么
- 通道是具有专用控制能力的I/O处理结构，通常能执行一串I/O通道命令
- CPU通过启动通道降低对每项I/O细节的参与，通道负责设备控制和数据传送编排
- **DMA强调数据搬运离开CPU指令循环；通道进一步强调I/O操作序列的独立控制**
- 具体设备主控、通道与DMA的体系结构实现可能不同，考试通常用教材抽象进行比较

## 最后辨析
- 串行通信“异步”与总线事务“异步握手”是不同层次；都可能不使用统一的固定相位关系
- 帧长度和CPU中断开销是两个独立变量，只有题设明确每帧中断一次时才能直接相乘
