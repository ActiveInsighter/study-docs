## 存储器特点

- 分类：
  - 按作用：
    - 高级缓冲存储器
      - 【即Cache】，位于CPU和主存之间，使CPU能更快速的使用到里面的数据（Cache中的数据是主存中的副本，而缓冲区不是）
    - 主存储器
      - 【即主存/内存】，存放计算机运行时需要的大量的数据，CPU可以直接与其进行访问，也可以和cache交换数据
    - 辅助存储器
      - 【即辅存/外存】，不能与CPU进行直接信息交换
  - 按存储介质：
    - 磁表面（磁盘磁带）、磁心存储器半导体存储器（MOS存储器）、光存储器（光盘）
  - 按存取方式：
    - 随机存取
      - RAM、ROM（只读存储器）
    - 串行访问存储器
      - 对存储单元进行读写时，根据其物理位置的先后进行寻址
      - 例如顺序存取（磁带）
  - 按信息可保存性：
    - 易失型（RAM断电后丢失）
    - 非易失性（ROM断电后不丢失）
    - 破坏性读出（DRAM芯片）
    - 非破坏性读出（SRAM芯片、DISK）
  - 其他
    - DAM直接存取存储器
      - 磁盘
- 性能指标：
  - 存储容量：
    - 存储字数 \* 字长
    - 公式 $2^{MAR位数} * MDR位数$

      - MAR位数：
        - 地址总线个数
      - MDR位数：
        - 数据总线个数
  - 单位成本：
    - 每位价格 = 总成本 / 总容量（bit)
  - 存储速度：
    - 存取时间：
      - 启动一次存储器到最终完成操作所经历的时间
    - 存取周期：
      - 存取时间 + 恢复时间
        - 又称：连续读或者连续写所允许的最短时间间隔
    - 主存带宽：
      - 数据传输率，表示每秒从主存进出信息的最大数量

## SRAM、DRAM

- 考频：低
  - 12、14、15、22
- SRAM
  - Static Random Access Memory
  - 存储元： （几个MOS)
    - 双稳态触发管，6个MOS <img src="/images/408-mind-maps/co-0003.svg" alt="双稳态触发管，6个MOS" width="300" height="141">

      - 了解即可
  - 优点：
    - 速度快，但是【集成度低、功耗大、用来组成高速缓存存储器】
    - 不需要进行刷新
  - 批注：Cache
- DRAM
  - Dynamic Random Access Memory
  - 存储元：
    - 栅极电容
  - 采用技术：
    - 地址复用技术
  - 优点：
    - 集成高、价格低、容量大、功耗低
  - 在工作时存储器内容不会发生改变（即会进行刷新，所以内容不会发生丢失）
  - 现在DRAM被称为SDRAM（例如DDR3，DDR4）
  - 刷新：
    - 每次刷新多少存储单元：
      - 【基础版】一次刷新一整行 <img src="/images/408-mind-maps/co-0010.svg" alt="【基础版】一次刷新一整行" width="300" height="177">

        - 例如有20根地址线，则一共对应有1024 \* 1024根选通线。
        - 刷新顺序：从上到下选n个。每次刷新一行
      - 【行列存储版】把地址分布改为行地址+列地址的存储方式 <img src="/images/408-mind-maps/co-0148.svg" alt="【行列存储版】把地址分布改为行地址+列地址的存储方式" width="300" height="123">

        - 例如有20根地址线，则有1024根行选通线，1024根列选通线 = 2048根选通线。
        - 刷新顺序：从左到右，从上到下。每次选n个一起刷新
    - 刷新周期：
      分组说明：题目没说刷新时间，那就是2ms；对应：[一般取2ms刷新一次](#focus=%E4%B8%80%E8%88%AC%E5%8F%962ms%E5%88%B7%E6%96%B0%E4%B8%80%E6%AC%A1)

      - 一般取2ms刷新一次
    - 刷新算法：
      - 集中刷新：
        - 在一个刷新周期内，在一个固定时间，停止其他操作，把【所有】的存储单元都进行刷新。
        - “死时间”、“死区”
      - 分散刷新：
        - 把每行的刷新分散到各个工作周期内，每个存储周期前半部分用于正常读写，后半部分用于刷新【某一行】（这一行是CPU安排的）
        - 加长了系统的存取周期
      - 异步刷新：
        - 即：集中刷新 + 分散刷新
        - 将刷新周期除以行数，得到两次刷新操作之间的时间间隔 t，则每隔时间t进行一次刷新，刷新【一行】
    - 注意：
      - 透明度：
        - 对CPU透明，不依赖外部的访问
      - 刷新单位：
        - 一行，行地址由CPU自行生成
      - 选片：
        - 不需要选片，对存储器中所有芯片都进行刷新
  - 批注：内存
- SRAM vs DRAM
  - 配图

    |类型特点|SRAM（静态 RAM）|DRAM（动态 RAM）|
    |---|---|---|
    |存储信息|触发器|电容|
    |破坏性读出|否|是|
    |读出后需要重写（再生）|不用|需要|
    |运行速度|快|慢|
    |集成度|低|高|
    |发热量|大|小|
    |存储成本|高|低|
    |易失性|易失，断电后信息消失|易失|
    |需要刷新|不需要|需要|
    |行列地址传送|同时送|分两次送|
    |用途|Cache|主存|

    - 都是易失，只不过一个不需要刷新（SRAM)、一个需要刷新（DRAM)

      - 片选线：
        - 地址复用技术：2根
          - DRAM
        - 否则：1根
      - 读写线：
        - 看题目怎么说
      - 地址线：
        - 地址复用：
          - 地址总线的个数/2
        - 不复用：
          - 地址总线的个数
      - 数据线：
        - MDR的位数
      - 注意一定有【供电线】和【接地线】
  - 总线个数：
    - 例：某DRAM总容量为 64K \* 2B，读写分开控制，问总引脚线数
      - （DRAM默认地址复用）
    - 片：2，读写线2根，（地址线：16根）地址复用线：8根，数据线：16根，供电线+接地线：2根
      - 注意这里的64K = 2^16 = 2^8 \* 2^8，所以在【译码器过后的选通线】有256（行） + 256（列）=512 根线，而在【译码器前的地址总线】处应该只有8根
        - 如果没有地址复用技术：2^16根选通线
      - 30根
      - 批注：64K = 2^16(16根线)，2B = 16bit(16根线)
  - 寻址：
    - 按字节寻址
    - 按字寻址、按半字/双字寻址
      - 要注意一次读写的【字长】为多少

## 只读存储器ROM

- 特点：
  - 不易失、断电不丢失、结构简单、位密度高
  - 写到主板中的，能让系统进入BIOS
    - ROM vs RAM：主板上的 BIOS 芯片属于 ROM，断电不丢失；内存条属于 RAM，断电丢失

- 类型：
  - MROM：
    - 中文：
      - 掩模式ROM(Mask)
    - 特点：
      - 厂商按照要求再生产时直接写入，写入后任何人无法改变内容
      - 可靠性高、便宜、灵活性差
  - PROM：
    - 中文：
      - 一次可编程ROM(program)
    - 特点：
      - 可以实现一次编程（用户可以使用专门的设备），一旦写入，不可改变
  - EPROM：
    - 中文：
      - 可擦除可编程ROM(Erase Program)
    - 特点：
      - 可以多次修改，编程次数有限，写入时间过长
      - UVEPROM紫外线擦除，(E^2)PROM电擦除
  - Flash：
    - 中文：
      - 闪速存储器
    - 特点：
      - 是EPROM的改良，擦除重写速度更快（写比读慢），Flash只用单个MOS，故位密度比RAM高
  - SSD：
    - 中文：
      - 固态硬盘
    - 特点：
      - 由控制单元和Flash组成，读写速度快，低功耗，价格高
- OS的自举装入程序：
  - 引导块
  - 位置：
    - 主板上的ROM的BIOS芯片里
  - 计算机系统中，OS保存在硬盘上，其内存储器应该采用：RAM + ROM
- RAM和ROM的同一编址：
  - 连续编址
- 随机存取
  - RAM和ROM都是可以随机存取的
  - 不可随机存取：
    - 磁带（OS）
- 考频：低
  - 10、15

## 双端口RAM和多模块存储器

- 考频：低
  - 15、17、22
- 双端口RAM：
  - 解决问题：
    - 用于优化多核CPU访问单个内存条的情况
  - 在同一个存储器的左右设置两个独立的端口，分别与两个CPU相连，每个端口都具有独立的地址、数据、控制线 <img src="/images/408-mind-maps/co-0011.svg" alt="在同一个存储器的左右设置两个独立的端口，分别与两个CPU相连，每个端口都具有独立的地址、数据、控制线" width="300" height="131">

    - 四种情况（读写者问题）
      - 时间\\地址
        - 同一地址
          - 不同地址
      - 同时
        - ①都读出 --- 无冲突 ②都写入 --- 冲突 ③写+读 --- 冲突
          - 不会冲突
      - 不同时
        - 不会冲突
          - 不会冲突
    - 解决冲突办法：设置“busy”信号，由逻辑信号决定暂时关闭一个端口（使其延时），未被关闭的正常访问
- 多模块存储器：
  - 解决问题：
    - 在一个存取周期中，存取时间很短，恢复时间非常长
      - 回复时间指：整个存储体的恢复时间
  - 多体并行
    - CPU可以同时快速的取出四条指令
    - 每个模块都有独立的控制电路、地址寄存器、时间寄存器、可以并行+交叉工作
    - 高位交叉编址
      - 高位2bit是对应不同的存储体 <img src="/images/408-mind-maps/co-0281.svg" alt="高位2bit是对应不同的存储体" width="300" height="158">

        - M0 : 00 xxxxxxxx M 1:  01 xxxxxxxx 编程难度大
          - 读完一个数据后，存储体需要进行恢复，恢复完后才能读下一个
        - 举例：

          连续访问地址依次为：

          ```text
          00000 → 00001 → 00010 → 00011 → 00100
          ```

          - 甘特图， 耗时 5T <img src="/images/408-mind-maps/co-0261.svg" alt="甘特图， 耗时 5T" width="300" height="122">

    - 低位交叉编址
      - 低位2bit对应不同存储体 <img src="/images/408-mind-maps/co-0253.svg" alt="低位2bit对应不同存储体" width="300" height="158">

        - 举例：

          连续访问地址依次为：

          ```text
          00000 → 00001 → 00010 → 00011 → 00100
          ```

          - 甘特图， 耗时 T+4r <img src="/images/408-mind-maps/co-0067.svg" alt="甘特图， 耗时 T+4r" width="300" height="142">

  - 流水线式
    - 多体并行 + 低位交叉
      - 模块存取一个字的存取周期为T，总线传送周期是r，为实现流水线方式存取，存储器交叉模块数应大于等于：m = T/r
        - 等于是最好的，不然少了浪费时间，多了浪费钱
        - 每过r周期启动下一个模块，这样当最后一块传完后，第一块又能接上了。
        - 存取m个字，需要T+(m-1)r的时间
  - 单体多字
    - 把多体并行存储器合并在了同一个存储器中，所有存储器共用控制电路、寄存器等等 <img src="/images/408-mind-maps/co-0076.svg" alt="把多体并行存储器合并在了同一个存储器中，所有存储器共用控制电路、寄存器等等" width="300" height="161">

      - 故一次存取都需要读写一整行的信息（可能会读取多余的信息）
      - 速度和多体并行的速度基本完全一致

## 主存储器和CPU的连接

- 总线信号命名：
  - 地址A0 ~ A7，数据 D0 ~ D7
- 主存的基本组成
  - <img src="/images/408-mind-maps/co-0258.svg" alt="主存的基本组成" width="300" height="112">

    - 内存条插槽内有存储器总线
    - 内存条中的信息通过【内存条的引脚】，再通过【插槽内的引线】连接到【主板】上，通过【主板上的导线】连接到【CPU芯片】。
    - <img src="/images/408-mind-maps/co-0069.svg" alt="主存的基本组成" width="300" height="125">

- 位扩展
  - 原因：芯片的字长(bit数)和CPU的字长(bit数)不统一，需要横向连接多块芯片来满足CPU的读取一次时的bit数需求
    - 即：扩展一次性可以读出的数据字长
  - 最开始只有一块芯片的时候（数据线不够） <img src="/images/408-mind-maps/co-0233.svg" alt="最开始只有一块芯片的时候（数据线不够）" width="300" height="150">

    - 例如再连一块 <img src="/images/408-mind-maps/co-0301.svg" alt="例如再连一块" width="300" height="150">

      - 最后连接8块芯片 <img src="/images/408-mind-maps/co-0309.svg" alt="最后连接8块芯片" width="300" height="142">

        - 这样就把八个8K \* 1位的芯片通过【位扩展的方法】扩展为了8K \* 8位的芯片
- 字扩展
  - 原因：芯片的字长和CPU已经满足了，可是CPU的地址总线上还是有很多根没有充分利用。故可以通过在地址中设置片选信号来增加地址数目
    - 即：扩展主存字数
  - 最开始的时候地址线还有3个引脚没有连接 <img src="/images/408-mind-maps/co-0074.svg" alt="最开始的时候地址线还有3个引脚没有连接" width="300" height="174">

    - 法一：线选法，CPU每一根多的地址线就连接着对应的芯片的CS。【这样CPU多了N根线，就可以多连接N个芯片】 <img src="/images/408-mind-maps/co-0314.svg" alt="法一：线选法，CPU每一根多的地址线就连接着对应的芯片的CS。【这样CPU多了N根线，就可以多连接N个芯片】" width="300" height="142">

      - 地址空间不连续
    - 法二：译码片选法，CPU的每一根对应的地址线都连接一个非门和一根线，这样可以控制两个芯片。【所以CPU多了N根线，可以多连接2^N个芯片】 <img src="/images/408-mind-maps/co-0138.svg" alt="法二：译码片选法，CPU的每一根对应的地址线都连接一个非门和一根线，这样可以控制两个芯片。【所以CPU多了N根线，可以多连接2^N个芯片】" width="300" height="140">

      - 译码片选法连接多个芯片(此处选择了A13,A14，所以A15无论是多少都不会改变A0-A14的地址映射）
      - 这样就把4个8K \* 8位的芯片通过【字扩展的方法】扩展为了32K \* 8位的芯片
- 字位扩展法：
  - <img src="/images/408-mind-maps/co-0125.svg" alt="字位扩展法：" width="300" height="133">

    - 两个芯片(16K \* 4)为一组进行【位扩展】，所以机器字长为8bit(16K \* 8)。再将四组通过【字扩展】连接在一起，形成(64K \* 8)的存储空间
    - 地址空间为： 0000 0000 0000 0000 ~ 1111 1111 1111 1111
      - 每个地址对应一个字的数据（此处一个字=1 Byte）
  - 注意CS和WE线

    - 动态平均：
      - 在SSD写入新数据的时候，会优先选择磨损次数少的块进行写入

    - 举例：主存地址空间 256 MB，按字节编址；数据 Cache 有 8 个 Cache 行，行长 64 B（Cache 块与主存块大小相等）

- Cache的替换算法
  - 直接映射：
    - 冲突直接覆盖
  - 组相联和全相联
    - RAND --- 随机算法
      - 随机确定一个替换的块
    - FIFO --- 先进先出算法
      - 将最早调入的行调出
      - 会出现Belady异常、抖动
    - LRU --- 最近最少使用算法
      - 堆栈类算法，在每个cache中添加一个“counter位”
        - 2^n 路组相联，就需要n bit的计数位
      - 举例 <img src="/images/408-mind-maps/co-0026.png" alt="举例" width="240" height="71">

        - 使用counter计数来模拟堆栈的实现，阴影数值越小，说明越新进入Cache
        - counter的值是有范围的 0 ~ 2^n-1，不会超过
    - LFU --- 最不经常使用算法
      - 每行都添加一个counter位，在一段时间内，每被访问一次，counter++。换出时把counter最小的换出
        - 没有遵循局部性
        - counter的大小未知
  - 批注：与OS的请求分页置换算法一致
- Cache的写策略
  - 原因：Cache存储的是主存内容的副本，当Cache内容进行变更时，需要使得Cache和主存的内容保持一致
  - 写命中
    - 全写法/写直通法
      - 把数据同时写入Cache和主存
      - 当需要进行替换时，可以不做其他操作，直接进行替换操作
      - 优化【CPU对主存的访问次数过多】：
        - 写缓冲
          - 在Cache和主存中加入一个写缓冲，CPU写数据到写缓冲中，写缓冲再自行控制将数据写入主存
    - 写回法
      - CPU只对Cache进行修改
      - 在Cache的每一行中添加一个脏位
        - 如果要进行Cache块置换的时候，如果发现该行的脏位为 1，则需要把该Cache块写回内存
  - 写不命中
    - 写分配法
      - 每次写不命中，都先把这个数据块写入到Cache中，然后把数据修改到Cache中，设置脏位为 1
    - 非写分配法
      - 每次写不命中，只写入主存，不进行调块
  - 通常搭配
    - 【全非】全写法 + 非写分配法
      - 写命中同时写回Cache和内存，写不命中只写回内存
    - 【回写】写回法 + 写分配法
      - 写命中只写入Cache并修改脏位，写不命中则把块调入到Cache中，并只修改Cache
    - 多级Cache的混合搭配
      - <img src="/images/408-mind-maps/co-0021.png" alt="多级Cache的混合搭配" width="240" height="44">

        - CPU -&gt; Cache -&gt; L2 Cache
          - 采用的是全写法 + 非写分配法（因为有写缓冲）
        - Cache -&gt; L2 Cache -&gt; DRAM
          - 采用的是写回法 + 写分配法
      - 离CPU越远，容量越大，速度越慢
        - Cache 存 L2 Cache 的复制 L2 Cache 存 DRAM 的复制
- 考频：超高
  - 09\*2、12、14、16、17、21、22、10大、13大、16大、20大

      - 利用局部性原理，如果在TLB中命中，就可以不用去内存中查询慢表了（少了一次内存访问）
    - 采用：全相联映射/组相联映射
      - 快表同样可以采用所有Cache的映射方式和替换算法

    - TLB命中了，主存一定命中
      - Cache命中了，主存也一定命中

        - CPU给出虚拟地址&lt;虚页号 + 页内地址&gt;
        - OS层：
          - 解析虚页号，查快表
            - 若命中了直接跳到合成物理地址
          - 若没命中，首先定位到页表寄存器，获得页表始址 + 页表大小，如果页表溢出了就报错

- 虚存 和 Cache
  - 相同处
    - 都提高了系统性能，两者都有容量、价格、速度等的梯度
    - 都把数据分成了若干块，虚存的块更大(页面大小) ，Cache的块更小(内存块大小)
    - 都有地址映射、替换算法、更新策略
    - 都运用了局部性原理
  - 不同处
    - Cache解决系统速度问题
      - 虚存解决主存容量问题
    - Cache纯硬件实现，对所有程序员都透明
      - 虚存对系统程序员不透明
    - Cache不命中对速度影响没有虚存不命中的影响那么大
      - Cache不命中：读内存
      - 虚存不命中：读外存
    - Cache不命中时，CPU直接访问主存
      - 虚存不命中时，只能先把硬盘的数据调入内存，再与CPU通信
    - 概要：Cache - 空间换时间；虚存 - 时间换空间。
