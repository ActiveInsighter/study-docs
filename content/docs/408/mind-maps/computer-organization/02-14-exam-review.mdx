# 2.14 数据表示和运算 · 题型汇总

## 四个贯通型计算问题
- **题1：相同位串不同解释**
  - 8位 `11111101`：无符号=253；补码=−3；原码=−125；反码=−2
  - 求8位补码加法 $(-3)+5$：`11111101+00000101=00000010`，结果2，CF=1但OF=0
- **题2：CF和OF同时判断**
  - 8位 `7Fh+01h=80h`：OF=1、CF=0、SF=1、ZF=0
  - 8位 `FFh+01h=00h`：OF=0、CF=1、SF=0、ZF=1
- **题3：乘法结果截断**
  - 8位有符号 $100\times2=200$ 超出−128～127
  - 16位完整结果 `00C8H`；若只留低8位 `C8H`，按补码解释为−56
  - 高8位 `00H` **不是**低8位符号的扩展 `FFH` → 有符号乘法溢出
- **题4：IEEE 754解释**
  - `3F800000H`=binary32的1.0；同位模式当uint32是1065353216
  - `80000000H`=binary32的−0；作为int32是−2147483648
  - 不可只按十六进制位串判断“是什么数”

## 高频公式复盘
- $w$ 位无符号范围 $0$～$2^w-1$
- $w$ 位补码范围 $-2^{w-1}$～$2^{w-1}-1$
- 补码负数编码 $2^w-|x|$
- 补码加减 $A-B=A+\overline B+1\pmod{2^w}$
- 加法OF：符号位输入进位 $\oplus$ 输出进位
- 全加器：$S_i=A_i\oplus B_i\oplus C_{i-1}$，$C_i=A_iB_i+(A_i\oplus B_i)C_{i-1}$
- binary32 正常：$(-1)^s(1+F/2^{23})2^{E-127}$
- binary32 次正规：$(-1)^s(F/2^{23})2^{-126}$
- 最小正binary32次正规 $2^{-149}$，最小正常 $2^{-126}$

## 最容易在选择题中扣分的判断
- **CF=1并不说明有符号溢出**；OF=1也不一定有无符号进位
- “补码只有一个零”成立；原码/反码有两种零码
- “负数算术右移相当于除2”要注意舍入方向
- “IEEE754阶码等于标准移码首位取反”是混淆偏置量
- “float尾数23位所以只有23位精度”错：正常数含隐藏有效位1，总精度24位
- “小于最小正常浮点数就变为零”错：可能存在次正规数
- “C里signed溢出和unsigned溢出相同”错：C语义不同
- “Intel唯一小端、Java唯一大端”错：端序依据具体平台/格式
- “所有未对齐访存必然分两次”错：涉及实现与地址边界

## 先做的自测题与答案
- Q1：8位 `10000000` 的补码与无符号值？
  - A：−128与128；取负仍是同一位串，但数学+128无法用int8表示
- Q2：8位 $127+1$ 的OF/CF？
  - A：OF1、CF0
- Q3：8位 $5-7$，按借位为CF的约定，CF/OF？
  - A：CF1、OF0
- Q4：4字节 `12345678H` 从低地址开始存 `78 56 34 12` 是什么端序？
  - A：小端
- Q5：IEEE754单精度最小正次正规数？
  - A：$2^{-149}$
- Q6：单精度为什么无法精确保存$2^{24}+1$？
  - A：正常有效精度24位，在该区间步长为2
- Q7：$m=11$ 位数据采用单错纠正汉明码，最少几个校验位？
  - A：$r=4$，因为$16\ge11+4+1$
- Q8：为什么 C 中 `short(-4096)` 转 `unsigned int` 与先转 `unsigned short` 再转 `unsigned int` 不同？
  - A：前者按有符号负值取32位模，后者先在16位取模并零扩展
