# 3.3 DRAM刷新与定时

## 刷新基本原理
- 目标：在电荷衰减到不可判定前对每个**行**完成周期性再生
  - 一般按行刷新，由存储器控制器/DRAM内部电路调度，不由CPU逐行直接生成刷新地址
  - 刷新暂停或影响正常访问，体现为延迟、吞吐量与能耗开销
- 题中的“每 $2\,\mathrm{ms}$ 刷新一次”仅是**具体教材例题条件**，绝非 DRAM 的统一规格
  - 工程上刷新时限受芯片规范、温度及器件特性影响

## 三种经典教材组织
- **集中刷新**：在规定时间窗口连续刷新所有行
  - 优点：其余时间读写可用；缺点：出现集中**死区/死时间**
- **分散刷新**：把正常访存和刷新分配在连续工作周期的不同阶段
  - 优点：没有长时间集中死区；代价：可能拉长每次访问的存储周期
- **异步刷新**：把一轮刷新分散到刷新期限内，如每隔固定时间刷新1行
  - 刷新间隔 $\Delta t=T_{ref}/R$（R 为行数，忽略调度余量）
  - 例：$R=256$，$T_{ref}=2\,\mathrm{ms}$ → 每隔 $7.8125\,\mu\mathrm{s}$ 处理一行
- 刷新本质是“**全部行在期限内至少刷新一次**”，不等于每次刷新整个阵列

## 时序与考题
- 存储器总周期 $T_c=T_{access}+T_{recovery}$ 属教材简化模型
  - DRAM真实时序还含行激活、预充电和列访问约束；不把CAS延迟直接当全部访问时间
- 有256行，每行刷新占用0.1μs，一轮集中刷新占 $25.6\,\mu s$
  - 在 2 ms 周期下集中刷新的不可访问比例 $25.6/2000=1.28\%$
  - 对于异步刷新，计算**平均间隔**同时核对每行最晚刷新期限
- 常见误区：刷新按“列”进行、每个存储单元独立刷新、刷新由CPU软件逐次发起
