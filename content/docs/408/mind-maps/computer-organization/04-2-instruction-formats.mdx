# 4.2 指令格式：操作码与地址字段

## 一条指令由哪些字段组成
- 操作码OP：指定操作类别；定长n位可表示**至多**$2^n$个不同编码
  - 保留码、扩展前缀等使“实际指令种数”可能小于编码总数
- 操作数/地址字段：可以是寄存器编号、主存形式地址、立即数或偏移量
  - 地址字段**不一定**表示“存储器地址”；需结合寻址方式解释
- 其他字段：寻址方式、数据宽度、条件/标志、指令扩展等

## 按显式地址字段数分类
- **零地址**：`OP`
  - 例：NOP、HLT；或隐含栈顶两个操作数的栈式ADD
- **一地址**：`OP A1`
  - 单操作数：$M[A_1]\leftarrow f(M[A_1])$
  - 累加器型双操作数：$ACC\leftarrow ACC\operatorname{OP}M[A_1]$
- **二地址**：`OP A1 A2`
  - 按这里约定：$M[A_1]\leftarrow M[A_1]\operatorname{OP}M[A_2]$
- **三地址**：`OP A1 A2 A3`
  - $M[A_3]\leftarrow M[A_1]\operatorname{OP}M[A_2]$，保留源操作数
- **四地址**：`OP A1 A2 A3 A4`
  - 前三个字段为操作数地址，第4字段指定后继指令地址（教学模型；现代机器一般靠PC/分支控制）
- **注意**：这里的 $M[A_i]$ 是为了计数给出的“主存直接寻址”假设，实际寄存器操作不按该式访问主存

## 地址位数与空间
- 假设**32位定长指令 + 8位OP + 地址字段均分剩余位**
  - 一地址：24位地址码，$2^{24}=16$Mi个可编码地址（若按字节编址为16MiB）
  - 二地址：各12位，分别可表示$2^{12}=4096$种地址
  - 三地址：各8位，分别$2^8=256$种地址
- **不是**：32位机器一定使用32位指令；地址字段也未必均等分配

## “访存次数”有条件
- 直接主存型单地址自增：取指1 + 读数据1 + 写数据1 = **3次主存访问**
- 隐含ACC双操作数：取指1 + 主存读1 = **2次**（结果存寄存器）
- 主存型二地址加法：取指1 + 读取2个操作数2 + 写回1 = **4次**
- 以上是**经典无Cache、指令完整一次取出**的模型；寄存器/多字指令/实际总线访存不同

## 常问判断
- 地址字段越多，固定长度下每个字段可用位数通常越少
- 操作码越长，可分配给地址字段的位数通常越少
