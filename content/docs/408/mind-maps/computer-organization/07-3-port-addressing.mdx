# 7.3 I/O端口编址：独立或统一

## 独立编址（I/O映射）
- 主存地址空间与I/O端口地址空间**彼此独立**；相同数值可分别指向内存和I/O端口
- CPU通常提供专门的I/O读写指令与控制信号，例如某些ISA中的 `IN/OUT`
- 优点：端口地址空间分离；对主存地址空间占用较少
- 局限：指令集需要支持相应访问方式，编程访问模型不如普通内存统一
- <img src="/images/408-mind-maps/co-0293.svg" alt="独立编址：内存与I/O端口分离" width="520" height="360">

## 统一编址（内存映射I/O，MMIO）
- I/O寄存器占据**统一的物理地址空间**中的某些地址区间
- CPU可通过允许的访存指令读取/写入映射寄存器
- 优点：地址访问模型和部分寻址方式统一，简化指令集对专用I/O指令的依赖
- 局限：占用物理地址区间；设备寄存器具备副作用，对缓存、乱序与访问宽度有特殊约束
- <img src="/images/408-mind-maps/co-0091.svg" alt="内存映射I/O：内存与设备端口使用统一地址空间" width="520" height="360">

## 三个必须区分的“地址”
- **虚拟地址**：用户进程或内核的程序视角，由MMU及映射权限决定具体地址转换
- **物理地址**：系统物理地址空间中的目的地，可能指向DRAM，也可能指向MMIO寄存器
- **I/O端口号**：独立编址体系的另一类地址，数值与内存地址互不冲突
- 用户态能否直接访问端口或MMIO，取决于体系结构与OS权限；**系统调用不是一条“物理I/O指令”**

## 考点对比与误区
- **“统一编址”不是把设备的数据自动存进主存**；它只是将接口寄存器映射到地址空间
- **“独立编址”不代表I/O控制器只能经CPU搬运数据**；DMA同样可与独立端口编址系统并存
- 笼统说内存映射I/O“一定只用普通访存指令”不够精确：实际还需遵守设备内存属性和访问屏障
