# 6.3 总线层次与组织结构

## 分类的三条轴线
- **按所在范围**：片内总线、系统总线、外部通信接口/互连
- **按传输方式**：并行总线、串行链路
  - 并行受引脚数量、时钟偏斜、串扰等约束
  - 高速串行通过差分信号、编码/均衡、多个lane实现高吞吐
  - **并行不一定比串行快**；需比较有效数据率
- **按组成结构**：单总线、双总线、三总线及层次化桥接

## 单总线系统结构
- CPU、主存与I/O接口共用一组系统总线
- <img src="/images/408-mind-maps/co-06-readable-0164.svg" alt="教材单总线结构：CPU、主存与I/O接口共享系统总线" width="700" height="241">
- 优点：硬件简单、扩展便捷、成本较低
- 缺点：带宽共享、争用大、外设可能拖慢共享通路
- 不意味着所有设备绝对不能并发执行内部操作
  - 但**同一共享通路**的冲突事务通常不能同一时刻无条件并行传输

## 双总线结构：主存总线与I/O总线
- 主存总线面向CPU、主存，I/O总线连接接口/外设
- <img src="/images/408-mind-maps/co-06-readable-0056.svg" alt="教材双总线：主存总线与I/O总线由通道或桥接部件连接" width="700" height="373">
- 优点：低速I/O与高速访存流量分层，减轻共享路径负担
- 代价：桥接/通道硬件、协议转换与管理复杂度
- 双总线不自动保证所有I/O与访存完全并行，取决于桥接、仲裁和数据路径

## 教材三总线结构
- 将主存、I/O与DMA的主要传输通路区分
- <img src="/images/408-mind-maps/co-06-readable-0053.svg" alt="教材三总线示意：CPU/主存/I/O与专用DMA路径的关系" width="700" height="361">
- DMA面向高速块传输，减少CPU逐字搬运开销
- **模型需按题图解释**，实际架构可能共享存储控制器，不保证DMA专用总线总是物理存在

## 现代体系结构：不要套用经典图
- CPU/内存控制器内部互连、片上网络、PCIe交换结构可能是多层次互连
- PCIe是点到点高速串行链路，不是传统多点共享并行系统总线
- 学习时先识别题目采用**教材单/双/三总线模型**还是**现代协议模型**

## 考点速辨
- 单总线：**低成本，但争用明显**
- 双总线：**主存与I/O路径分层**
- 三总线：**教材中引入更直接的DMA传输通路**
- 区分三种总线图时看连线，不要仅背“并发性高/低”的绝对判断
