# 6.5 带宽题：先建模，再代入

## 解题模板
- 第一步：确认问题问**峰值带宽**、**有效带宽**还是**传一块数据需多久**
- 第二步：记录数据通路$W$bit、频率$f$、每周期传输数$r$、通道数$C$
- 第三步：画事务相位：地址$a$拍、等待$w$拍、有效数据$d$拍、其他控制$h$拍
- 第四步：判断是否有突发共享地址开销、重叠传递、流水化、独立通道与全双工
- 第五步：统一单位并注明假设

## 例题一：普通同步总线
- 32-bit，100MHz，每拍传1个数据字，传输完全连续
  - 单次数据4B，1拍10ns
  - $B_{peak}=4\times10^8$B/s = **400MB/s**
- 若每次事务先耗1拍地址、再1拍数据且不重叠
  - 2拍仅4B → $B_{\mathrm{eff}}=4/(20\,\mathrm{ns})=200\,\mathrm{MB/s}$
  - 两个数字不可混为一谈

## 例题二：普通读与突发读
- 每节拍10ns、数据宽32bit，连续读取4个数据字
- **非突发**：每字1拍地址+1拍数据；无额外等待且无重叠
  - $T=4(1+1)\times10=80$ns，16B / 80ns = **200MB/s**
- **突发**：只发1拍首地址，其后4拍各传一个数据字
  - $T=(1+4)\times10=50$ns，16B / 50ns = **320MB/s**
- 对照：数据相位峰值仍为400MB/s；突发有效平均是320MB/s
- **注意**：只有题目明确后续4拍可连续交付且无等待，50ns才成立

## 例题三：DDR与通道数
- 64-bit、200MHz、每周期双沿传数据
  - $B_{\mathrm{peak}}=8\times200\times10^6\times2=3.2\times10^9\,\mathrm{B/s}$ = **3.2GB/s**
- 双通道若两条独立且可同时满载 → 合计6.4GB/s
- 有效带宽若为峰值的75%：单通道2.4GB/s

## 例题四：线速与有效载荷
- 串行链路原始线速8Gb/s，采用8b/10b编码，忽略其他开销
  - 有效编码净速率$8\times8/10=6.4$Gb/s
  - $6.4/8=0.8$GB/s = 800MB/s
- 若再有协议包头/校验/填充，则应用有效带宽更低

## 三种计算题“不要套公式”的情况
- **有重叠流水**：地址相位与下一事务数据相位可重叠，不能无条件相加
- **有随机等待**：需平均或按题设逐项累计
- **有双向合计**：全双工才可能将同时双向吞吐相加；单方向不能乘2

## 随堂自测
- Q：16-bit、50MHz、SDR，连续不间断传输的峰值？
  - A：$2\times50\times10^6=100$MB/s
- Q：总线1拍地址+3拍数据，宽64bit且100MHz，无重叠，效率？
  - A：有效数据相位占$3/4$，峰值800MB/s，有效600MB/s
