# 6.2 总线信号线与传输方向

## 系统总线的逻辑组成
- **数据总线 DB**：传输载荷/数据，通常可按事务双向传送
  - 数据线宽度 $W$ bit：一个数据传输节拍可并行传输的位数（以题设为准）
  - **不要混淆**CPU机器字长、存储字长、数据总线宽度，三者不必相等
- **地址总线 AB**：指定存储单元或I/O端口
  - 传统模型下CPU为主，向地址总线输出目标地址
  - 若地址总线有 $n$ 根且能独立寻址，最多形成 $2^n$ 个地址编码
- **控制总线 CB**：读/写、有效、请求、允许、确认、中断、时钟等控制/状态
  - **不一定单向**：CPU向外发读/写命令，设备可向内送就绪、中断等信号

## 地址空间计算
- $n$ 根地址线的可区分地址数是 $2^n$，不自动等于 $2^n$ 字节
- **按字节编址**：每地址对应1 B → 理论空间 $2^n$ B
- **按字编址**：每地址对应一个 $k$ B 的字 → $2^n k$ B
- 独立I/O编址与统一编址的意义
  - **统一编址**：I/O寄存器占用部分存储地址空间；仍受实际地址译码影响
  - **独立编址**：I/O有专用端口地址空间与对应控制命令
  - 详见[第七章I/O系统](/docs/408/mind-maps/computer-organization/07-io-system)

## 总线复用
- 地址/数据复用：**同一组引脚**在不同时间承载地址与数据
  - 可能减少引脚数量，却增加控制及多路复用开销
  - **物理信号线总数**不必等于逻辑地址位宽+逻辑数据位宽
- 非复用：地址与数据有独立通路，允许更灵活的重叠传递（受协议约束）
- 与DRAM**行/列地址分时**及网络NAT“地址转换”不是同一机制

- 寄存器、ALU、内部Cache等通过片内通路协调工作

## 高频选择题陷阱
- 32根地址线、32位数据总线**不意味着**机器字长必为32位
- “数据总线只能单向”错；“控制总线只由CPU输出”也错
- 地址总线根数控制可编码地址数量；可访问物理容量还与编址单位、控制器和映射有关
