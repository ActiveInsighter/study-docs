# 2.2 定点数与常见机器表示

## 有符号和无符号、定点整数与小数
- 无符号 $w$ 位整数范围 $0\le x\le 2^w-1$
  - 例8位：`11111111` 按无符号解释是255
- 有符号数编码通常用最高位表达符号，但**不能只看符号位就确定整个位串的真值**
  - 原码、反码、补码、移码的解释不同
- 定点整数：规定小数点在末位之后；定点纯小数：在符号位之后
  - 纯小数数值位 $n$ 位，量化步长 $2^{-n}$

## 原码：符号与绝对值分开
- 正数符号位0；负数符号位1；其余 $n=w-1$ 位保存绝对值
  - $w$ 位整数可表示 $[-(2^n-1),2^n-1]$，有 `+0`、`-0`
  - $n$ 位小数数值部分：$[-(1-2^{-n}),1-2^{-n}]$，同样两个零
- 8位举例：+14→`00001110`，−14→`10001110`
- 优点：数值直观；缺点：正负加法不能无条件直接按位相加

## 反码：负数数值位取反
- 正数与原码相同；负数符号位仍为1，其余数值位逐位取反
  - 8位 −14 的反码为 `11110001`
- 表示范围与原码相同；存在 `000...0` 与 `111...1` 两个零
- 反码可作为教学中求补码的中间步骤；不等于“所有硬件先产生反码再加1”

## 补码：统一加减法
- 正数和零编码不变；负整数的 $w$ 位补码为 $2^w-|x|$
  - 8位 −14 → `11110010`；`11111111`=−1
  - 8位补码只有一个零；`10000000`=−128
- $w$ 位整数表示范围 $[-2^{w-1},2^{w-1}-1]$
  - 例8位：−128～127，负值比正值多一个
- 定点纯小数 $n$ 位数值：$[-1,1-2^{-n}]$
  - 最小机器数 `1.000...0` 表示−1（补码小数约定）

## 移码：偏置适合阶码比较
- 教材通常以 $w$ 位整数给出 $[x]_{\mathrm{移}}=x+2^{w-1}$
  - 与同位宽补码**最高位取反**等价；真值范围不变
- 8位：−128→`00000000`，0→`10000000`，127→`11111111`
- 固定位宽同一偏置下，移码按无符号大小排序与真值排序一致
- IEEE754阶码偏置是 $2^{k-1}-1$，**不能把二者混为一谈**
