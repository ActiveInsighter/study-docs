# 4.7 数据寻址（三）：基地址 + 位移

## 三大经典偏移寻址
- **PC相对**：$EA=PC_{base}+\operatorname{signext}(A)$
  - 常用于分支或PC相对取数；PC基准由ISA定义，常取已取指后的下一指令地址
- **基址**：$EA=R[BR]+\operatorname{ext}(A)$
  - 某基址寄存器给出存储区起点，A为相对偏移；有助于装载重定位/区域访问
  - 教材常说“基址寄存器由OS设置”，但不同ISA可用普通寄存器且由编译器/程序管理
- **变址**：$EA=A+R[IX]$
  - 适合数组、循环：A表示数组基地址，IX表示元素位移
  - **本质上基址/变址都做地址加法，区别主要在用途与寄存器管理约定**

## 可计算的数组例子
- 数组首地址2000，元素4B，访问下标i=7
  - 变址寄存器若存**字节偏移**28，则EA=2000+28=2028
  - 若IX仅存元素序号7，需额外乘4，**不能直接**当字节地址相加

## x86复合有效地址
- 典型32/64位x86内存形式：`[base + index*scale + disp]`
  - scale∈{1,2,4,8}；某些寄存器不能充当编码中的index
  - 示例`[ebx + esi*4 + 12]`：EBX=1000，ESI=5 → EA=1032（十进制）
  - `LEA`只计算EA，不读取$M[EA]$；`MOV`从该地址取数据才访问主存

## 变式：有效地址与读写操作数
- 求EA只需读取PC/BR/IX和立即数字段，**地址计算本身不等于一次主存访问**
- `LOAD R1,[BR+A]`：计算EA后读取主存**1次**（不计取指）
- `STORE R1,[BR+A]`：计算EA后写主存**1次**（不计取指）
