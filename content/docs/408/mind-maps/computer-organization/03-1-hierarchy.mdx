# 3.1 存储器基本概念

## 分类的不同维度
- 按位置：寄存器 → Cache → 主存 → 辅存
  - CPU 可按体系结构直接发起对寄存器和主存的访问；磁盘需经 I/O 控制器
  - Cache 保存主存某些**块的副本**，不等于任意软件缓冲区
- 按存储介质：半导体 SRAM/DRAM/Flash；磁记录 HDD/磁带；光存储
- 按存取方式：RAM（随机访问）/ 顺序访问 SAM（典型磁带）/ 直接访问 DAM（磁盘）/ 相联访问 CAM
  - **ROM也可随机读取**，只读不等于顺序访问
  - 硬盘读取任意位置需要寻道/旋转，随机读延迟并不等于常数
- 按断电保持能力：SRAM/DRAM 易失；ROM/Flash/HDD 非易失
  - “破坏性读出”与“易失性”是不同维度：DRAM读后需要再生，SRAM不需要

## 三个性能指标
- 容量：**可寻址存储单元数 × 每单元位宽**
  - 例：`64K × 8 bit = 64 KiB`；这里 `K=2¹⁰`，与厂商磁盘标称十进制 GB 区分
  - 可用地址位数为 a、每个地址指向 b bit 时，容量为 $2^a b$ bit
  - **不能脱离总线与编址单位认定 `MAR×MDR` 就是主存容量**
- 存取时间 $T_a$：发出访问到获得有效结果/完成操作的延迟
  - 存取周期 $T_c$：连续两次独立访问所需最小间隔，一般 $T_c\ge T_a$
  - 延迟短不一定持续传输带宽高：内存通道、突发传输、并行体数均影响带宽
- 带宽：每秒可传输的信息量，$B=\text{一次传输字节数}/\text{传输间隔}$
  - 峰值带宽是理想上界；实际还受仲裁、读写切换、刷新与访问模式约束

## 为什么要分层
- 速度、容量、成本无法同时最优；越靠近 CPU 常见情况越快、越小、每 bit 更贵
- 寄存器/Cache 解决**访问速度**；主存提供运行时工作集；辅存提供大容量持久保存
- Cache—主存之间以块传送；主存—磁盘之间通常按页/块，由操作系统参与
- 命中与局部性：时间局部性（近期再次访问）/ 空间局部性（附近地址很快访问）
  - 计算题先辨别 **bit、B、KiB、MiB** 与编址单位
