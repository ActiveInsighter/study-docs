# 5.17 从一个核心到多个核心

## 硬件多线程的三种调度
- **粗粒度**：一个线程运行较长时间，遇到较长停顿（例如Cache miss）才切换
  - 切换线程可有流水线重填或切换开销
- **细粒度**：在相邻时钟周期轮流发射不同线程的指令
  - 各线程流水阶段可交错，提高延迟隐藏能力
- **SMT（同时多线程）**：单核心同一时钟可从多个线程向不同发射槽发射指令
  - 典型超线程属SMT思想；同一核的执行端口、Cache和带宽仍被线程争用
- “细粒度=同一周期同时发两个线程”错误；同拍多线程通常属于SMT

## 多核与多处理器
- 多核：单个处理器封装/芯片中有多个CPU核心
- 多处理器：系统包含多个处理器；和多核配置可以同时存在
- 常见层级：每核心私有L1、可能私有/共享L2、多核心共享LLC（例L3）
  - **哪级Cache共享没有固定规则**，以真实架构为准

## 共享内存：UMA与NUMA
- **UMA**：各处理器访问同一共享物理地址空间，平均访存延迟大体相近
- **NUMA**：同一共享地址空间，访问本地内存比远端内存通常更快
  - NUMA并非ASMP的同义词；对称多处理也可采用NUMA结构

## Cache一致性与同步
- 多核各有Cache时，同一共享变量的多个副本需要**一致性协议**维护合理可见性
  - MESI等协议是典型实现；一致性不能代替**内存顺序模型/线程同步**
- 自旋锁用原子读-改-写操作获得互斥；等待期间忙轮询消耗CPU时间
  - 适合极短临界区；长等待/单核抢占场景通常不宜无条件忙等
- 线程迁移到远NUMA节点可能增加访问延迟；亲和性和数据本地化可改善

## 易错点
- UMA/NUMA区分的是**访问延迟特征**，不是Cache共享与否
- 多核、SMT和SIMD作用于不同层级，可同时出现在同一CPU中
