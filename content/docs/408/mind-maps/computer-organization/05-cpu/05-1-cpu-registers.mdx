# 5.1 CPU功能与内部结构

## CPU必须完成的五类职责
- **指令控制**：按照程序规定的顺序取指、译码、执行、更新PC
- **操作控制**：发出数据通路选通、读写、ALU功能等控制信号
- **时间控制**：安排微操作的先后关系和并行关系；同步或协调功能部件
- **数据加工**：算术、逻辑、移位、比较；生成条件码
- **中断/异常处理**：保护必要现场、转到处理程序、最终恢复执行

## 两大核心组成
- **运算器（数据加工）**：ALU、通用寄存器组、暂存器Y、结果寄存器Z、移位器、PSW等
  - 加法时ALU可能需要两个同时可用的输入；单总线结构常先把一个操作数放入Y
  - ALU输出可直接写回寄存器，也可先锁存到Z；依数据通路设计而定
- **控制器CU（指挥执行）**：指令寄存器IR、PC、译码/控制逻辑、时序部件等
  - 存储器接口寄存器MAR/MDR通常与控制器、数据通路共同协作，不应机械按物理位置分割
  - **硬布线**：组合/时序逻辑产生微命令；**微程序**：从控制存储器取微指令产生微命令

## 四类最常考寄存器
- **PC**：保存下一次取指所用的指令地址；分支、异常、返回均可能改变PC
- **IR**：保存当前取出的指令，供译码和控制使用
- **MAR**：存放本次主存访问的地址；通常连接地址通路
- **MDR**：暂存从主存读出的数据或准备写入主存的数据；通常双向传送
- 区分PC/IR：PC是**地址**；IR是**指令编码**
- 区分MAR/MDR：MAR是**地址**；MDR是**内容**

## 编程可见性：以具体ISA为准
- 通用寄存器GPR、部分PSW标志、PC的效果通常对程序可见
  - PC可通过分支指令间接改变；不等于任意ISA都提供普通写PC指令
- MAR/MDR/IR通常是**程序员不可直接访问的内部实现状态**
- PSW除ZF、CF、SF、OF等算术标志外，还可能含中断允许、特权级等控制位
  - 不应认为PSW**恰好只有四位**

## 408速辨
- **功能职责不等于固定硬件归属**：寄存器划分因教材框图而异
- **RISC/CISC不决定控制器唯一实现**，两者都可有硬布线与微码机制
