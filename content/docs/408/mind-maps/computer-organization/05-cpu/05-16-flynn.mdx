# 5.16 多处理器入门：Flynn分类

## 分类坐标
- Instruction Stream：指令流S(单) / M(多)
- Data Stream：数据流S(单) / M(多)
- **四象限**：SISD、SIMD、MISD、MIMD

## SISD：单指令流单数据流
- 典型传统串行处理器：每个控制流按顺序作用于单条数据流
- 可包含指令流水线和Cache，**不表示绝对没有阶段重叠**

## SIMD：单指令流多数据流
- 同一操作广播给多个处理元素，对不同数据同时加工
  - 典型向量处理、CPU SIMD扩展、部分GPU的SIMT相关模式（不完全等价）
- 适合向量加法、图像处理、矩阵等**数据并行**任务
- 限制：不同数据项出现控制分歧时，执行效率可能降低
- <img src="/images/408-mind-maps/co-05-readable-0106.svg" alt="一个控制单元驱动多个运算单元处理不同数据的SIMD示意" width="1040" height="411">

## MISD：多指令流单数据流
- 现实中极少见，不是“逻辑上根本不可能”
  - 在容错流水、特定冗余计算的讨论里可构造MISD类比，常规商用系统不典型

## MIMD：多指令流多数据流
- 多个独立执行流可对不同数据执行不同指令
  - SMP/多核处理器、分布式多机系统都可归入相关类别
- 共享内存：通信通过共享地址空间、需要同步和缓存一致性机制
- 分布式内存：每节点私有地址空间，通常通过消息传递交换数据
- <img src="/images/408-mind-maps/co-05-readable-0007.svg" alt="多个计算节点有独立处理器与内存并用网络通信的MIMD示意" width="1020" height="685">

## 408易错辨析
- Flynn分类的是**指令流与数据流的关系**，不是直接按CPU颗数分类
- SIMD一条指令处理多个数据元素；MIMD多个执行流可运行不同程序片段
- 多核CPU内部既可运行MIMD线程，又可对每核内部使用SIMD向量指令
