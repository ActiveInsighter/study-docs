# 5.2 指令执行的时间层次

## 基本术语
- **指令周期**：从开始取一条指令到该指令执行结束（必要时包括相关处理）的时间
  - 不同类型指令可以有不同周期长度
- **机器周期**：教学模型中取指、间址、执行、中断等相对独立的功能阶段
  - 一条指令不必依次经过四类周期；现代流水CPU不一定用此划分实现
- **时钟周期/节拍**：相邻时钟边沿之间的间隔，常是教学模型中的最小定时单位
- **微操作**：寄存器传送、ALU运算、存储器读写启动等原子级动作
  - 微操作可以并行发生；不应把“一个时钟周期只能有一个微操作”当公理
- **微指令**仅是微程序控制器中的控制字，不与“微操作”同义

## 典型的教学阶段
- 取指周期FE：`PC → MAR`，读出指令到MDR，再送IR，形成顺序PC
- 间址周期IND：当指令要求**主存间接寻址**时，读取存储器中的指针并求有效地址
- 执行周期EX：完成计算、访存、写回或改变控制流
- 中断周期INT：若在规定检查点响应可受理中断，保存现场并转中断处理程序
  - **中断请求可在任意时刻到来**，但何时检测/响应由架构和控制设计决定

## 定长与变长的两层含义
- 指令的机器周期**个数**可能不同，例如直接寻址省去IND
- 每类机器周期中所需时钟周期**个数**也可能不同
- 不能混淆“定长机器周期”和“定长指令编码”，它们讨论不同层次

## 取指顺序为何会变
- 固定长、按字编址时：教材常写`PC+1 → PC`
- 4B固定长、按字节编址时：顺序PC通常加4B
- x86变长指令：顺序PC加本条指令实际字节数
- 当存在取指队列、预取和乱序执行时，内部PC行为更复杂，考试须按题设数据通路判断

## 易错提示
- 周期数**不是**从指令字段数直接推出
- 同一节拍内允许有独立微操作并发；是否能并发还要看总线和数据依赖
