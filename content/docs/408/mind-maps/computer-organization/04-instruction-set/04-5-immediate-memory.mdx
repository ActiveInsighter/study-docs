# 4.5 数据寻址（一）：立即数与内存链

## 先定义符号
- A：**形式地址字段**；EA：有效主存地址；$M[x]$：主存地址x的内容
- 寻址方式决定怎样解释A；**有效地址与操作数值**不能混淆
- 已取出指令后，下列“次数”只计算取得源操作数的**主存数据访问**

## 立即寻址
- `ADD R1, #5`：数值5在指令内部，**无数据主存访问**
  - 立即数字段长k位的有符号范围一般为$[-2^{k-1},2^{k-1}-1]$，若补码编码
- **不是**EA=5；立即数没有“需访问的操作数主存地址”
- <img src="/images/408-mind-maps/co-0252.svg" alt="立即寻址，操作数编码在指令的立即数字段" width="690" height="330">

## 直接寻址
- A直接作为主存地址：$EA=A$，值为$M[A]$
  - 读取一次主存得到操作数；若写回主存结果需另计写访问
  - 地址空间受A字段可表示位数限制（未考虑段/基址扩展）
- <img src="/images/408-mind-maps/co-0226.svg" alt="直接寻址用A访问主存中的操作数" width="810" height="364">

## 一次主存间接寻址
- 主存A处存放目标地址：$EA=M[A]$；源操作数=$M[EA]$
  - **2次数据访问**：先读指针，再读操作数
  - 地址字段较短时，可通过指针指向更大的空间；多一次访存
- 多级间接：若题设用间址标志位持续指示链表，要逐层解引用，次数随层数增多
- <img src="/images/408-mind-maps/co-04-fixed-0024.svg" alt="修复缺字的主存一次及两次间接寻址示意图" width="1000" height="395">

## 别把隐含寻址当公式
- 隐含寻址：一个或多个操作数由指令约定（如ACC、SP或标志位）
  - 源操作数不需要在指令中单列地址字段
  - 例如 `ADD A` 可表示 `ACC ← ACC + M[A]`，ACC是隐含的另一个操作数
- **错误表达**：“隐含寻址 EA=A+ACC”——EA是地址，ACC参与算术而不是地址相加
