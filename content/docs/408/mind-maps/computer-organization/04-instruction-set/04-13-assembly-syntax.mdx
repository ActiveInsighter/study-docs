# 4.13 看懂两种常见x86汇编语法

## Intel语法（常见反汇编输出）
- 操作数通常：**目的在前、源在后**
  - `mov eax, 5` → EAX=5；`sub eax, ecx` → EAX−ECX
- 寄存器不加`%`，立即数可直接写数字
- 内存寻址通常加方括号：`mov eax, dword ptr [ebp+8]`
  - `dword ptr`说明内存操作数宽度32位

## AT&T语法（GNU汇编常见模式）
- 操作数通常：**源在前、目的在后**
  - `movl $5, %eax`；`subl %ecx, %eax` → EAX−ECX
- 寄存器`%eax`、立即数`$5`；内存操作数不用`$`且通常无`[]`
- 助记符后缀：`b`=8位、`w`=16位、`l`=32位、`q`=64位（具体指令支持依模式）
  - `movl 8(%ebp),%eax` ≈ Intel `mov eax,[ebp+8]`

## 两种语法对照
- Intel：`add eax, 1` ↔ AT&T：`addl $1, %eax`
- Intel：`mov eax, [ebx+ecx*4+8]`
  - AT&T：`movl 8(%ebx,%ecx,4), %eax`
- Intel：`cmp eax, 7` ↔ AT&T：`cmpl $7, %eax`，两者均比较EAX−7
- **注意**：一操作数`push`、`pop`的“源目的顺序”不适用

## DB/DW/DD与指令宽度
- `DB`,`DW`,`DD`常用于汇编器的数据声明伪指令：定义8/16/32位存储单元
  - 不是ISA中统一的“寄存器宽度后缀”；别与`byte ptr`、`dword ptr`混淆

## 机器码的位移和端序
- x86相对CALL的4B位移在编码中按小端排列
  - `D6 FF FF FF` → 32位二补码`0xFFFFFFD6` → −42
- **机器码首地址 + 指令长度**先求下一PC，再加位移
  - 指令字节按序流读取，不可把“整体指令机器码”字节顺序倒转

## 易错
- `lea`不会自动读取EA处的数据；`mov`可能读或写数据
- 汇编格式是一种记法；同一机器码可由不同反汇编器显示不同风格
