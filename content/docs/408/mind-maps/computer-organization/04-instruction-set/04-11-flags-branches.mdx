# 4.11 x86条件跳转：先CMP，再看FLAGS

## 四个高频状态标志
- **ZF（Zero）**：结果为0则ZF=1
- **SF（Sign）**：运算结果的最高符号位
- **CF（Carry）**：无符号加法进位；x86减法时为无符号**借位**标志
- **OF（Overflow）**：有符号运算数学结果超出目标位宽可表示范围
  - CF和OF可独立变化；“最高位有进位”不直接等于有符号溢出

## CMP统一看成a−b
- `cmp a,b`设置a−b的标志、不更改a/b
- **相等**：`JE/JZ`当ZF=1；`JNE/JNZ`当ZF=0
- **有符号比较**（如有符号int）
  - `JL`：SF≠OF；`JLE`：ZF=1或SF≠OF
  - `JG`：ZF=0且SF=OF；`JGE`：SF=OF
- **无符号比较**（如unsigned）
  - `JB/JC`：CF=1；`JBE`：CF=1或ZF=1
  - `JA`：CF=0且ZF=0；`JAE/JNC`：CF=0

## 同一位模式可得不同跳转
- 32位：EAX=`0xFFFFFFFF`，EBX=`0x00000001`
  - 有符号解释：−1$<$1 → `JL`成立
  - 无符号解释：4294967295$>$1 → `JA`成立
  - 指令比较结果、标志相同；**用哪个Jcc由程序员/编译器选择**

## 易错补充
- `INC/DEC`不修改CF，故不能把旧CF当本次增减的进位标志
- `TEST`不等价于`CMP`，并非所有指令都以同样规则更新各标志
- 条件码不等于CPU“直接保存比较结果true/false”，而是组合解释状态位
