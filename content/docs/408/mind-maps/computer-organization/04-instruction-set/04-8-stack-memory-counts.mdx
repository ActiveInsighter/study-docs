# 4.8 堆栈寻址与访存计数

## 堆栈寻址
- 栈是后进先出(LIFO)结构；栈顶地址通常由**SP**保存
  - 栈向高地址增长或低地址增长由ISA/运行约定决定；x86典型栈向低地址增长
- 硬堆栈：以CPU内部寄存器组织；软堆栈：主存中的栈区
  - `PUSH/POP`通常隐含SP参与寻址及更新，不是所有CPU都使用相同先增/后减语义
- 以32位x86 `push eax`为例：ESP减4，再写$M[ESP]$
  - `pop eax`：读$M[ESP]$，ESP加4（忽略异常条件与特殊目标寄存器情况）

## 不计取指：读取一个源操作数
- 立即数/寄存器直接/纯隐含寄存器：**0次**主存数据访问
- 主存直接：**1次**；寄存器间接：**1次**
- 主存一级间接：**2次**（先取指针再取操作数）
- PC相对/基址/变址：**1次**读取主存（如果最后取数，而不是仅跳转地址）
  - **分支指令只计算目标PC时未必读取该目标处的“数据操作数”**

## 完整指令的访问次数不能套死
- **写回主存**的指令另计写访问；RMW读改写可能不同
- 多字长指令与缓存命中、地址翻译、总线突发会改变实际总线事务
- 指令取出本身1次或多次（教学计算若题设“取指一次”则按该口径）
- 虚拟地址转换页表访问属于另一个层面的存储系统计数

## 典型例子对比
- `ADD R1,R2`：两个源均在寄存器，数据主存访问0次
- `LOAD R1,[R2]`：从内存读1次
- `ADD [A],R1`：假设内存结果原址写回，读1次、写1次 → 数据访问2次
- `LOAD R1,[[A]]`：教学上两级解引用通常读指针2次后再读数据1次
