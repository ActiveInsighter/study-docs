# 3.5 存储芯片如何工作

## 从存储单元到芯片
- 存储元：可容纳若干bit的电路单元；字线选中一行，位线传送感测信号
  - “一排电容等于机器字长”**不是普适规律**：阵列内部行宽与外部数据组织可不同
- 存储芯片标记 `N × b`：N 个可选地址，每个地址一次给出 b bit
  - `8K × 8`：$2^{13}$ 个地址、8根数据引脚；总容量8 KiB
  - 使用13位地址就可寻址这颗芯片，不代表整机CPU总线仅13位

## 信号与时序
- 地址线 A：选择单元；数据线 D：承载读/写字；CS/CE：选择目标芯片
  - `CS̅` 或 `/CS` 表示**低电平有效**；电平意义依器件说明书
  - WE、OE/RD：写使能、输出使能；单独 WE 低表示写，WE 高也未必自动就完成读
- CPU地址先稳定 → 片选/读写控制满足建立时间 → 数据有效 → 完成读写
  - DRAM有行/列地址复用和 RAS/CAS，不应把这些控制端机械等价于两个 CS

## 译码器和片选
- n→$2^n$ 译码器：选通一个输出；输出是否低有效由电路规格决定
  - 使用带使能端的 74LS138 可实现3位片选，通常3选8个输出为低有效
- **线选法**：直接用不同高位地址线做片选，简单但容易出现非连续/重复映射
  - **译码片选法**：用高位组合解码，形成不重叠、连续的地址区间
- 每组芯片位扩展时所有组内片选通常共用；数据线接到不同bit位段
- 地址跨度求法：芯片有 $2^k$ 个地址 → 映射区间有 $2^k$ 个编址单位
  - 例 `8K×8` 按字节编址，区间 `0x4000–0x5FFF` 恰好8KiB
