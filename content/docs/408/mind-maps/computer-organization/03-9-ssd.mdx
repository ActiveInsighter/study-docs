# 3.9 SSD 固态硬盘

## 闪存的物理限制
- NAND Flash通常以**页**进行读取/编程，以**块**为单位擦除
  - 一个擦除块由多个页组成；页/块具体容量因芯片代次不同
  - 已写入的物理页不能随意在原位置“改写成任意bit组合”
- 面向操作系统呈现 LBA 逻辑块，不等于闪存页的物理大小
  - 主机一次提交4KiB I/O，控制器可能拆分/合并请求和做内部纠错

## FTL 与写时重映射
- Flash Translation Layer维护 **逻辑块地址(LBA) ↔ 物理闪存位置** 的映射
  - 更新逻辑块：分配新的空闲物理页 → 写入新内容 → 标记旧页失效 → 更新映射
  - 垃圾回收：搬迁一个块中的有效页，然后擦除旧块，重新释放空间
  - TRIM帮助SSD知道主机已不再使用的逻辑区间，不等于即时物理擦除

## 磨损均衡与写放大
- 动态磨损均衡：优先在空闲块之间分散新写入/擦除次数
- 静态磨损均衡：**也迁移长期不变的冷数据**，避免部分块始终不参与轮换
  - 两者互补，不能机械断言“静态永远比动态好”
- 写放大 $WAF=\text{闪存物理写入量}/\text{主机请求写入量}$
  - 垃圾回收、映射元数据和纠错管理可使物理写大于主机写
  - 空闲预留区、垃圾回收策略、负载等都会影响寿命/性能
- 机械盘 vs SSD：SSD无需磁头寻道，通常随机IO延迟更低
  - 接口（SATA/NVMe）与存储介质（HDD/NAND）是**两个不同维度**
