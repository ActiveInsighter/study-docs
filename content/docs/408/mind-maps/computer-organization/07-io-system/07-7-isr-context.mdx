# 7.7 中断服务全过程与现场保护

## 一条完整主线
- ① 设备请求，中断控制器判优并由CPU接收
- ② **硬件入口动作（中断隐指令）**：完成必要状态保护，获取入口并转去处理程序
- ③ **软件中断服务程序 ISR**：按需保存其他寄存器，读取设备状态，完成服务/清除中断源
- ④ 恢复软件保存的上下文，执行中断返回指令
- ⑤ CPU按保存状态恢复原程序或调度别的任务
- <img src="/images/408-mind-maps/co-0288.svg" alt="中断处理流程以及嵌套中断的开关中断位置" width="550" height="629">

## 硬件保存与软件保存的边界
- **PC（断点）**：CPU进入处理程序时必须保存足够信息供恢复执行，常由硬件保存或转移到特定保存区
- **PSW/标志寄存器**：各ISA对硬件压栈、保存到特殊寄存器或软件保存的规定不同
- **通用寄存器**：在教材典型模型中由ISR程序保存；具体由ABI与硬件机制决定
- **教材口径冲突的处理**：有些教材把PC交给中断隐指令、PSW交给软件；另一些硬件模型同时保存PC和PSW
  - 答题应遵循**题目指定机器与教材约定**；不得推出“PSW永远由硬件/软件保存”
- **保护断点** ≠ **保护全部现场**；二者执行时机和责任可不同

## 单级中断和多级嵌套
- **单级**：处理中保持同级/可屏蔽中断关闭，返回后再继续原程序
- **多重中断**：保存当前上下文和屏蔽状态，必要时在安全位置重新开中断
- 更高优先级事件可打断低优先级ISR，返回时必须恢复低优先级ISR尚未完成的上下文
- 嵌套层数增加会加大栈占用和最坏响应时间分析的复杂度

## 中断延迟与CPU开销
- **响应延迟**：从设备提出请求到CPU开始处理；包括屏蔽等待、当前指令完成、硬件仲裁/入口等
- **处理开销**：保存/恢复现场、ISR中的处理指令、返回指令等
- 一秒有 $N$ 次中断，单次消耗 $C$ CPU周期、CPU频率 $f$：$U=N C/f$
- **避免重复计费**：若题设给定单次服务周期已包含现场保护/恢复，不应额外再加一次
