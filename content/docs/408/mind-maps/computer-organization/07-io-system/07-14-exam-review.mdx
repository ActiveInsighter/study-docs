# 7.14 高频题型：逐步计算与辨析

## 题型一：轮询是否可行
- **已知**：CPU 100 MHz，单次查询200周期；每秒40万次查询
- **求CPU查询占用率**：$U=400000\times200/10^8=0.8=80\%$
- 若另需CPU搬运数据或执行应用程序，则剩余20%的CPU时间未必足够
- **关键检查**：题给的是“查询间隔”还是“每个数据字查询一次”，不能臆造查询次数

## 题型二：中断服务开销
- **已知**：设备每秒完成2000批，每批产生一次中断；每次中断服务2500周期，CPU为500 MHz
- **求CPU占用率**：$U=2000\times2500/(5\times10^8)=1\%$
- 若每批包含64 B，有效数据吞吐 $2000\times64=128000\,\mathrm{B/s}$
- 若每字节产生一次中断，事件率会变化；题设不能随意把“中断每批一次”改为“每字一次”

## 题型三：DMA管理开销
- **已知**：DMA每块8 KiB，设备数据率64 MiB/s；每块初始化与收尾总计2000 CPU周期；CPU为1 GHz
- **每秒传输块数**：$64\times2^{20}/(8\times2^{10})=8192$
- **CPU管理开销比例**：$8192\times2000/10^9=1.6384\%$
- **易错**：这个比例是CPU指令管理开销，不是DMA的主存/总线占用率

## 题型四：周期窃取与内存事务
- **已知**：DMA每次主存访问搬4 B；需要搬64 KiB
- **理论最少数据访存次数**：$N=65536/4=16384$
- 若每个访存周期 40 ns、且全都与CPU需求冲突，最大相应停顿估计为 $16384\times40\,\mathrm{ns}=655.36\,\mathrm{\mu s}$
- **限定**：这是按题设抽象的最坏无重叠估计；实际可能批量传输、缓存命中或并行互连，不应当成普遍实测值

## 题型五：异步串行实际吞吐
- **已知**：19200 bit/s、每帧1起始+8数据+1奇偶校验+1停止位
- **每字符帧长**：11 bit；**字符率**：$19200/11\approx1745.45$字符/s
- **有效数据位速率**：$19200\times8/11\approx13963.6\,\mathrm{bit/s}$
- 不能把“19200 bit/s”除8直接得到有效字节率

## 题型六：屏蔽矩阵
- 处理优先级：`D > A > C > B`；列顺序 `A B C D`，**1屏蔽、0允许**
- A行：`1110`；B行：`0100`；C行：`0110`；D行：`1111`
- 逐行自检：每行自身位为1；低优先级B仅可阻断B自己；最高优先级D阻断全部

## 最易失分的六句话
- “中断处理程序中的PC/PSW保存机制**依具体ISA或教材约定**”
- “外部中断检查与DMA访存争用**不属于同一时机机制**”
- “I/O接口不等于某一个I/O端口”
- “DMA能降低CPU数据搬运开销，但仍会争用主存/互连”
- “传输率的MB与MiB先统一口径，线路bit与有效Byte不要混用”
- “中断屏蔽字和硬件响应优先级作用于**不同层次**”
