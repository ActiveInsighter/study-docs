# 7.2 I/O接口、设备控制器与端口

## 三者关系：先辨概念
- **I/O接口**：主机与外设之间的接口逻辑，可由寄存器、缓冲器、地址译码器及控制逻辑组成
- **设备控制器**：管理一类或多台设备的硬件部件；在许多教材图中与“I/O接口”所指的硬件范围高度重合
- **I/O端口**：CPU/总线主设备可访问的接口寄存器或其地址位置
  - **端口不等于整个接口**：寄存器集合 + 控制逻辑 + 连线才构成接口
- 一个控制器可控制多个设备；有些系统也存在多个访问同一存储设备的路径

## 接口五项核心功能
- **设备选择**：译码地址，确定当前命令针对哪个端口/设备
- **命令与时序控制**：接收 `READ/WRITE/START/RESET` 等命令并驱动设备
- **数据缓冲**：利用数据寄存器、FIFO/缓冲区弥合两侧速度差异
- **状态报告**：`ready/busy/error/interrupt-pending` 等条件由状态寄存器反映
- **格式或电气转换**：位宽、串并转换、编码以及电压/时序转换；并非每个接口都必备每一种转换

## 常见接口寄存器
- **数据寄存器 DR**：保存当前待读/待写数据；读写动作可能触发设备状态变化
- **状态寄存器 SR**：保存就绪、忙、出错、完成等状态位
- **控制寄存器 CR**：保存命令、模式位和中断允许等控制项
- **地址译码/设备选择逻辑**：根据总线地址启用目标寄存器
- 某些控制器将状态/控制复用同一端口地址（按读/写方向区分），具体以题设和硬件手册为准

## 读写示例：读入一个字符
- ① CPU读取状态端口，判断 `ready=1`
- ② CPU从数据端口读入字符；读动作可能清除就绪位
- ③ 控制器继续接收外设数据，必要时置位状态或发出中断请求
- **易错**：读取状态端口不等于读取数据端口；控制线不是“写入控制寄存器”这一动作的全部
