# 7.1 I/O系统：从设备到CPU

## 系统组成与各层职责
- **外部设备**：将信息输入计算机或将结果输出（键盘、磁盘、显示器、网卡等）
- **设备控制器／I/O接口**：负责命令、状态、数据缓冲和信号转换
- **互连资源**：总线、交换互连、控制信号与数据传输路径
- **主机侧**：CPU发起控制、内存存放程序及缓冲区；DMA可在取得访问权后代替CPU完成数据搬运
- **软件侧**：设备驱动程序、OS的I/O子系统、系统调用
- 逻辑链：应用 → 系统调用 → 驱动/控制器 → 外设；数据可能通过CPU寄存器或DMA直接进入内存

## 常用设备分类
- **按功能**：输入设备、输出设备、存储设备、通信设备
- **按传输单位**：字符设备与块设备是OS常见抽象，并非“硬件一次只传1字符/1块”的硬性约束
- **按速率**：低速、中速、高速是相对分级；不能简单据设备名称判断采用哪种控制方式
- **按交互方向**：输入、输出、双向；网卡和磁盘均可双向传输
- **机械与电子结构**：机械/传感部分完成实际动作，控制电路实现命令解析、信号驱动和状态检测

## 串行、并行与异步串行帧
- **串行**：少量数据线按时间顺序传比特；**并行**：同一时刻多线传多位
- 串行不等于低速：线路数量、符号率、通道数和协议开销共同决定有效吞吐
- UART式异步帧：起始位 + 数据位 + 可选校验位 + 停止位
  - 常用 `8N1`：1个起始位、8个数据位、无校验、1个停止位，**每传8位有效数据占10位线路容量**
  - 若线路比特率为 $R$，忽略间隔时：$R_{\mathrm{payload}}=R\times\frac{8}{10}$
- **单位陷阱**：`Mb/s` 是百万比特每秒；`MB/s` 是百万字节每秒；`MiB` 按 $2^{20}$ 字节定义
  - 通信链路速率常用十进制前缀；主存容量题若采用二进制口径应明确 $\mathrm{KiB,MiB,GiB}$

## 性能与考研范围
- **I/O总历时**：设备准备 + 传输 + 等待/控制开销；CPU忙碌时间不必等于设备工作时间
- **吞吐率**：单位时间交付的有效数据；**时延**：一次请求从发起到完成所需时间
- **中断延迟**与**DMA占用主存通路**分别衡量CPU响应和数据搬运的成本
- 总线传输与CPU处理可部分重叠，但共享资源冲突会引入停顿
