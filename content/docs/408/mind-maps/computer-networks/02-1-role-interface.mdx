# 2.1 物理层任务与接口四大特性

## 物理层的定位
- OSI第一层，面对物理链路实现**透明传送原始比特流**
  - 不负责IP寻址、端到端路由、应用消息解释
  - **传输媒体本身通常不算协议层**：双绞线、光纤、自由空间提供承载条件
- 主要解决：怎样用电、光或电磁信号代表并传送比特
- 规定通信设备与传输媒体接口的特征；可定义时钟、编码和传输参数

## 接口四大特性（高频记忆）
- **机械特性**：连接器形状/尺寸、引脚排列、锁定方式
- **电气特性**：电压范围、电流/阻抗及相关电气条件
- **功能特性**：某引脚/信号电平分别表示什么意义
- **规程（过程）特性**：接口信号与控制事件按什么次序发生
- 示例：某接口第3脚何时置高以表示“准备好”
  - 第3脚的位置→机械；高电平范围→电气
  - “准备好”的含义→功能；置高时机→规程

## 与协议三要素区别
- 协议的语法、语义、时序属于**通用抽象**；接口四特性属于**物理接口规范**
- 不能把四种接口特性简单等同于语法、语义、同步三个词

## 跨层辨析
- 物理层PDU可称**比特**；链路层PDU是**帧**
- 中继器/集线器是典型物理层设备；交换机主要依据MAC帧工作
