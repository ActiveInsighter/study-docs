# 3.4 海明码、码距与纠错能力

## 海明距离与码距
- 两个**等长码字**对应位不同的位置数称其海明距离
- 例如`10101`与`00110`：第1、4、5位不同，距离为`3`
- 一组合法码字的**最小海明距离**`d_min`决定检错/纠错能力
  - 最多检出`d`位错误需 $d_{\min}\ge d+1$
  - 最多纠正`t`位错误需 $d_{\min}\ge2t+1$
- “海明距离”适用于任意等长二进制编码，**并非只属于海明码**

## 经典单错纠正海明码
- `m`位数据，`r`位校验：需满足 **$2^r\ge m+r+1$**
  - 例如$m=4$：$r=3$满足$8 \ge  4+3+1$，得到(7,4)海明码
- 标准安排：位置从1编号，校验位放在`1、2、4、8…`（2的幂）
- 每个数据位参与哪些校验组，由其**位置编号的二进制表示**决定
- 偶校验版本：各组按异或求校验位，令该校验组总异或值为0

## 接收端综合症S（syndrome）
- 接收后重算各校验组奇偶；校验结果组成二进制综合症
- **S=0**：未检出单错（不保证绝无多位错误）
- **S非0**：在“最多1位翻转”前提下，S指示该错误位的编号，翻转修正
- 经典(7,4)海明码$d_{\min}=3$：可纠1位错误、检测至多2位错误，但**无法保证识别双错与单错的区别**

## 扩展海明码（SECDED）
- 另加整体奇偶校验位，典型最小码距提升到4
- **SECDED**：Single Error Correction + Double Error Detection
- 单比特错误可纠；双比特错误可检测但不能纠
- 注意：遇到超过设计能力的错误，可能漏检或误判，不能无限纠错

## 做题清单
- 先求最小`r`，再排校验位位置
- 列出每个校验组覆盖的位置；按题给奇/偶约定求值
- 重新做异或得到综合症，最后再判断错误位
