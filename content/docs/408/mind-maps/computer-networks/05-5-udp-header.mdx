# 5.5 UDP报文格式、长度与IP层边界

## UDP首部四个字段
- <img src="/images/408-mind-maps/cn-0025.svg" alt="UDP首部四个16位字段" width="720" height="309">
- **源端口（16位）**：IPv4/IPv6 UDP均有该字段；若不用回信，在经典UDP中可置0
- **目的端口（16位）**：指明接收端通信服务
- **长度（16位）**：UDP首部+数据字节数，**最小8字节**；长度为8代表零数据载荷
- **校验和（16位）**：覆盖UDP首部、数据以及IP伪首部，不是仅检验数据

## 长度关系
- IPv4无选项时：`IP总长度 = 20 + UDP长度`；有IP选项时应加实际IP首部长度
- 假设IPv4总长度240B、IP首部20B、UDP首部8B，则应用数据为**212B**
- UDP数据报长度受字段、IP层长度与路径MTU约束；普通IPv4/UDP应用不应假设可直接发送65535B有效载荷
- IP分片发生在IP层；接收端**先IP重组**，再将完整UDP报文交到传输层

## 检错的范围
- IPv4：UDP校验和字段为0表示发送端未计算；校验结果为0需按规则编码为全1
- IPv6：UDP校验和**一般必须使用**（少数受约束隧道例外），不能照搬IPv4可省略的结论
- 检验失败通常直接丢弃；不存在标准要求“必须把错误UDP报文交给应用并附差错报告”

## 计算题提示
- 注意区分UDP长度、IP总长度、MTU和以太网帧长度四种字节数
- IPv4分片偏移以8字节为单位；**UDP本身不维护分片偏移字段**
