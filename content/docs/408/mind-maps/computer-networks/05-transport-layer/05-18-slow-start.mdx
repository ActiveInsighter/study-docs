# 5.18 慢开始与拥塞避免的逐RTT计算

## 慢开始：指数式上升
- 按常见408简化模型：初始`cwnd=1 MSS`、`ssthresh=16 MSS`
- 每个RTT收到全量新数据ACK后：`1 → 2 → 4 → 8 → 16`
- 达到阈值后转拥塞避免：`16 → 17 → 18 → 19`（每RTT约加1 MSS）
- **不要说“每个RTT只发送一个MSS”**；每轮可发送数据由当前窗口控制

## 拥塞避免：加性增
- 经典每确认一个MSS的数据，拥塞窗口增长量约`MSS²/cwnd`字节
- 若每个RTT近似确认满窗口的数据，则每个RTT总计增量约1 MSS
- `ssthresh`不是物理链路容量；它是发送端切换增长策略的控制阈值

## 超时后的处理
- 示例：丢包前`cwnd=20 MSS`，发生RTO超时，教材常设`ssthresh=10 MSS`，`cwnd=1 MSS`
- 之后慢开始`1→2→4→8`，接近/达到阈值后进入拥塞避免；阈值附近按题设处理
- 真实实现可用`FlightSize`而不直接取当前cwnd的一半来设阈值；408做题**必须先看题设**
