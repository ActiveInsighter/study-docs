# 1.8 SDU、PCI、PDU 与封装解封装

## 三个关键缩写
- **SDU**：Service Data Unit，来自上一层/交付给本层的服务数据
- **PCI**：Protocol Control Information，本层为协议操作添加的控制信息
- **PDU**：Protocol Data Unit，本层对等实体之间逻辑交换的协议数据单位
- 一般抽象关系：`n-PDU = n-PCI + n-SDU`
- 在无特殊分段/聚合时，`n-PDU`通过下层SAP成为`(n−1)-SDU`

## 封装方向
- **发送**：应用数据 → 传输层首部 → IP首部 → 链路层头/尾 → 物理比特
- **接收**：按层解封装，各层验证/消费控制信息，向上交付上层数据
- 数据链路层可加**帧首部和帧尾部**（如FCS）；不能把所有PCI想成只有头部
- 现实中可能出现分段、分片、聚合、隧道封装，不能假定每层永远一对一
- <img src="/images/408-mind-maps/cn-01-encapsulation-clean.svg" alt="五层封装：报文段、IP数据报、帧" width="800" height="349">

## 五层数据单位（408常用）
- **应用层**：应用报文/数据
- **传输层**：TCP报文段（segment）/UDP用户数据报（datagram）
- **网络层**：IP数据报/分组（packet）
- **数据链路层**：帧（frame）
- **物理层**：比特（bit）

## 高频辨析
- 对等层的PDU是**逻辑通信**，不是越过下层直接传给对端
- 一个IP数据报并不总只变成一个链路帧；封装单位受MTU和分片/分段影响
- IP数据报与以太网帧头中的地址用途不同：IP用于跨网寻址，MAC用于链路交付
