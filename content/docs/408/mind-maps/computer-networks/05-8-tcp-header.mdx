# 5.8 TCP首部字段、标志位与选项

## 首部定长与可变部分
- <img src="/images/408-mind-maps/cn-0076.svg" alt="TCP标准报文段首部" width="900" height="461">
- 源/目的端口各16位；**序号、确认号各32位**；首部长度(数据偏移)4位、单位为4B
- 固定首部20B；首部长度字段取5～15，对应20～60B；**不是IP分片偏移**
- 窗口字段16位，以字节计数；检验和16位；紧急指针16位；可选项需4B对齐
- TCP伪首部校验和：源/目的IP + 协议号6 + TCP报文段长度（IPv4、IPv6伪首部格式不同）

## 标志位六件套
- **SYN**：请求同步初始序号；SYN本身**消耗1个序号**
- **ACK**：ACK=1表示确认号字段有效；建立连接后一般持续置1
- **FIN**：本方向数据发送完毕，**消耗1个序号**；对端仍可反向发送
- **RST**：复位或拒绝无效连接；不是正常关闭的四次挥手
- **PSH**：提示尽快把已接收数据交付应用；不保证“立即无缓存”
- **URG**：紧急指针有效；传统紧急数据语义，不是应用可自由设定的通用优先级

## 常用TCP选项
- MSS(kind 2，4B)：TCP报文段**数据部分**建议的最大长度，常在SYN中协商
- Window Scale(kind 3)：扩大有效接收窗口表示范围；在建连时协商
- SACK Permitted(kind 4) / SACK(kind 5)：允许报告不连续收到的数据块
- Timestamp(kind 8)：改善RTT测量及PAWS等；NOP/EOL辅助选项填充
- **纠错**：“TCP只规定MSS一种选项”不正确；其它标准选项在考试与实践中均有意义
