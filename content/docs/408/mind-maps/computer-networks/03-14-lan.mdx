# 3.14 局域网与IEEE 802子层

## 局域网LAN特点
- 通常覆盖较小区域，由一个组织管理；常用以太网和802.11无线网
- 早期共享介质局域网多站争用；**现代交换式以太网不意味着所有主机共享同一带宽**
- 典型拓扑：总线、星、环、树；**物理拓扑**与**逻辑访问方式**可能不同

## 主要经典技术
- **IEEE 802.3以太网**：有线以太网；历史共享式采用CSMA/CD，现代交换式全双工不采用
- **IEEE 802.11 WLAN**：无线局域网；采用无线MAC协调机制
- **IEEE 802.5 Token Ring**：令牌环，历史性技术，逻辑环/可用物理星型布线
- **FDDI光纤分布式数据接口**：双环光纤网络，属于历史性LAN/MAN技术；**不是802.8标准**
- ATM以固定长度信元交换为特色，**不能简单定义为第五种IEEE 802局域网**

## IEEE 802架构
- 数据链路层传统划分：**LLC（逻辑链路控制）**与**MAC（介质访问控制）**
- MAC：媒体访问、MAC编址、帧封装/差错检测等
- LLC：向上提供逻辑链路服务接口、协议复用；并非所有现代以太网通信都显式使用802.2 LLC
- 现代以太网多使用**Ethernet II帧格式**携带IPv4/IPv6

## 广播域与冲突域
- **冲突域**：可能在共享介质争用中产生冲突的范围；每个交换机端口通常独立冲突域
- **广播域**：二层广播帧通常可以到达的范围；VLAN可划分广播域
- 路由器或三层转发可隔离二层广播域；**网桥/二层交换机本身不自动隔离所有广播**

## 令牌类受控访问
- **令牌传递**：站点要发送需取得令牌；正常运行时能避免竞争式碰撞
- 代价：传令牌开销，令牌丢失恢复和设备故障处理
- 常见考法：高负载下避免碰撞，不能因此推断总性能必优于高速交换式以太网
