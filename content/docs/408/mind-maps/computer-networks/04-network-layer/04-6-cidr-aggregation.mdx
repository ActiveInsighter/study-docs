# 4.6 CIDR路由聚合与地址块范围

## CIDR与超网
- 无分类域间路由：用前缀表达可达网络，不再以A/B/C类默认掩码作为路由边界
- 前缀短→地址范围大；前缀长→匹配更具体
- 路由聚合减少路由表条目，**不能改变应到达的真实网络或下一跳选择结果**

## 相邻网段合并
- `192.168.8.0/24`+`192.168.9.0/24`→`192.168.8.0/23`
- 条件：等大、连续、**按更短前缀地址边界对齐**，且汇总后转发政策可接受
- `192.168.9.0/24`与`192.168.10.0/24`虽连续，但**不能**精确合并成一个`/23`（起点不对齐）

## 最长公共前缀 ≠ 一定可合并
- 若只有`10.0.0.0/24`和`10.0.2.0/24`，共同前缀可能包含中间未拥有的地址块
- 贸然聚合会把不属于该下一跳的流量也引过来
- 广域网汇总可能配合更具体例外路由，需分析地址范围与黑洞风险

## 前缀数量与计算
- `/p`所覆盖的地址数为$2^{32-p}$
- 一组`2^k`个相邻且对齐的`/p`，可精确合并为`/(p-k)`
- 例如4个对齐的/24→一个/22，但首个网段第三段要能被4整除

## 记忆法
- **同下一跳、地址连、边界齐、不能多覆盖**：是“精确聚合”的充要检查方向
- 转发表遇到汇总与更具体路由同时存在时，依**最长前缀匹配**决定最终下一跳
