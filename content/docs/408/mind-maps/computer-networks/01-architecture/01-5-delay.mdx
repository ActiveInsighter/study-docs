# 1.5 四类时延与多跳时延计算

## 四类时延：先看物理过程
- **发送/传输时延**：把一份`L`位分组全部推入链路
  - `d_tx = L / R`；与比特长度和发送链路速率有关
- **传播时延**：信号从链路一端传播到另一端
  - `d_prop = d / v`；`d`为长度，`v`为传播速度，**与报文长度无直接关系**
- **处理时延**：检查差错、查转发表、执行协议处理等
- **排队时延**：在网络设备队列中等待；受突发流量、调度与拥塞状态影响

## 一个节点/一条链路模型
- 常用分解：`d_nodal = d_proc + d_queue + d_tx + d_prop`
- <img src="/images/408-mind-maps/cn-01-delays-clean.svg" alt="发送与传播时间的两段示意" width="760" height="297">
- 例：`L=12000 bit`、`R=6 Mbit/s`、`d=300 km`、`v=2×10⁸ m/s`
  - 发送 = `12000 / 6×10⁶ = 2 ms`
  - 传播 = `300×10³ / 2×10⁸ = 1.5 ms`
  - 不含处理排队的链路部分合计 `3.5 ms`

## 多跳存储转发
- `H`条链路，**一个长度为L的分组**，各段发送速率相同：
  - 不计排队/处理：`H×L/R + Σ(d_i/v_i)`
- `P`个等长分组，`H`条等速链路且可流水线：
  - 若传播/处理/排队均忽略，总完成时间 `(H+P−1)×L/R`
  - 这里`L`是**每个分组**的实际发送位数，不能误当整份报文位数

## 408易错判断
- `L/R`与`d/v`通常同时存在；远距离高带宽链路可能传播主导
- 路由器每一跳通常重新计算发送时延，不能只计算源主机一次
- 队列时延没有固定公式可无条件套用；实际取决于到达/服务过程
