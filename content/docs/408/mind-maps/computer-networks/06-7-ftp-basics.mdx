# 6.7 FTP服务、控制/数据双连接与命令

## FTP的基本工作方式
- **FTP是C/S架构**，使用TCP的可靠字节流传输文件
- 存在独立的**控制连接**与**数据连接**，称为带外控制（out-of-band control）
- 控制连接通常由客户端发起连接到服务器**TCP 21**，会话期间保持
- 一个目录列举或文件传送可新建数据连接；**不是控制连接和数据连接固定同时只有两条**

## 控制连接做什么
- 客户端发送文本命令：`USER`、`PASS`、`CWD`、`PWD`、`LIST`、`RETR`、`STOR`、`QUIT`
- 服务器返回三位数字响应码；数据在独立连接上传输
- 客户端在某个传输结束后可以继续通过控制连接请求其他操作

## 数据传输内容
- 文本`TYPE A`与二进制`TYPE I`传输方式：注意转换规则，传文件通常优先考虑二进制
- 用户权限、目录及服务器配置影响能否读写；匿名登录常使用`anonymous`而不是原文误拼`annoymous`
- **FTP≠NFS**：NFS是网络文件系统语义，不是FTP的数据连接模式

## 基本安全
- 传统FTP控制登录密码与数据一般都是明文，公网传输有窃听风险
- FTPS是基于TLS保护的FTP族；SFTP属于SSH文件传输协议，不是FTP+SSL
