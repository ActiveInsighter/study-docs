# 2.12 导向型介质：双绞线与同轴电缆

## 传输媒体与分类
- **导向型媒体**：电磁能量沿实体导体/波导约束传播；铜线、光纤
- **非导向型媒体**：信号在自由空间传播；无线电、微波等
- 媒体是物理承载环境，**不是自动提供帧交换或可靠传输的L1协议实体**

## 双绞线
- 两根绝缘铜导线成对绞合，利用电磁耦合与差分方式**降低外界干扰和串扰**
- 可有非屏蔽UTP与屏蔽STP等类型，线缆等级/标准决定带宽、布线要求等
- 优点：成本较低、安装方便、现代以太网常用
- 局限：距离、串扰、衰减与环境干扰限制速率；不能泛称“串行比并行慢”
- <img src="/images/408-mind-maps/cn-0045.svg" alt="双绞线绞合及屏蔽结构示意" width="740" height="347">

## 同轴电缆
- 结构：**内导体→绝缘介质→外部屏蔽导体→保护外套**
- 电磁场受导体结构约束，通常有较好的屏蔽性能
- 常见**50Ω**用于一些射频/历史基带网络；**75Ω**常见于有线电视及视频分配
  - 50/75Ω是特性阻抗，**不能机械等同“数字/模拟”的绝对分类**
- <img src="/images/408-mind-maps/cn-0150.svg" alt="同轴电缆四层结构示意" width="720" height="288">

## 对比要点
- 双绞线：布线便捷、成本优势；同轴：同心屏蔽结构更强
- 实际速率、距离和价格需结合标准与设备，不能按媒介名称单独确定
