# 2.2 通信模型、传输模式与同步

## 数据通信模型与术语
- **信源**（产生信息）→发送设备→信道/媒体→接收设备→**信宿**
  - 信号是数据的物理表现：电信号、光脉冲、无线电磁波等
  - 模拟信号参数连续；数字信号在规定判决状态上离散
- <img src="/images/408-mind-maps/cn-02-communication-clean.svg" alt="信源发送机信道接收机信宿和通信方向" width="790" height="391">
- **信道**是信息传输方向/资源的抽象；一条物理线路可以承载多条逻辑信道

## 按方向：三种方式
- **单工**：数据单方向流动；例：单向广播
- **半双工**：两端都能发送，但同一时刻不能双向同时发送；例：传统对讲机
- **全双工**：两端可同时双向发送；例：双向电话、现代全双工以太网
- 不能机械背“半双工需要两条信道、全双工需要两条线”
  - 双向资源可通过频率、时间、线对或回声消除等方式分离

## 串行与并行
- **串行**：沿某条数据通路按时序逐位传送；适合高速、长距离、较少导线
- **并行**：多个位借多条并列通路同步传送；常见于短距离、板内并行总线
- “串行一定慢，并行一定快”错误：高速串行可避开多线时钟偏斜与串扰
- 字节内部的**高位先发/低位先发由具体协议规定**，不能默认为低位先发

## 同步与异步
- **同步传输**：采用时钟/定时恢复使收发同步，常成块连续传送
- **异步字符传输**：每字符常有起始位、数据位、可选校验位、停止位
  - 字符之间允许不定间隔，**单字符内双方仍需约定波特率**
- <img src="/images/408-mind-maps/cn-0114.svg" alt="异步字符起止位示意" width="680" height="307">
- 同步不要求两端永久共用物理时钟；可通过线路时钟恢复实现
