# 3.12 CSMA/CD、最短帧与指数退避

## CSMA/CD完整流程
- **先听后发，边发边听，冲突停发，随机重发**
- 使用于历史上的**共享总线/集线器半双工以太网**，不用于现代点对点全双工交换链路
- 发送时持续检测冲突；检测到冲突后终止本次帧发送，可发干扰信号

## 为什么需要最短帧长（高频计算）
- 最坏情况下的碰撞信号可能在**最长往返传播时延**后到达发送者
- 必须**尚未发完帧时仍可检测碰撞**：$T_{t,\min}\ge2T_p$（忽略中继等附加延迟）
- 得到 **$L_{\min}\ge2T_pR$**（bit），若有更多设备时延需要加入争用期
- <img src="/images/408-mind-maps/cn-03-collision-clean.svg" alt="CSMA/CD最坏碰撞往返时延与最短帧" width="820" height="394">

## 经典10Mbit/s以太网
- 时隙（争用期）$51.2\,\mu\mathrm{s}=512\ \mathrm{bit\!\!\!-times}$
- $512\,\mathrm{bit}/8=64\,\mathrm{Byte}$：最短MAC帧长（不含前导码/SFD）
- 数据载荷不够时要填充到最短帧；常规Ethernet II/802.3载荷最小`46B`
- `51.2µs`并非**所有**速率以太网都固定采用的传播时延

## 二进制指数退避
- 第`i`次冲突，退避取随机整数 $K\in[0,2^{\min(i,10)}-1]$
- 等待$K\times T_{\mathrm{slot}}$，然后按载波侦听规则再次竞争
- 经典以太网**累计16次失败**后放弃帧发送并上报失败
- 退避的核心是**分散重试概率**，而非保证一定不会再碰撞

## 速记计算
- 单程电磁波传播$T_p=\frac dv$；若$d=2\,\mathrm{km},\quad v=2\times10^8\,\mathrm{m/s}$ → $T_p=10\,\mu\mathrm{s}$
- $R=10\,\mathrm{Mbit/s}$时往返要求$L_{\min}\ge 2\times10\,\mu\mathrm{s}\times10\,\mathrm{Mbit/s}=200\,\mathrm{bit}$
- **这是按给定链路距离的物理下界**，真实以太网仍受标准最小64B等约束
