# 3.19 网桥、二层交换机与自学习

## 三类设备要分清
- **集线器Hub（物理层）**：重复电信号，入端口外的其他端口均可看到信号，共享冲突域
- **网桥/以太网交换机（二层）**：检查MAC帧头，转发表将帧转发到适当端口
- **路由器（三层）**：依据IP网络层转发，通常分隔二层广播域并重封装帧

## 交换机转发表自学习
- 收到帧：先记**源MAC→入端口**（及老化时间），不依目的MAC学习
- **已知单播且出口≠入口**：仅向对应出口转发
- **目的MAC未知**：向同VLAN内除入端口外的其他转发端口洪泛
- **已知目的MAC恰在入端口**：过滤，不必再次发到该端口
- 广播、多播：按所在VLAN的转发规则泛洪/复制，不跨VLAN自动转发

## 二层交换方式
- **存储转发**：先收完整帧并检验FCS，再转发；可以在不同端口速率间缓存
- **直通交换**：收到足够识别目的地址的数据后即转发，延迟低但可能传播坏帧
- 实际交换芯片能力多样，不能绝对化“直通永远不能不同速率端口互连”

## STP与二层环路
- 交换网络有冗余链路时，广播/未知单播可能循环形成**广播风暴**
- **生成树协议STP/RSTP**选择部分链路处于转发状态，使活动二层拓扑逻辑无环
- 只靠MAC自学习**不能消除环路**，甚至可能导致MAC地址表抖动

## 经典集线器+交换机题
- H4连接Hub，Hub另接H3并上联交换机；交换机另接H2
- 若H2之前向H4发过帧，交换机已经学到**H2所在端口**
- H4向H2发单播ACK：**H3可从集线器电气信号中收到**，交换机只向H2端口转发
- 除H4以外，在相应拓扑下能从物理层收到：**H3与H2**；H1若是交换机其他端口则收不到
