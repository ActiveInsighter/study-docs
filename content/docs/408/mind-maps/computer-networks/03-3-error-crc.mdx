# 3.3 奇偶校验、CRC与差错检测

## 差错与检测概念
- **误码**：发送位与接收位不一致；误码率BER是错误比特数/传输比特数
- **奇偶校验**：附加校验位，使整组`1`的个数为偶数/奇数
  - 能检测**奇数个**翻转；**偶数个**翻转通常不能检测
  - 不自动定位与纠正错误位
- 循环冗余检验CRC：将比特串视为GF(2)多项式，使用**模2除法（异或，无进位/借位）**

## CRC计算步骤（高频）
- 生成多项式`G`最高幂为`r` → **校验序列FCS长度为`r`位**
- 数据`D`后补`r`个0，得到$D\cdot 2^r$
- 用`G`作模2除，得到**r位余数R**：$R=(D\cdot 2^r)\bmod G$
- 发送码字$T=D\cdot 2^r\oplus R$（即数据后附上R）
- 接收方以相同生成多项式检查`T' mod G`：非零→检测到差错；零→**可能仍有未检出差错**

## 验算例（纠正原图的阶数/位数混淆）
- $D=1101011011$（10位），$G(x)=x^4+x+1$，除数比特`10011`
- **生成多项式4阶=5位除数=4位FCS**，不要把“除数位数”直接当FCS位数
- 在D后补四个0：`11010110110000`
- 异或除法余数：`1110`
- 最终发送：`1101011011 1110`

## 能力范围（必须区分）
- CRC是**检错码**；常规链路层CRC仅用于发现可检出的差错，不能据此宣称自动纠错
- CRC的检错能力取决于生成多项式、报文长度和错误模式；**不是所有错误都能被发现**
- 发生错帧后可丢弃、上报或由其他协议启动ARQ重传

## 常见陷阱
- 模2减法等于**逐位异或**，不是普通十进制除法
- $G=10011$→FCS是4位，不是5位
- “余数为0⇒绝对未出错”错误；正确表达是**未检测到差错**
