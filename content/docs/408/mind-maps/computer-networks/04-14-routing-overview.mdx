# 4.14 静态动态路由、AS与路由算法

## 路由选择的层级
- **静态路由**：管理员/配置管理系统录入；简单，拓扑变动时需维护
- **动态路由**：路由器依协议交换可达性并更新路由；增加协议开销
- **IGP**自治系统内部：RIP、OSPF等；**EGP**跨自治系统：BGP
- AS是统一路由政策/管理范围；**不是必须使用一种且仅一种IGP**

## 三种经典思路
- 距离向量DV：知道到目标的度量与下一跳；典型RIP
- 链路状态LS：邻接和链路代价在一定范围内同步；典型OSPF并以SPF算最短路径
- 路径向量PV：传播前缀与AS路径等属性；典型BGP，更注重自治域政策

## 控制与数据分离
- 路由协议维护RIB，转发平面按照选路结果生成的FIB转发
- 动态学习一个前缀不代表每条流量都会逐包运行最短路算法
- 当有多种路由来源，管理距离/优先级、度量等用于**选出路由**，最终目的查表依LPM

## 度量与收敛
- RIP最小化跳数；OSPF通常最小化总代价；BGP按照多属性与策略选路
- 网络变化到稳定一致的时间叫收敛时间；不稳定时可能环路/黑洞
- 防环机制依协议不同：跳数上限、序列号、AS_PATH等

## 试题切入点
- 先问：域内还是域间？链路状态还是距离向量？跑什么承载协议？
- 再问：路由学习结果与实际转发表是否相同；当前目的地址命中最长前缀哪条
