# 1.1 网络概念、组成与核心功能

## 网络是什么
- **计算机网络**：由通信链路和网络设备连接的、按协议交换信息的自治计算机系统集合
  - 自治：各主机具有独立处理和控制能力；距离不构成绝对判别条件
  - 互连：使用有线/无线媒介传递数据；异构系统依协议互通
- **互联网 internet**：多网络互连的通用概念；**因特网 Internet**：基于全球TCP/IP协议族的公共互联网
- **资源**：硬件（存储、打印机）/软件（应用、服务）/数据（文件、数据库）

## 从工作方式看
- **边缘部分**：主机、终端、服务器、端系统；承担应用与数据源/宿
- **核心部分**：路由器及其互连链路；提供分组转发与网络连通
- 路由器连接多个网络，主机通常是通信的端点；交换机与路由器不能混为一谈

## 从组成与功能看
- **物理组成**：主机、接口、交换/路由设备、传输介质；运行软件和网络协议
- **功能组成（教材抽象）**
  - 通信子网：负责传输、交换和路由；并非总能严格按OSI层划界
  - 资源子网：承载应用服务、数据与计算资源；与现代虚拟化设施可交叉
- **主要功能**：数据通信、资源共享、分布式处理、提高可用性、负载分担
- **端到端思想**：复杂功能（如应用数据语义、端到端可靠性）通常由端系统参与实现

## 408典型辨析
- **网络 ≠ 因特网**：LAN与离线局域网络仍属计算机网络
- **自治 ≠ 完全无管理**：网络可以有统一管理，但连接的主机逻辑上可独立运行
- **核心负责转发 ≠ 核心负责全部可靠性**：可靠交付可由传输/应用层提供
