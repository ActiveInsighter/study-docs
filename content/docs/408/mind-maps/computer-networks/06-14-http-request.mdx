# 6.14 HTTP请求行、方法、首部与实体

## HTTP/1.1请求报文结构
- <img src="/images/408-mind-maps/cn-06-http-messages-clean.svg" alt="HTTP 1.1 请求和响应报文结构" width="1120" height="497">
- **请求行**：`方法 SP 请求目标 SP HTTP/1.1 CRLF`
- **请求头**：一个或多个`字段名: 值`，各行CRLF结束
- **空行**：标记首部结束；其后按报文定界规则可能跟请求消息体
- 主体不是所有请求都具备；GET没有“一定不能携带主体”的绝对句法禁令，但其主体通常不定义通用语义

- <img src="/images/408-mind-maps/cn-0010.svg" alt="HTTP 请求报文的结构" width="620" height="430">

## 常考方法
- `GET`获取目标资源的表示；`HEAD`只取与GET类似的元数据、不传响应主体
- `POST`向指定资源提交数据，可能创建或处理资源；一般**不保证幂等**
- `PUT`按目标URI创建/替换资源的状态，方法语义上幂等
- `DELETE`请求移除目标资源的关联；方法语义上幂等不等于永远返回同一状态码
- `OPTIONS`探查支持能力；`CONNECT`建立隧道；不要把方法与TCP控制标志混同

## 常用请求头
- `Host`（HTTP/1.1必需）指定目标主机/虚拟主机
- `Accept`选择响应媒体类型；`Content-Type`描述发送实体的类型
- `Cookie`回传服务器设置的Cookie（满足域/路径/安全等匹配条件）
- `Connection: close`表示在当前消息后不希望保持该连接

## 极简请求例子
- `GET /index.html HTTP/1.1`
- `Host: example.com`
- `Accept: text/html`
- 随后空行；GET简单请求可以没有消息体
