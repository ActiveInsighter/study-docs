- 例：按字编址，Cache 有 4 行，块大小为 1 个字；2 路组相联 + LRU；初始为空。依次访问主存地址 0, 4, 8, 2, 0, 6, 8, 6, 4, 8，命中 Cache 的次数是？（A. 1　B. 2　C. 3　D. 4）
  - 本题把“块号的次低位”作为组号：块 0、4、8 → 第 0 组，块 2、6 → 第 1 组

    |访问|0|4|8|2|0|6|8|6|4|8|
    |---|---|---|---|---|---|---|---|---|---|---|
    |第 0 组|0|0, 4|8, 4|8, 4|8, 0|8, 0|**8**, 0|8, 0|8, 4|**8**, 4|
    |第 1 组||||2|2|2, 6|2, 6|2, **6**|2, 6|2, 6|
    |结果|缺|缺|缺|缺|缺|缺|中|中|缺|中|

  - 共命中 3 次，选 C
