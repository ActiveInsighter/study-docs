- 网络层总流程示例：AS1 中有主机 A、B、C 与路由器 R1、R2、R3（R3 为 BGP 发言人），AS2 中有 R4（BGP 发言人）、R5 与主机 D、E、F
  - ① A 刚接入：A 用 DHCP 获取 IP（由 B 帮忙转发也可）
  - ② A → B：A 查 ARP 缓存，有则直接发；没有则广播 ARP 请求，B 收到后单播 ARP 响应告知自己的 MAC
  - ③ A → F：A 查 ARP 得到默认网关 R1 的 MAC，经 R1 → R2 → R3 → R4 → R5 → F
    - 经过 NAT 时需要转换地址
    - AS 内部用 OSPF 或 RIP 维护路由表；AS 之间 R3、R4 用 BGP 交换（BGP-4）
    - 每一跳都要用 ARP 找下一跳的 MAC 地址
