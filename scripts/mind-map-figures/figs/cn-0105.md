- CRC 模 2 除法示例：数据 1101 0110 11，生成多项式 $G(x) = x^4 + x + 1$ 即 10011（k = 4 阶），在数据后补 4 个 0

  ```text
              1100001010
         ┌──────────────────
   10011 │ 11010110110000
           10011
           ─────
            10011
            10011
            ─────
             00000 1 0 1 1 0
                 10011
                 ─────
                  010100
                   10011
                   ─────
                    01110   ← 余数（4 位）
  ```

  - 余数 1110 即 FCS，发送 1101 0110 11 1110；接收方用同一 G(x) 去除，余数为 0 则无差错
