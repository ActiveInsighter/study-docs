- 具体示例：在浏览器开发者工具（Network 面板）中查看一次 HTTP 请求的首部
  - General：Request URL `https://www.bilibili.com/`，Request Method `GET`，Status Code `302`，Remote Address `124.239.244.17:443`，Referrer Policy `strict-origin-when-cross-origin`
  - Response Headers：`Cache-Control: no-cache`、`Content-Length: 77`、`Content-Type: text/html; charset=utf-8`、`Date`、`Expires`、`Location: https://m.bilibili.com/`、`Vary: Origin,Accept-Encoding` 等
  - 302 表示重定向：浏览器根据 Location 再去请求新的地址
