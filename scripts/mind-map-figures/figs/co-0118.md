- 原码一位乘法手算模拟：机器字长 5 位（含 1 位符号位，n = 4），x = −0.1101，y = +0.1011
  - 解：|x| = 00.1101，|y| = 00.1011；每轮看 MQ 最低位 C₄：为 1 则 ACC + |x|，为 0 则 ACC + 0，然后 ACC、MQ 一起逻辑右移

    |步骤|ACC（高位部分积）|MQ（低位部分积 / 乘数）|说明|
    |---|---|---|---|
    |起始|00.0000|1011|C₄ = 1，+\|x\||
    |+\|x\||00.1101||部分积 00.1101|
    |右移|00.0110|1101|C₄ = 1，+\|x\||
    |+\|x\||01.0011||部分积 01.0011|
    |右移|00.1001|1110|C₄ = 0，+0|
    |+0|00.1001||部分积 00.1001|
    |右移|00.0100|1111|C₄ = 1，+\|x\||
    |+\|x\||01.0001||部分积 01.0001|
    |右移|00.1000|1111|乘数全部移出|

  - 结果绝对值 |x·y| = 0.10001111；符号 $P_s = x_s \oplus y_s = 1 \oplus 0 = 1$，得 x·y = −0.10001111
  - 要点：符号位不参与运算；累加 n 次、右移 n 次；部分积用双符号位（模 4）防止加法时溢出
