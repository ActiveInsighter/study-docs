- 微程序模式下的层次（以 X₁ = X₁ + X₂ 为例）
  - ① 高级代码 `X1 = X1 + X2` → 一对多 → 机器指令（汇编）`LDA …`、`ADD R1, R2`：执行一条机器指令的时间是一个指令周期
  - ② 机器指令 `ADD R1, R2` → 一对一 → 微程序：取指周期、间址周期、执行周期、中断周期 → 一对多 → 微程序组 A、B、C、D：执行一个微程序组的时间是一个机器周期
  - ③ 微程序组（如执行周期）→ 一对多 → 微指令（μOP + 下地址，存放在 CM 的 0、1、2 号单元）：执行一条微指令的时间是一个节拍 / 时钟周期
  - ④ 微指令 → 一对多（μOP 部分）→ 微操作 / 微命令：`(PC)→MAR`、`1→R`，在同一个节拍内完成
