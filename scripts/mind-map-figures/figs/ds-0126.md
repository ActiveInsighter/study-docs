- 括号匹配：`[ ( ) ( ) ] [ ]`
  - 左括号入栈；遇到右括号时与栈顶匹配并出栈，右括号本身不入栈
  - 栈中同时最多有 2 个元素：`[ (`，所以栈至少需要 2 个单元
- 中缀表达式求值：`(A+B)*C+D÷E`
  - 用两个栈：符号栈存运算符和左括号，数值栈存操作数和中间结果
  - 遇到操作数直接入数值栈；遇到运算符时，先把符号栈中优先级 ≥ 它的运算符弹出计算，再让它入栈
  - 过程：`(`、`(+` 时符号栈最多 2 个；遇到 `)` 计算出 A+B；`*` 入栈后遇到 `+` 先算 (A+B)*C；`+÷` 入栈，数值栈最多同时有 `(A+B)*C, D, E` 3 个
  - 结论：符号栈最少需要 2 个单元，数值栈最少需要 3 个单元
